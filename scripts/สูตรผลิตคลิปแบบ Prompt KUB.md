| 20–30 | ลูป 1: ปัญหา → ข้อเท็จจริง → ทางแก้ | "อย่างแรกคือน้ำ เพราะบ่อบาดาลใช้ปั๊มไฟฟ้า ไฟดับเมื่อไหร่น้ำก็หยุดไหล" | ข้อเท็จจริงต้องเป็นของจริง ใส่แหล่งอ้างอิงในคำอธิบายคลิป |

| 38–50 | ลูป 2: นับทรัพยากร (HUD ตัวนับเพิ่มทีละใบ) | "ไก่ 30 ตัว เป็ด 12 ตัว ปลาในบ่ออีกเป็นร้อย และหมาไทยหลังอานที่เห่าทุกอย่างที่ขยับ" | ตัวเลขรูปธรรม 3–4 รายการติดกัน |
| 50–58 | ลูป 3: สรุปทางแก้ + ความคืบหน้า | "เขาจึงล็อกประตูรั้ว…แล้วเริ่มนับของทุกอย่างที่มีบนกระดาษ เขาอยู่ที่นี่ได้เป็นเดือน" | ให้ความรู้สึกปลอดภัยชั่วคราวก่อนหักมุม |

## 3. สูตรภาพ (visual grammar)

### 3.1 ลำดับประเภทช็อตที่ตัวอย่างใช้ (ลอกลำดับนี้ได้เลย)
1. ภายในบ้าน/ร้าน มุมกว้าง มีแสงลอดหน้าต่าง ตัวละครกำลังทำกิจวัตร (กินข้าว) สัตว์นอนข้าง ๆ
2. โคลสอัพ "สิ่งที่ส่งสัญญาณเตือน" (จอมือถือสีแดง) ตัวละครถือ
3. มุมสูงทั้งสถานที่ (แผนที่สวน) + การ์ด HUD ใหญ่ "วันที่ 1 · 06:42 น."
4. ไดอะแกรมวงกลมขยายส่วน (แผนที่ + ไอคอน เครื่องมือ/เชื้อเพลิง/น้ำ/อาหาร)
5. ตัวละครเดินด้านข้าง (walk cycle) + สัตว์ตาม ฉากหลังเลื่อน
6. ตัวละครเดินผ่านยานพาหนะ (รถกระบะ) → POV ในรถ มือจับกุญแจ
7. ไดอะแกรมเครือข่าย "ทุกคนมุ่งหน้าไปไหน" (จุดแดงขยาย เส้นเชื่อม ระยะ 18 กม.)
8. ภายในบ้านอีกมุม + HUD นาฬิกาถอยหลัง 30:00 → 29:26 → …
9. โคลสอัพทรัพยากร (ชั้นขวดน้ำ) + HUD ตัวเลข 110 → 180 ลิตร
10. ภาพตัดขวางใต้ดิน (บ่อบาดาล ปั๊ม) + แถบสถานะ ไฟฟ้า→ปั๊ม→น้ำ มีเครื่องหมายถูก/กากบาท
11. ฉากมืด มีไฟฉายส่อง (เครื่องปั่นไฟ) = "ทางแก้ที่สร้างปัญหาใหม่"
12. มุมสูงอีกครั้ง + วงรัศมี 300/500 ม.
13. ฉากป่ามืดหมอก มีเงาคน = ภัย
14. โคลสอัพสัตว์ทีละชนิด (ไก่ เป็ด ปลา หมา) + HUD ตัวนับซ้อนกัน
15. มุมสูง โซนกลายเป็นสีแดง = "แทบเป็นไปไม่ได้"
16. โคลสอัพมือล็อกประตู
17. ตัวละครต้อนสัตว์ (เดินอีกครั้ง)
18. โต๊ะ สมุด ปากกา ไฟฉาย กุญแจ (มุมบน) + การ์ดรายการเสบียง
19. ตัวละครนั่งพักกับสัตว์ ตอนเย็น (แสงอุ่น) = ปลอดภัยชั่วคราว
20. โคลสอัพหน้าสัตว์หูตั้ง = สัญญาณเตือน
21. กลางคืน เงาคนยืนหน้าโรงเก็บ → ประตูมืดมีแสงลอดใต้ประตู = cliffhanger
22. การ์ดดำ "ตอนที่ 2" + บรรทัดแดง
23. โลโก้ช่อง

สัดส่วน: ฉากเล่าเรื่อง 60% / ไดอะแกรม-แผนที่-ตัดขวาง 25% / โคลสอัพวัตถุหรือสัตว์ 15%

### 3.2 แสงและสี
- 1 ฉาก = 1 โทนหลัก + 1 สีตรงข้ามเป็นจุดเน้น (ภายในอุ่นเหลือง-น้ำตาล / ภายนอกเขียว-ฟ้าอ่อน / กลางคืนน้ำเงินเทา / ไดอะแกรมพื้นเขียวเข้ม-แดง)
- มีลำแสงจากหน้าต่าง (god rays โปร่ง 10–15%) + ฝุ่นลอยในแสง
- vignette ขอบมืด 50–60% + เกรนฟิล์มบาง ๆ ทั้งคลิป
- ฉากหน้าเบลอ 1 ชิ้น (ใบไม้ เก้าอี้ เสา) เพื่อมิติ
- เงาทอดใต้ตัวละครและวัตถุทุกชิ้น

### 3.3 ตัวละคร
- คน: สัดส่วน 6 หัว เสื้อผ้าจำง่าย (หมวกเขียว + ผ้าพันคอแดง) มีหน้า ตา คิ้ว ปาก กะพริบตาทุก 2–3 วิ
- สัตว์ประจำ 1 ตัว (หมาไทยหลังอาน) โผล่ตั้งแต่ช็อตแรก หูตั้งเมื่อมีภัย
- ทุกช็อตที่มีตัวละครต้อง "ทำอะไรสักอย่าง" (กิน เดิน ขับ ล็อก เขียน นั่ง) ไม่มียืนเฉย
- walk cycle: ขา ±20° คาบ 0.35 วิ แขนสลับ ฉากหลังเลื่อนสวนทาง

### 3.4 HUD และไอคอน
- การ์ดครีม มุมบน 18px เงาอ่อน ไอคอนเส้น 2.5px สีดำในป้ายเหลือง ข้อความ 2 บรรทัด (ป้ายเล็ก + ค่าใหญ่)
- ค่าที่ "เปลี่ยน" ต้องเห็นเปลี่ยนบนจอ (นาฬิกาเดิน ตัวนับเพิ่ม แถบสถานะติ๊ก)
- ไม่เกิน 3 ใบต่อช็อต เพิ่มใบใหม่ด้วยการเลื่อนเข้าจากซ้าย 0.25 วิ
- ไอคอนที่ต้องมีในชุด: นาฬิกา จับเวลา น้ำ ไฟฟ้า ปั๊ม อาหาร เครื่องมือ เชื้อเพลิง สัตว์แต่ละชนิด แผนที่/หมุด ระยะทาง เสียง/คลื่น อันตราย กล้อง สมุด

### 3.5 ซับไตเติล
- ฟอนต์ไทยหนา ~56px (ที่ 1080px) ขาว เงาดำ 2 ชั้น
- 2–5 คำ เปลี่ยนตามวลีเสียง ไม่ใช่ตามประโยค
- คำสำคัญ: ป้ายแดง (#e03b3b) ตัวขาว สำหรับ "อันตราย/ห้าม/ผิด" และตัวเหลือง (#ffd54a) สำหรับ "สถานที่/ตัวเลข/คำตอบ"

## 4. ท่อการผลิต (ที่ Prompt KUB ใช้และเราทำซ้ำได้)

1. **บท**: เขียนตามตาราง §2 ด้วย Claude (ให้ Claude ตรวจกฎ "แต่/ดังนั้น" และใส่ข้อเท็จจริงพร้อมแหล่ง)
2. **เสียง**: ElevenLabs v3 ภาษาไทย (ผ่าน fal.run หรือ API ตรง) ตัดความเงียบ + เร่ง 1.25–1.3 เท่า วัดความยาวแต่ละบรรทัดด้วย ffprobe → ได้ไทม์ไลน์ช็อต
3. **ภาพ**: HyperFrames (npx hyperframes init --resolution portrait) + SVG ทุกช็อต (ฉาก ตัวละคร HUD ซับ) ตามสูตร §3 ไฟล์เดียว index.html สร้างจากสคริปต์ Python/Node ที่อ่านความยาวเสียง
4. **ซับ**: ตัดวลี 2–5 คำ ตั้งเวลาเริ่มตามช็อต (หรือใช้ Whisper/Scribe จับเวลาระดับคำแล้วจัดกลุ่ม)
5. **เสียงประกอบ**: ElevenLabs Sound Effects (ฝน เครื่องจักร เห่า ดนตรีโดรน สติง) ทำลูป 90 วิ ด้วย ffmpeg -stream_loop
6. **ตรวจ**: npx hyperframes lint → snapshot ทุกช็อต → ดูเฟรมจริงทุกใบก่อนเรนเดอร์
7. **เรนเดอร์**: npx hyperframes render -q looks (หรือ delivery) → MP4 1080x1920 → โพสต์ 19:30
