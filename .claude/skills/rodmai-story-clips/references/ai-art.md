# ลุคภาพ AI (เจ้าของเลือก 6 พ.ย. 2569): ทุกเฟรมวาดด้วย AI ในสไตล์รูปต้นแบบ แล้วเอามาขยับในระบบเดิม

เจ้าของส่งรูปที่ GPT วาด (จอมโกหกถือการ์ด F แสงเงานุ่ม 3D) แล้วบอกว่า "ทำคลิปแสงเงามีมิติแบบในภาพได้มั้ย" — ฟิลเตอร์ SVG ไม่ถึง ("มันไม่เหมือนในภาพ") สิ่งที่ผ่าน: วาดภาพด้วย fal nano-banana โดยแนบรูปต้นแบบเป็น style reference แล้วประกอบเป็นเพลต + ตัวตัด (cut-out) ในเอนจินเดิม (กล้อง แคปชัน HUD ไอคอน มิกซ์ เรนเดอร์ เหมือนเดิมทุกอย่าง) งานแรก: `video/jk-ep1-ai/` (จอมโกหก EP.1 ฉบับภาพ AI)

## 1. วาดภาพ (fal.run · key อยู่ใน proxy แล้ว ห้ามขอ key)
- สคริปต์: `production/gen.py jobs.json` (งาน `edit` = `fal-ai/nano-banana/edit` 9:16 → 768×1344 jpg ≈ $0.039/รูป · `cut` = `fal-ai/birefnet/v2` → png โปร่ง) รันขนานได้ 6 งาน รูปละ ~12 วิ · prompt ประกอบจาก `chars.py` (STYLE + คำบรรยายตัวละครคงที่ทุกช็อต)
- refs ทุกช็อตที่มีตัวเอก = รูปต้นแบบของเจ้าของ + รูปตัวเอกที่วาดได้แล้ว (เพื่อให้หน้าเหมือนกันทุกช็อต) · ตัวละครอื่นวาดช็อตกว้างก่อน แล้วส่งรูปนั้นเป็น ref ของโคลสอัป ("the GODDESS from the second image")
- ขอ **ไม่มีตัวหนังสือ** ในภาพเสมอ (AI สะกดไทยพัง) ตัวหนังสือทุกอย่างใส่จาก SVG/HTML ของเรา (การ์ด ป้าย กระดาน แคปชัน)
- ภาพคู่สลับสีหน้า: edit รูปเดิมด้วย "Edit the FIRST image. Keep everything else exactly the same. Change only: …" (ตาปิด→เปิด, หูแดง, ชักดาบ, ทั้งแถวหัวเราะ) แล้ว crossfade ในช็อต (`vars` + `vari()`)
- เพลตไม่มีตัวละคร: edit "Remove the man completely and fill in …" → ใช้คู่กับ cut-out ของรูปเดิม (ตำแหน่งตรงกันเพราะเฟรมเดียวกัน) · ท่าตก/ของชิ้นเดียว: วาดบนพื้นขาว แล้ว cut
- ไม่ต้อง upscale: ESRGAN anime ลบเกรน/โบเก้ของภาพ (ดูแย่กว่า) ให้เบราว์เซอร์ขยาย 768→1080 เอง ซูมกล้องไม่เกิน ~1.5
- ค่าใช้จ่ายจอมโกหก EP.1: 36 งาน ≈ $1.2 (เกินงบเสียง $3.10 ไม่ได้ แต่เป็นงบใหม่ แจ้งเจ้าของแล้ว)
- ตรวจทุกชุดด้วย contact sheet ก่อนใช้ (PIL ต่อรูป 8 ใบ/แถว) และวาดกริด 100 px ทับเพลต (`grid_*.jpg`) เพื่ออ่านพิกัดของปากท่อ ปากคน แผ่นกระดาษ ฯลฯ ก่อนวางของ SVG ทับ

## 2. ประกอบในเอนจิน (`body_head.part` ท้ายไฟล์ · `body_shots.part`)
- `Sets.aiPlate(L, o)`: `o.src` ใน set (parallax 1) · `o.mid` ใน mid (0.6 → มีมิติเวลากล้อง push เมื่อมี cut-out อยู่ใน act) · `o.vars` = รูปสลับ (opacity 0) · `ai(k, {plate:{…}, cam|camAt, fx})` = shot() ที่ปิด light/depth/grade, dark 0
- `P(x, y, s, sx, sy)` = `fr()` ที่ **clamp** หน้าต่างกล้องให้อยู่ในรูป 1080×1920 (ไม่งั้นขอบดำ: a02/a09/a20 เคยเป็น) · `vari(tl,k,i,at)` crossfade · `flashW()` แฟลชขาว
- cut-out: `cut(L, id, "x.png", fx, fy, parent)` (<image> เต็มเฟรม, origin ที่เท้า) · `breathe/sway/tremble/walk` · ตกลงหลุม: `clipBelow(id, g, y)` + tween y ให้พ้นเส้น (ท่อ: y ≥ ความสูง cut-out ไม่งั้นเหลือหัวโผล่)
- แคปซูล/ของชิ้นเล็ก: ครอบ `<g transform="translate scale(.23)">` แล้ว tween กลุ่มด้านใน (x,y,rotation ด้วย svgOrigin กลางวัตถุ)
- Engine.look vignette 0.3 (ภาพ AI มี vignette ของตัวเองแล้ว) · เพลตที่ต้องเบลอใส่ `blur:{set:n}` ได้ตามปกติ
- **หน้าเว็บจะ crash ถ้าโชว์ทุก clip พร้อมกัน** (22 รูปเต็มเฟรม + เบลอ) — ทุกสคริปต์ snapshot ต้องซ่อน `.clip` ที่ไม่ active (sheet9/snapt ทำอยู่แล้ว; pageerr แบบ seek อย่างเดียวจะตาย)
