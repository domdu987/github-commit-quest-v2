## 1. ผลที่ต้องได้ (ยังไม่ผ่านข้อไหน = ยังไม่เสร็จ)

### 1.1 รูปแบบและการส่งมอบ
- คลิปสั้น 1080×1920 60fps · ตอนละ 60–80 วิ · เสียง −14 LUFS (±0.5) · true peak ≤ −1 dB · ความยาววิดีโอ = มิกซ์ ±0.05 วิ
- **ลงคลิปสั้นแค่ EP.1 และ EP.2** (ผู้ใช้สั่ง 5 พ.ย.) ตอนที่เหลือเป็น "เรื่องเต็ม" บน YouTube · EP.1 ปิดด้วยการ์ด "ดูเรื่องเต็มทาง YouTube"
- ตอนยาว YouTube: **แนวนอนจริง 1920×1080 เต็มเฟรม** ไม่มีแผงข้าง ไม่มีปก/ท้ายคลิป (ผู้ใช้ปฏิเสธแบบมีแผงทันที) ต่อ 4 ตอนเป็นเรื่องเดียว ตัดฮุคของตอน 2–4 และการ์ดท้ายตอนออก ครอสเฟด 0.2 วิ พร้อมเวลาแบ่งตอน
- ส่งทุกครั้ง: ไฟล์ HQ + ปก + `CAPTIONS.md` (ชื่อคลิป คำอธิบาย คอมเมนต์ปักหมุด แฮชแท็ก ≤ 6) และสำหรับตอนยาว `YOUTUBE.md` + ปก 16:9 · ปิดท้ายคำอธิบายว่า "เรื่องและตัวละครเป็นเรื่องสมมติ"
- เก็บเข้า repo ด้วย `store.sh` ทุกตอน + `video/release/<เรื่อง>.json` (sha256 ทุกไฟล์ สถานะ final/archive กฎการลง) + `video/<เรื่อง>-long/` (ตอนยาวฉบับ ≤ 95 MB, README วิธีสร้างใหม่, สคริปต์, โปรเจกต์ปก)

### 1.2 เรื่องและบท
- ฮุค 3 วินาทีแรกเป็นคำถาม "ถ้าคุณ…" + ของที่กากที่สุด/ตลกที่สุดของเรื่อง · ผู้ใช้บอกว่าความยาวเรื่องตอนนี้ "สนุกแล้ว" — **อย่ายืดเรื่อง** ทำให้แน่นแทน
- บทเป็นเสียงเล่าคนเดียว (voice Enceladus/Puck ผ่าน `voice.py` → fal gemini-3.1-flash-tts) ประโยคสั้น มีคำที่ปล่อยเป็นมุก (ติ๊ง… หนึ่งเปอร์เซ็นต์) · คำบรรยายแบ่งด้วย " / " ให้ลงจังหวะเสียง · `[คำสำคัญ]` = เหลือง `{คำสั่ง/คำเด็ด}` = กล่องแดง
- สิ่งที่บทพูดต้องตรงกับภาพ 100% (เคยพลาด: บทว่า "มังกรสามหัว" แต่วาดหัวเดียว) — **grep บททุกคำที่เป็นภาพก่อนวาด**

### 1.3 ภาพ (ระดับที่ผู้ใช้ชม "น่ารักที่สุด" / "ดีมากกกก")
- ฉากมีมิติ: ชั้น sky/far/mid/set/act/fg + glow/light · กรวยแสงจากโคม หมอกไกล ฝุ่นลอย เงาสัมผัสพื้น ของตกแต่งประจำฉาก (ป้ายรถเมล์ ไฟจราจร โปสเตอร์ WANTED ขวดบนชั้น ถังไม้ ธงราว) ผ่าน `JKD.dress[set]` ใน `jkdepth.js` · **แสงต้องไม่กลบตัวละคร** (ผู้ใช้ติ) — glow ของโคม/เตาผิง/แดดลดลงแล้วใน `jkset.js` อย่าปรับขึ้น
- ตัวละคร v2 (`flat.js`): ผ้ามีแสงเงา หัวมีไล่สี แก้มแดง ผมมีประกาย หายใจ ตาเหลือบ เนคไท/ผ้าพันคอแกว่ง ย่อ-ยืดตอนลงพื้น และ**ท่าแสดงประจำช็อต** (shrug facepalm cheer cower think coverEars despair relief pray fold nod no + แบบนั่ง sit*) กับสีหน้า (happy sad squint smirk grin pout grit) — ทุกช็อตที่มีอารมณ์ต้องมีท่า ไม่ปล่อย idle
- ไอคอน v3 (`jkicons.js`): เหรียญมีเงาพื้น วงแหวน โดม แสงวิ่ง ปั๊มสัญลักษณ์ เด้งเข้าแบบพลิกเหรียญ + แฟลช + ประกาย + กระดาษสี แล้วสั่นนิดๆ · ป้ายชื่อปั๊มเข้า · ลายสัตว์ต้องมีลูกเล่น (จิ้งจกหางม้วน ตะกวดลิ้นแฉก จระเข้ฟันซี่ มังกรน้อยปีกค้างคาวพ่นไฟ)
- สิ่งที่ผู้ใช้ไม่เอา: 3D · แสงจ้าทับตัว · ของที่ "ดูเหมือนต้นไม้" แทนมังกร (ต้องดุ: ขากรรไกรอ้า เขี้ยว ตาเหลือง เขา ปีก หนาม สามหัวตามบท) · ตัวละครทะลุเฟอร์นิเจอร์ (ตรวจกับ act-front ของฉาก: เคาน์เตอร์ x 970–1530 โต๊ะ x 160–420/560–820 ในโรงเตี๊ยม)

### 1.4 มุมกล้อง (รสนิยมผู้ใช้ สรุปจากการเลือก A/B/C 5 พ.ย.)
- **ใช้แบบ A**: กล้องแบบหนังเฉพาะจุดที่มีเหตุผล — เครนเปิดฉาก · ซูมฉับตอนช็อก · วิปแพนเข้าเหตุการณ์ · เอียง+สะเทือนตอนกระแทก · โฟกัสเบลอ→ชัดตอนตื่น · ข้ามไหล่ตอนคุย · มองจากหลังหัวตอนอ่านป้าย · แถบดำตอนร่วงลงเมือง · มุมต่ำตอนยืนเหนือคนอื่น
- **ไม่เอา**: มือถือสั่น/เอียงในช็อตพูดคุยเฉยๆ · มุมสูงจากฟ้า (พระเจ้ามอง) · ช็อตสายตาตอนตกท่อ (ผู้ใช้ชอบ "ตกลงไปเฉยๆ ตลกดี")
- **เอา**: มุมมองสายตาที่เป็นมุก — "มองลอดถัง" (ตาสองรูของถัง เห็นทั้งร้านหัวเราะกับเลข +1 ลอย) ผู้ใช้ถามหาเอง · ใช้ `JKC.bucketPOV(L)` + `shake: JKC.pov(7, 4.5)` และเอาตัวเอกออกจากช็อต
- ตัวเล็กในช็อตกว้างได้ ("ตัวเล็กก็ดีแล้ว") แต่ต้องเห็นว่าใครทำอะไร

### 1.5 เสียง
- มิกซ์ = เสียงเล่า (ปรับระดับ) + เพลงจาก Suno ของผู้ใช้ (`musicbed.py` ตัดเป็นช่วงอารมณ์ ductก 60% ใต้เสียงพูด) + SFX สังเคราะห์จาก `synth.py` ตาม `sfx_cues.json` · loudnorm I=−13.3 TP=−2.2 ที่ท้าย `mix.py` ให้ได้ −14 LUFS จริง
- **ห้ามมีเสียง "แตกๆ" และ "ซ่า"** (ผู้ใช้ติ): ตัดคิว `steps` ที่ดังกรอบแกรบออก whoosh ใช้ lowpass 400/1200 เกน 0.26 · ตรวจซ่าด้วย `scripts/hiss.py` (ย่าน >5 kHz ในช่วงเงียบต้อง < −60 dBFS)

### 1.6 QA ก่อนส่ง (ทำครบทุกข้อ ทุกไฟล์)
1. `qa_video.sh <HQ> mix.wav` → ขนาด fps ความยาว ความดัง peak
2. `scripts/qa_splice.py <HQ> <out.jpg> key…` ทุกช็อตที่แก้/ที่มีกล้องขยับ: ดูเฟรมขอบ+ต้น+กลาง+ท้าย
3. `scripts/blackscan.cjs <port> <dir>` + วิเคราะห์ (ใน pipeline.md) ทุกหน้า: หา "สี่เหลี่ยมดำ" ของ overlay ใต้ฟิลเตอร์เงา (เคยเจอ 6 เฟรมที่ไอคอน % กำลังเด้งเข้า)
4. `scripts/hiss.py mix.wav vo/*.wav`
5. ตอนยาว: เฟรมที่รอยต่อทุกจุด (±0.2 วิ) + เฟรมช็อตเด่นของทุกตอน + ตรวจ "ไอคอนซ้ายบนทับกัน" (แถบสถานะ vs สติกเกอร์นับคน) และ "แถวไอคอนทับคำบรรยาย" ในแนวนอน
6. ดูภาพทุกใบด้วยตาจริงๆ แล้วเขียนสิ่งที่ยังขาดบอกผู้ใช้เอง (ผู้ใช้ถาม "คิดว่าดียัง" บ่อย ตอบตรง มีรายการ)

## 4. กับดักที่เจอแล้ว (ทำตามนี้จะไม่เจอซ้ำ)
- overlay ที่ `opacity:0` ใต้ `filter="url(#nvDrop)"` วาดเป็น **กล่องดำ** → ซ่อนด้วย `autoAlpha` (มีใน `enterC` แล้ว) อย่าใช้ opacity อย่างเดียวกับกลุ่มที่มีฟิลเตอร์
- `tl.fromTo(..., immediateRender:false)` กับของที่ต้องซ่อนก่อนเข้า → ต้อง `tl.set(opacity 0 @0)` + `set(1 @at)` ด้วย
- tween ที่เริ่มเวลาติดลบทำให้ timeline ทั้งหน้าเลื่อน → `Math.max(0, …)` เสมอ
- CSS `filter: blur()` บนกลุ่ม SVG ที่ล้นจอไม่วาด → ใช้ SVG filter (jkiSoft / whip ต่อ clip)
- จับภาพขนานกันตอน CPU หนักได้เฟรมครึ่งเดียว → จับทีละภาพ และใช้ `snapq.cjs`
- nohup/setsid เรนเดอร์ถูกยกเลิก (parent exited) → ใช้ Bash background task เท่านั้น · task มีเพดาน 2 ชม. → ≤ 2 ตอนต่อ task · ต่อคิวด้วย sentinel เฉพาะ (เช่น `QUEUE7-END` ใน log ที่ tee ไว้) **อย่า grep "exit 0" จาก output ของ task ก่อนหน้า** (เคยทำให้ 2 เรนเดอร์ชนกัน)
- worker restart ทำให้ `python3 -m http.server` ตายทั้งหมด → ก่อน capture ให้ `curl` เช็กพอร์ตแล้วสตาร์ตใหม่
- GitHub รับไฟล์ < 100 MB: HQ ตอนยาวเก็บฉบับ crf 23 (~75 MB) ส่วนต้นฉบับ 170 MB ส่งผู้ใช้ตรง/LFS/Release
- บทพูด "สามหัว" → วาดสามหัว · เด็กยืน x 1000 ทะลุเคาน์เตอร์ (act-front เริ่ม 970) → ย้ายไป 920
