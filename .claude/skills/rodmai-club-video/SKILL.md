# Rod Mai Club · คู่มือทำคลิป "ถ้าวันหนึ่ง… คุณ…"

ช่อง Rod Mai Club ทำมินิซีรีส์แอนิเมชันแนวตั้งภาษาไทย: **ผีไทยหนึ่งตน + อันตรายใกล้ตัวคนไทย + ความรู้เอาตัวรอดที่ถูกต้องจริง**
เล่าแบบหนังสั้นที่ลุ้นจนอยากดูตอนต่อ ผู้ใช้คือเจ้าของช่อง ตัดสินงานด้วยคำถามเดียว: **"ดีกว่าคลิปล่าสุดไหม"**

ไฟล์นี้บอกว่าคลิปต้อง "ได้อะไร" (หัวข้อ 1) และ "ทำอย่างไร" (หัวข้อ 2–6) ทุกข้อในหัวข้อ 1 มาจากสิ่งที่ผู้ใช้ติหรือสั่งจริง
ผู้ใช้จับผิดเก่งมาก: เห็นทันทีว่ารถเล็กกว่าคน นาฬิกาหมุนทั้งเรือน การ์ดกฎหายไปหนึ่งตอน ผีดูไม่น่ากลัว
**ก่อนส่งอะไรให้ผู้ใช้ดู ให้ไล่หัวข้อ 1 เองก่อนทุกครั้ง** อย่าให้ผู้ใช้ต้องเป็นคนตรวจ

## 1. ผลที่ต้องได้จากวิดีโอ (ยังไม่ผ่านข้อไหน = ยังไม่เสร็จ)

### 1.1 รูปแบบ
- **F1** 1080×1920 · 60 fps · H.264 + AAC 48 kHz · ไฟล์ลงช่อง = `*-HQ.mp4` (copy ภาพจาก raw ไม่บีบซ้ำ) · ไฟล์เก็บ repo = `*-share.mp4`
- **F2** ตอนละ ~1:40–2:00 ช็อตเฉลี่ย 3–4 วิ ไม่มีภาพนิ่งหรือความเงียบเกิน 3 วิ ยกเว้นจังหวะกลั้นหายใจที่มีเสียงหัวใจเดิน
- **F3** เรื่องละ 3 ตอนเป็นค่าเริ่มต้น (ผู้ใช้ไม่จำกัดจำนวนตอน ถ้าเรื่องต้องการ) ตอนละ 1 กฎ

### 1.2 เรื่องและบท
- **S1** คำแรกของทุกตอนคือ **"ถ้าวันหนึ่ง… คุณ…"** ตามด้วยคำสั่งสวนสัญชาตญาณ เฟรมแรกต้องเห็นอันตราย
- **S2** EP.1 ของเรื่องใหม่เปิดด้วยชื่อเรื่อง + EP.1 ในฉากเปิดที่คิดจากโลกของเรื่องนั้น **ห้ามซ้ำฉากเปิดของเรื่องอื่น**
- **S3** สูตร "เสียงกอย" (คลิปที่คนดูเยอะที่สุดของช่อง ผู้ใช้สั่งให้กลับมาใช้เสมอ):
  - สถานการณ์ใกล้ตัวคนไทย + ผีไทย 1 ตน
  - ตัวละคร 3–4 คน มีบทพูดราว 40% และมีมุกแบบคนจริง
  - ประโยคสั้น 2–5 คำ
  - ไม่เอาสงคราม ไวรัส หรือไซไฟ
- **S4** ผู้ใหญ่ในเรื่องตั้ง **กฎคล้องจอง 3 ข้อ ตอนละข้อ** การ์ดกฎต้องขึ้น **ทุกตอน** ตรงจังหวะที่ตัวละครทำตามหรือเรียนรู้กฎข้อนั้น
  - ข้อที่ผ่านแล้วติ๊กถูก ข้อของตอนนี้ไฮไลต์ ข้อที่ยังไม่ถึงขึ้นจางๆ
  - ผู้ใช้ถาม "แล้วกฎ 3 ข้อล่ะ" ตอน EP.2 ไม่มีการ์ด
- **S5** EP.1 บอกลักษณะผีสั้นๆ 2–3 ประโยคบนภาพตำนานแบบหนังตะลุง: รูปร่าง สี จุดเด่น วิธีล่อ และวิธีทำร้าย
- **S6** จังหวะของบท:
  - มีจุดหักทุก 10–15 วิ ("แต่…" / "เพราะงั้น…")
  - มีภัยที่คนดูเห็นก่อนตัวละครอย่างน้อย 1 ฉาก
  - มีประโยคที่ quote ได้ 1–2 ประโยค
- **S7** ความต่อเนื่องและเหตุผล:
  - ทุกเหตุการณ์ส่งผลกับทุกช็อตหลังจากนั้น เช่น ไฟดับแล้วต้องดับตลอด
  - ทุกการกระทำมีเหตุผลที่ **เห็นในภาพ** (ผู้ใช้ถาม "มันต้องขึ้นทางบันไดมั้ยนะ")
- **S12** ฉากเดินทางต้องมีแผนที่: หมุดต้นทาง/ปลายทาง เส้นทางวาดตาม และพาหนะวิ่งตามเส้น ก่อนตัดเข้าฉากที่ไปถึง (ผู้ใช้: "ถ้ามีฉากที่ต้องเดินทางทำแผนที่ด้วย" 28 ต.ค. 2026)
- **S8** ปมค้างต้องเป็นหลักฐานในภาพที่คนดูต่อเองได้ เช่น รอยเท้านิ้วยาว หรือหน้าต่างที่ไฟดับ
  - วางเบาะแสข้ามตอนไว้ให้ตอนจบเฉลยได้
- **S9** ตอนจบของแต่ละ EP:
  - EP.1–2: ประโยคปิดหลอน 2 ท่อน → ตัวเลือก 2 ทางที่ถูก "ดึง" ไปทางน่ากลัว → ตัดดำ → การ์ดท้ายจากโลกของเรื่อง ~2 วิ
  - ตอนสุดท้าย: ไม่มีตัวเลือก จบที่ปม แล้วขึ้นการ์ด "ตอนจบ"
- **S10** ไม่มีประโยคซิกเนเจอร์ "ถูกหมด… ผิดแค่ข้อเดียว" อีกแล้ว (ผู้ใช้สั่งลบ 25 ต.ค. 2026)
- **S11** เรื่อง ตัวละคร ผี การ์ด และฉากเปิดต้องเป็นของเราเอง คลิปต้นแบบใช้ได้แค่หลักการ

### 1.3 ความรู้
- **K1** ทุกข้อเท็จจริงต้องยืนยันกับแหล่งทางการหรือแหล่งปฐมภูมิ
  - เก็บข้อความตรงตัวพร้อมลิงก์ไว้ใน `video/<เรื่อง>/ARC.md`
  - ข้อไหนยืนยันไม่ได้ให้ **ตัดทิ้ง** · ถ้าแหล่งทางการขัดกัน ให้ใช้ข้อที่ปลอดภัยกว่าและจดไว้
- **K2** ความรู้เขียนเป็น **เหตุ → ผล + ตัวเลขจริง** แล้ววาดเป็นภาพในโลกของเรื่อง เช่น ภาพผ่าครึ่ง กระดานหมอ หรือของวางบนแคร่
  - ห้ามเรียงการ์ดไอคอนหลายใบ
- **K3** ชิปที่มาเล็กๆ ขึ้นจอตอนพูดความรู้ แหล่งเต็มใส่ในคอมเมนต์ปักหมุด
- **K4** UI ขึ้นเฉพาะสิ่งที่บทพูดถึง และต้องเล่นตามสิ่งที่พูด เช่น "สามทุ่ม" → นาฬิกาเดินไปสามทุ่ม

### 1.4 ภาพ (ระดับมืออาชีพ: ผู้ใช้ขอ "มีมิติ แบบมืออาชีพทำ")
- **V1** ตัวละครและแสง:
  - ตัวละครวาดแบบ rig2 มีแสงเงาและ rim light
  - ฉากหลายชั้นมีความลึก มีหมอก ฝุ่น อนุภาค และแสงที่มีที่มา
  - เกรดสี vignette และ grain · ฉากกลางวันต้องสว่างสด ไม่หม่นเทา
- **V2** มุมกล้องหลากหลายแบบภาษาหนัง:
  - เรียงแบบ establishing → กลาง → ใกล้ → insert → reaction
  - ใช้มุมต่ำ มุมสูง ข้ามไหล่ มองผ่านช่อง กล้องเลื่อนตามมีเหตุผล
  - มุมมองคนที่หนึ่งใช้แค่จังหวะวิกฤตสั้นๆ (ผู้ใช้: "แค่ให้ทำหลายๆ มุมกล้อง")
- **V3** การวางตัวละครต้องสมเหตุสมผล ใครอยู่ตรงไหน ทำอะไร เพราะอะไร
  - คนขับนั่ง **ในรถ ที่นั่งขวา** (รถไทยพวงมาลัยขวา) มือจับพวงมาลัย
  - ไม่มีตัวละครคนเดียวกันซ้ำในช็อตเดียว ของอยู่ในมือจริง
- **V4** สัดส่วนจริง ดู `references/visual-direction.md` หัวข้อสัดส่วน
  - รถ บ้าน ประตู และเฟอร์นิเจอร์ต้องได้ขนาดเทียบคน (หลังคากระบะสูงราว 1.1 เท่าของคน)
  - มือไม่จิ๋ว คนนั่งต้องมีที่นั่ง เท้าแตะพื้น หัว คอ ไหล่ และแขนต่อกัน
  - ผมต้องติดหัว: ไรผมอยู่เหนือคิ้ว ไม่มีแถบสีผิวคั่นระหว่างผมกับหัว ซูมดูหัวทุกตัวละครใหม่ก่อนส่ง (ผู้ใช้: "ผมหลุดออกจากหัวแล้ว" 28 ต.ค. 2026)
- **V5** ของต้องอ่านออกว่าเป็นอะไร:
  - บันไดมีขั้นและราว
  - รอยเท้าแยกซ้ายขวา มีนิ้ว และย่อตามระยะ
  - เมฆเป็นก้อนนุ่ม แอ่งน้ำมีเงาสะท้อน
- **V6** การเคลื่อนไหวต้องถูกหลักฟิสิกส์:
  - นาฬิกาหมุนแค่เข็ม
  - ของหมุนหรือเด้งรอบจุดของมันเอง ไม่พุ่งมาจากนอกจอ
  - รถวิ่งแล้วถนนกับเสาข้างทางต้องเลื่อน
  - ไม่มีอะไรกระโดดไปมุมจอ
- **V7** ผีต้องตัวดำสนิท ตาเขียวเรือง และโชว์ให้น้อยที่สุด
  - ฉากเผยตัวใช้ความมืด: ไฟกะพริบแล้วดับ เหลือแต่ตา
  - จัมป์สแกร์ตามสูตรกองกอย EP.3: นิ่ง 2–4 วิ → ตาดับ เงียบ 0.3–0.6 วิ → ตูมครั้งเดียว 0.15–0.25 วิ → ตัดดำ
- **V8** ไอคอนและการ์ด (ผู้ใช้: "icon ต่างๆทำให้ดีกว่านี้ และให้เคลื่อนไหวสวยๆ… แบบมืออาชีพ" 28 ต.ค. 2026):
  - ระดับงาน motion graphics มืออาชีพ: เข้าด้วย easing (back/elastic) ไล่จังหวะทีละชิ้น แล้วมีการเคลื่อนไหวรองต่อ (เต้น สั่น วาดเส้น ประกาย) ห้ามเป็นภาพนิ่งแปะ
  - วาดเป็นไอคอนจริง วัตถุชิ้นเดียว เส้นหมึกหนา สีแบน 3–4 สี + เงาหนึ่งชั้น + ไฮไลต์หนึ่งชั้น อยู่ในวงกลม
  - เครื่องหมายที่ให้ความหมาย (วงห้าม ลูกศร) ต้องอยู่ครบตอนการ์ดค้างจอ
  - ห้ามย่อพร็อพในฉากมาทำไอคอน · การ์ดออกแบบให้เข้ากับโลกของเรื่อง
- **V10** ทุกอย่างต้อง "มีมิติ" และละเอียด (ผู้ใช้ดูสตอรี่บอร์ดตึกโยก EP.1: "ทำแผนที่ icon ต่างๆการเคลื่อนไหว ให้สวยให้มีมิติ ฉากให้ละเอียดกว่านี้ได้มั้ย สิ่งของต่าง ให้ดีกว่านี้" 29 ต.ค. 2026):
  - ฉาก: ของในห้องเยอะพอให้เชื่อว่ามีคนอยู่จริง วัสดุอ่านออก (ลายไม้ โลหะขัด กระจกสะท้อน ผ้ามีรอยพับ) เงาใต้ของทุกชิ้น แสงมีที่มาและตกกระทบพื้น/ผนัง
  - ของ (props): ไม่ใช่สี่เหลี่ยมสีเดียว ต้องมีหน้าบน/หน้าข้าง ไฮไลต์ เงา และรายละเอียดของจริง (มือจับ ปุ่ม ขอบ รอยต่อ)
  - ไอคอน: แบบ 2.5D ไล่แสงเงา มีขอบหนาให้รู้สึกเป็นเหรียญ/ป้าย เงาตกด้านล่าง การเคลื่อนไหวมี squash & stretch และ overshoot
  - แผนที่: แผ่นดินนูนมีความหนา ภูเขา ทะเลไล่สี หมุด 3 มิติพร้อมเงา และเห็นพื้นเอียงเหมือนมองจากมุมสูง
  - การเคลื่อนไหว: ของในฉากตอบสนองตามเหตุการณ์ (สั่นแล้วหนังสือหล่น กรอบรูปแกว่ง ผ้าม่านไหว ฝุ่นร่วง) ไม่ใช่แค่กล้องสั่น
- **V9** ซับและป้าย:
  - ซับอยู่ในกรอบปลอดภัย ไม่บังหน้าหรือของสำคัญ
  - ไม่มีป้ายหรือตัวละครหลุดขอบจอโดยไม่ตั้งใจ
  - คำสำคัญอยู่ในกล่องเหลือง `[คำ]` คำอันตรายหรือหักมุมอยู่ในกล่องแดง `{คำ}`

### 1.5 เสียง
- **A1** ผู้บรรยายใช้ Gemini TTS เสียง **Puck** อ่านเรียบไม่ใส่อารมณ์ tempo ~1.2
  - ตัวละครใส่อารมณ์เต็มที่ เลือกเสียงให้เข้ากับนิสัย
  - ห้ามใช้ style "กระซิบ"
- **A2** ทุกบรรทัดต้องผ่าน Whisper QA (CER ≤ 0.25) และฟังคำสำคัญเองอีกรอบ (เคยหลุดเป็น "ถูกทาก")
- **A3** ระดับเสียง:
  - เสียงพูด −18 dB RMS ดนตรี −30 SFX −27
  - ลดดนตรีใต้เสียงพูด และเงียบก่อนจังหวะหลอน
  - ทั้งคลิป −14 LUFS พีกไม่เกิน −1 dB
- **A4** **ไม่มีเสียงซ่าหรือ noise bed** (ผู้ใช้สั่งลบหลายรอบ) · SFX ต้องตรงกับสิ่งที่เห็นในภาพ

## 3. ทำให้ "ดีกว่าคลิปล่าสุด" (ทำทุกเรื่องใหม่)

ผู้ใช้ขอแบบนี้ทุกครั้ง ก่อนเริ่มเรื่องใหม่ให้เปิดคลิปล่าสุดของช่อง (`video/<เรื่องล่าสุด>-ep*-v2/` หรือ share mp4 ล่าสุด) แล้วยกระดับอย่างน้อย 3 ด้านนี้ บอกผู้ใช้ด้วยว่ายกระดับอะไร:
1. **เรื่อง:** hook แรงขึ้น · เบาะแสข้ามตอนที่เฉลยแล้วคนดู "อ๋อ" · มุกตัวละครที่จำได้ · ทุกตอนมีฉากที่ต้องดูซ้ำ
2. **การแสดง:** ท่าทางมีเหตุผล (หยิบ ถือ จับ ชี้ หันมอง) · มีจังหวะเตรียมตัวและส่งต่อ (anticipation/overshoot) · ผมและผ้าขยับตาม · ร่างกายแตะสิ่งที่ใช้จริง (เท้าบนพื้น มือบนพวงมาลัย)
3. **กล้องและแสง:** เปิดฉากด้วย establishing ทุกฉากใหม่ · มี insert ของสำคัญ · ฉากหน้ากรอบภาพ (foreground framing) · แสงมีที่มาและต่อเนื่อง (ไฟเปิด/ดับตรงกันทุกช็อต)
4. **ความรู้:** วาดเป็นกลไกที่ขยับได้ในโลกของเรื่อง แทนการ์ด · ตัวเลขจริงขึ้นเป็นกราฟิก
   - แบบที่ผู้ใช้ชม: ภาพพลิก อสม. หัวใจปกติบีบส่งเลือดตรงจังหวะจอ ECG เทียบหัวใจที่ไฟลัดวงจรสั่นระริกไม่มีเลือดออก ปิดด้วยตรายาง (ข้อความทุกคำมาจาก quote)
   - ไอคอนเป็นสัญลักษณ์มาตรฐานที่คนเข้าใจทันที (คนนอน + มือปั๊มอก = CPR) ขยับตามความหมาย (ปั๊ม 110 ครั้ง/นาที, มือตบไหล่, คลื่นหัวใจวิ่ง)
   - ทุกการเดินทางมีแผนที่จริง (`Sets.mapTH` + `Maps.route`) แล้วซูมเข้าปลายทาง
5. **เสียง:** SFX ตรงทุกการกระทำ · เงียบก่อนตกใจ · ดนตรีขึ้นช่วงแอ็คชั่น
6. **ผี:** ความมืด + ตาเขียวเท่านั้น · ยิ่งโชว์น้อยยิ่งน่ากลัว · ใกล้ขึ้นทีละช็อต

## 5. กติกาการทำงานกับผู้ใช้

- **ตอบเป็นภาษาไทยทั้งหมด สั้น และตรง** (รวมตัวเลือกใน AskUserQuestion) เรียกผู้ใช้แบบเป็นกันเองได้ ("เพื่อนรัก" คือคำที่ผู้ใช้ใช้เอง)
  - ถ้าผู้ใช้ถามคำถาม ให้ตอบคำถามก่อนลงมือทำอย่างอื่น (ผู้ใช้เคยต้องพิมพ์ "ตอบผมก่อน")
  - เรื่องใหญ่ (premise ใหม่ เสียงตัวละคร) ให้เสนอ 2–3 ตัวเลือกพร้อมตัวที่แนะนำ
- **ห้ามขอ API key ในแชท** key ของ fal.ai อยู่ใน network secret ของ environment แล้ว
  - ถ้าเจอ `403 TOP_UP` แปลว่าเครดิตหมด ให้บอกผู้ใช้เติม
- **git:** ทำงานบน branch ที่ session กำหนด (ปัจจุบัน `ccr-fb88c4b3-kcqyid`)
  - ห้ามเปิด PR ถ้าไม่สั่ง และห้ามใส่ชื่อหรือรหัสโมเดลใน commit
  - commit + push ก่อนจบเทิร์นทุกครั้ง
- **งานยาว:** เรนเดอร์ใช้ ~30–110 นาทีต่อตอน
  - สั่งเรนเดอร์ทีละตอนเป็น background ด้วย `timeout` 2 ชม. เพราะค่าเริ่มต้น 30 นาทีจะตัดงานกลางทาง
  - ห้ามใช้ `sleep` รอ · ระหว่างรอทำงานอื่นต่อ และแจ้งความคืบหน้าสั้นๆ
  - เครื่องมี 4 คอร์ ถ้าเรนเดอร์ 2 ตอนพร้อมกันจะช้าลงทั้งคู่
- **ดิสก์:** พื้นที่ของ session มีจำกัด ถ้า `df` เหลือ < 3 GB ให้ลบ raw/HQ เก่าของตอนที่ส่งและเก็บแล้วใน scratchpad
- **ผู้ใช้เปลี่ยนใจได้เร็ว:** ถ้าคำสั่งกำกวม ("เอาแบบเดิม") ให้ถามกลับสั้นๆ ก่อนทำงานที่ย้อนกลับยาก
