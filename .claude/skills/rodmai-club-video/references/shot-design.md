## 1. ตอบ 7 ข้อก่อนเขียนช็อต

เขียนคำตอบเป็นคอมเมนต์หัวช็อตก่อนเขียนโค้ด:
1. **คนดูต้องเข้าใจอะไร 1 อย่าง** จากช็อตนี้ (ถ้าตอบไม่ได้ ช็อตนี้ไม่ควรมี)
2. **อยู่ที่ไหน มองจากไหน** (set + view) และต่อจากช็อตก่อนอย่างไร (ไฟ ระดับน้ำ ของที่ตก ประตูที่เปิด)
3. **ขนาดภาพ** ต้องต่างจากช็อตก่อน: establishing / wide / medium / close / insert / มุมบน / มองผ่านช่อง
4. **ใครอยู่ในภาพ** ยืนตรงไหน ทำอะไร ถืออะไร หันไปทางไหน และทำไม
5. **กล้องขยับอย่างไร เพราะอะไร**: ดันเข้า = ลุ้นหรือเน้น · ถอยออก = เผยของ · ตาม = แอ็คชั่น · นิ่งแล้วตัดฉับ = น่ากลัว
6. **อะไรขึ้นจอ**: ซับ, ชิปที่มา, การ์ด เฉพาะสิ่งที่บทพูดถึง (K4)
7. **เสียงอะไร**: ทุกการกระทำที่เห็นมี SFX (เขียนลง `mix.py` ทีหลัง)

## 2. ไวยากรณ์ภาพทั้งตอน

- เขียนลำดับภาพทั้งตอนเป็นคอมเมนต์บนสุดของ `body.part` ก่อน แล้วอ่านดูว่าขนาดภาพสลับกันจริง
- เข้าที่ใหม่ → establishing ก่อน · คุยกัน → ภาพสองคน แล้ว**ตัดไปที่คนพูด**ตอนอีกคนพูด · ความรู้ → insert หรือกลไกที่ขยับ ·
  เผยความจริง → ภาพกว้าง · ฉากน่ากลัว → กล้องนิ่งแล้วตัดฉับ
- insert ทำเป็นฉากของตัวเอง (`tideShop` view `wall` / `table` / `door`) ไม่ใช่ซูมเข้าไปในภาพกว้าง จะได้มีรายละเอียดพอ
- หลักฐานปิดตอนเป็นภาพนิ่งที่กล้องค่อยๆ ดันเข้าหาจุดเดียว (ประตูร้านเปิด → รองเท้ายายบนบันได)
- ช็อตเดียวมีสองมุมได้ด้วย `cam.keys` (ตัดฉับหรือเลื่อน) โดยไม่ต้องแยกช็อตใน `timing.py`:
  ```js
  // ภาพสองคนตอนจูนพูด แล้วตัดไปที่ยายตอนยายพูด (ทะเลลด ช็อต acct)
  cam: { keys: [{ t: 0, ...fr(575, 1050, 1.32, 540, 1000) },
    { t: vo("acct", 1) - 0.15, glide: vo("acct", 1) - 0.15, ...fr(560, 1040, 1.4, 540, 1000) },   // ดันเข้าช้าๆ ระหว่างประโยคแรก
    { t: vo("acct", 1) - 0.12, ...fr(410, 990, 2.1, 540, 900) },                                // ไม่มี glide = ตัดฉับ
    { t: D("acct"), glide: D("acct") - vo("acct", 1), ...fr(405, 985, 2.2, 540, 900) }] },
  ```

## 3. ตัวเลขกล้อง

- `fr(wx, wy, s, sx, sy)` วางจุด (wx, wy) ของฉากไว้ที่จุด (sx, sy) บนจอ ด้วยซูม s
  - กว้าง 1.0 · กลาง 1.2–1.5 · ใกล้ 1.8–2.4 · insert = ฉากของตัวเองที่ 1.0–1.1
- key ใน `cam.keys`: `{ t, glide, ease, ...fr() }` · **glide จบที่เวลา t** (เริ่มที่ t − glide) · key ที่ไม่มี glide = ตัดฉับที่ t
- engine ดันกล้องเข้าเองราว 1.2% ต่อวินาทีในทุก key (`drift.s` ค่าเริ่มต้น 0.012) · ช็อตที่ต้องนิ่งจริง (สยองนิ่งแล้วตัดฉับ ฉากวาดใหม่ทุกเฟรม) ใส่ `drift: { s: 0 }`
- ช็อตส่วนใหญ่ดันเข้าเพิ่มด้วย glide 0.07–0.15 ของซูมตลอดช็อต · ช็อตเปิดเรื่องหรือช็อตเผยความจริงถอยออกได้
- ช็อตที่ถือมือถือหรือวิ่ง ใช้ `shake`:
  `shake: (t) => ({ x: 4 * Math.sin(t * 3.1) + 2 * Math.sin(t * 7.7), y: 3 * Math.sin(t * 2.3), r: 0.4 * Math.sin(t * 1.7) })` (ไลฟ์) ·
  `({ x: 5 * Math.sin(t * 9), y: 4 * Math.sin(t * 13), r: 0.5 * Math.sin(t * 5) })` (วิ่ง)
- ฉากที่วาดใหม่ทุกเฟรม (แผนที่ 3 มิติ ภาพผ่าครึ่ง): กล้อง engine นิ่ง `fr(540, 960, 1, 540, 960, { drift: { s: 0 } })` แล้วคุมกล้องของฉากเอง
  (`TideMap.play(..., { cam: [{ t, lon, lat, tilt, yaw, S, cy }] })`) · จุดสำคัญ (จุดแผ่นดินไหว + ป้าย) ต้องอยู่เหนือแถบซับ
- ของใน `L.mid` / `L.far` เลื่อนช้ากว่ากล้อง (parallax p: sky .05 far .25 mid .6 set/act 1 fg 1.5) ตำแหน่งบนจอคำนวณได้:
  กล้อง `fr()` ให้ {x, y, s} → ชั้นที่ parallax p ใช้ซูม ls = 1 + (s − 1)·p แล้ว จอ x = 540 + ls·(px − 540 − x·p), จอ y = 960 + ls·(py − 960 − y·p)
  (หมู่บ้านเมื่อมองจากเขาอยู่ใน `L.mid`) คำนวณแล้วยังต้องถ่ายภาพนิ่งยืนยัน
- **แถบซับ y 1480–1700:** หน้าคนและของสำคัญต้องอยู่เหนือ y ~1450 หรืออยู่ข้างกล่องซับ (x < 300 หรือ x > 780)
- **ล่าง 220 px คือ UI ของ TikTok:** ห้ามมีป้ายหรือชิปสำคัญ (ป้าย "แผ่นดินไหวใต้ทะเล" เคยตกไปอยู่ตรงนั้น)

## 4. การวางตัวละคร

- ขนาดตามระยะ: ใช้ฟังก์ชันของฉาก (`Tide.shopPos(X, Z)`, `Tide.SHOP.spots`) · มุมมองทะเล: scale ≈ 3.87·h/d (h สูงเป็นเมตร d ระยะ) ·
  rig สูง ~620·s · 1 เมตร ≈ 376·s · เด็ก 10 ขวบ ×0.76 ของผู้ใหญ่
- ของที่บังตัวละคร (เคาน์เตอร์ `#id-front`) ถูกวาดทับนักแสดงอยู่แล้ว ห้ามวางคนตรงหน้าของพวกนี้ (ยายยืน**หลัง**เคาน์เตอร์)
- คนคุยกันต้องหันเข้าหากัน (`flip`) · ของในมือใช้ cast ตัวแปรที่ถือของ (`junePhone`, `tangBucket`, `taJunConch`)
- วิ่ง: `moveTo: { x, y, dur, ease: "power1.in" }` (ออกตัวช้าแล้วเร่ง) · คนเดินผ่านยาวๆ: `ease: "none"`
- เดินเข้าหาหรือออกจากกล้อง: ใส่ `moveTo.s` (หรือ `s` ในแต่ละจุดของ `path`) ให้ตัวโตหรือเล็กลงตามระยะ
  - rig มีแต่ด้านหน้า ไม่มีมุมหลัง: คนที่เดินออกจากกล้องให้หันข้าง หรือใช้คนเล็ก `Tide.fig`
  - ตัวอย่าง: ทะเลลด ช็อต hill สองพี่น้องวิ่งขึ้นบันไดเข้าหากล้อง scale 0.44 → 0.74
- ฝูงคนไกลๆ: รูปคนเล็ก `Tide.fig` เดินสองเฟรม ย่อลงตามระยะ (helper `walkDown` ใน `video/tide/ep1/body.part`)
  - คนเล็กพวกนี้หยาบเมื่อใหญ่เกิน ~120 px ให้โผล่ตอนกล้องถอยออกแล้วเท่านั้น และค่อยๆ เฟดเข้า
- ทุกสิ่งที่บทพูดถึงต้องเห็นในภาพ: "ห่วงยางผม!" → ห่วงยางหล่นเด้งบนทรายข้างกล่องซับ · "แล้วคนก็เดินลงไปเก็บของ" → คนเดินลงบันได

## 5. การแสดง

- ทุกบรรทัดของตัวละคร: `talk: [TALK(k, i, "o")]` (พูดปกติ "o" · หัวเราะ "laugh" · ตะโกน "scream")
- เปลี่ยนท่าตรงจังหวะที่ตัวละครรู้สึกหรือรู้อะไร: `track` หลายจุด เช่น ตาจุ่น `shadeEyes` → `pointUp` ตอนรู้ว่าต้องหนี ·
  `blowConch` (ตาปิด) → `pointUp` + ปาก `scream` ตอนตะโกน
- ตา: `wide` ตกใจ · `worry` เป็นห่วง · `closed` เป่าหอย · กะพริบ `blinks: [0.8, 2.9]`
- ท่าใหม่ประกาศใน cast ของเรื่อง (`tidecast.js`: film, pointUp, blowConch, ringArms, cheer, shadeEyes, wagFinger, scoop, holdPhoto)
