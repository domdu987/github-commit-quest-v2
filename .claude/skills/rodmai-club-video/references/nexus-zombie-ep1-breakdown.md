- **#1 ถ้าวันหนึ่ง** — เงื่อนไขสมมติ 3 พยางค์ ไม่ให้ข้อมูลอะไรเลย = บังคับรอใบต่อไป · ภาพ = ชีวิตปกติ (กินข้าว หมานอน แสงอุ่น) ตั้งไว้ให้ชนกับคำถัดไป
- **#2 ซอมบี้ระบาด** — premise ทั้งเรื่องใน 4 พยางค์ กล่องแดงใบแรก · ภาพยังปกติอยู่ → ความขัดแย้งภาพ/คำ
- **#3 ตอนที่คุณอยู่ในสวน** — ล็อก "คุณ" + สถานที่เฉพาะ (สวน ≠ เมือง) · ภาพมือถือแจ้งเตือนแดง = ใช้ UI ที่คนไทยเคยเห็นจริง (emergency alert) แทนภาพซอมบี้ → ไม่ต้องวาดซอมบี้เลยทั้งคลิป
- **#4 อย่าเพิ่งขับรถ เข้าเมือง** — คำสั่งห้ามสวนสัญชาตญาณ · "เพิ่ง" = ชะลอ ไม่ใช่ห้ามถาวร → เปิดคำถาม "แล้วเมื่อไหร่" · เหลืองที่ "เข้าเมือง" = คำที่จะวนกลับมาใบ #13
- **#5 เพราะโดยไม่รู้ตัว** — "เพราะ" สัญญาว่าจะให้เหตุผล · "โดยไม่รู้ตัว" = ตั้งคนดูเป็นคนกำลังจะได้รู้ความลับ · ตัดมุมสูง + HUD "วันที่ 1 · 06:42 น." (world-building ด้วยตัวเลขเล็ก)
- **#6 คุณกำลังยืนอยู่ใน** — ค้างที่บุพบท "ใน"
- **#7 ที่ที่รอดได้ดีที่สุด** — payoff สีเหลือง · ภาพแผนที่วงกลม 4 ไอคอน (เครื่องมือ/เชื้อเพลิง/น้ำ/อาหาร) พิสูจน์โดยไม่พูด · เบสในเพลงหายไปช่วงนี้ให้ประโยค "ลอย"
- **#8 แห่งหนึ่ง** — hedge ท้ายประโยค (หนึ่งใน… ไม่ใช่ที่สุด) = ความน่าเชื่อถือแบบสารคดี แต่วางไว้ *หลัง* payoff เพื่อไม่ลดแรง

**BEAT 1 · กฎข้อ 1 (10–23 วิ) — เข้าสู่ "เอก"**
- **#9 แต่ต้องไม่พลาด เรื่องโง่ๆ** — "แต่" ตัวแรก + แดง + สติง + เบสเข้า = จุดเปลี่ยน hook→เรื่อง · "โง่ ๆ" เป็นคำพูดคน ให้โทนเพื่อนเตือน ไม่ใช่ครูสอน
- **#10 แค่เรื่องเดียว** — open loop หลักของตอน · ภาพแนะนำเอกด้วยการเดินกับหมา *ก่อน* บอกชื่อ
- **#11 สัญชาตญาณแรกของเอก** — บอกชื่อครั้งแรก (เอก = 1 พยางค์ everyman) · "สัญชาตญาณแรก" บอกล่วงหน้าว่าสิ่งที่จะทำคือ reflex ไม่ใช่เหตุผล → คนดูเดาได้ว่าผิด · การ์ดยาวสุด 2.2 วิ = หายใจก่อนเร่ง
- **#12 คือขับกระบะ** — "คือ" เชื่อมแบบ explainer · "กระบะ" ไม่ใช่ "รถ" = รายละเอียดชนบทไทย
- **#13 เข้าเมือง** — callback #4 ภายใน 12 วิ → คนดูรู้ก่อนเอกว่านี่คือเรื่องโง่ ๆ · ภาพมือเสียบกุญแจ = จุดที่คนดูอยากตะโกน
- **#14 ไปดูว่าเกิดอะไรขึ้น** — เหตุผลของเอก = ความอยากรู้ (ความผิดพลาดที่ทุกคนทำ) การ์ดสั้นลงเป็น 0.8
- **#15 อย่า** — คำเดียว แดง · ภาพตัดเป็นกราฟมืด (สว่าง 128→34) · สติง · **ผู้เล่าแทรกเข้ามาสั่งตัวละคร** = เสียงโค้ชที่คนดูรู้สึกว่าสั่งตัวเอง
- **#16 นั่นคือที่ที่ ทุกคนกำลังมุ่งหน้าไป** — ยาวสุด 11 พยางค์ = เหตุผลครบในประโยคเดียว · network graph ทุกเส้นวิ่งเข้าจุดแดง + HUD 18 กม. (ไกลพอจะไป ใกล้พอจะอันตราย) · สติงใหญ่สุดของคลิป
- **#17 เอกมีเวลาราว** — ค้างที่ "ราว" → ตัวเลขถัดไป · HUD "กฎข้อ 1" สรุปบทเรียน 1 บรรทัด อ่านได้แม้ปิดเสียง · คำว่า "ข้อ 1" บอกว่ามีข้ออื่น = ซีรีส์

**BEAT 2 · 30 นาที / น้ำ (23–34 วิ)**
- **#18 30 นาที** — ตัวเลขเหลือง + นาฬิกานับถอยหลังบนจอ · เวลาในจอเดิน 30:00→26:48 ใน 3 วิของคลิป = time-lapse ไม่ต้องบอก
- **#19 ก่อนไฟฟ้า** — ค้าง
- **#20 จะเริ่มติดๆ ดับๆ** — คำซ้ำภาษาพูด · ไม่พูด "ไฟดับ" ตรง ๆ เพราะ "ติด ๆ ดับ ๆ" = กำลังจะพัง (anticipation) น่ากลัวกว่าพังแล้ว
- **#21 อย่างแรกคือ** — สัญญาณลิสต์ (มี "อย่างแรก" = จะมีถัดไป) ค้าง
- **#22 น้ำ** — คำเดียวเหลือง · HUD ตัวเลขวิ่ง 110→180 ลิตร (ตัวเลขเดิน = กำลังทำอยู่)
- **#23 เพราะบ่อบาดาลในสวน** — "เพราะ" รอบสอง · ภาพตัดขวางใต้ดิน = โหมด explainer เต็มตัว
- **#24 ใช้ปั๊มไฟฟ้า** — HUD ลูกศร ไฟฟ้า→ปั๊ม→น้ำ = ห่วงโซ่เหตุผลวาดเป็นไอคอน
- **#25 ไฟดับเมื่อไหร่** — โครง "เมื่อไหร่…ก็" ค้าง
- **#26 น้ำก็หยุดไหล** — แดง ปิด beat ด้วยปลายห่วงโซ่ · HUD ทั้งสายขึ้นกากบาท · ไม่มีสติง (ใบถัดไปตัดภาพแรงแทน)

**BEAT 3 · เครื่องปั่นไฟ → เสียง (34–45 วิ)**
- **#27 เขามีเครื่องปั่นไฟ** — เสนอทางแก้ทันที ไม่ยืด · ภาพเงาดำหน้าประตูสว่างจ้า = ลางร้ายทั้งที่เนื้อหาเป็นข่าวดี → ภาพบอกล่วงหน้าว่าทางแก้นี้มีปัญหา
- **#28 แต่ทันทีที่สตาร์ท** — "แต่" ตัวที่สอง + "ทันที" = ไม่มีช่วงโล่งใจ · เสียงเครื่องยนต์จริงเข้า (เบสดังสุดของคลิป)
- **#29 ก็เกิดปัญหาใหม่** — แดง · การ์ดที่ประกาศโครงสร้างตรง ๆ (ทางแก้→ปัญหาใหม่) → คนดูจับแพทเทิร์นได้ เริ่มรอ "แต่" ครั้งถัดไป = ติดด้วยฟอร์ม
- **#30 ในสวนที่เงียบสนิท** — ตั้ง contrast ก่อนเฉลย (เงียบ vs เสียง) · HUD วงรัศมี 100/300 ม. VO ไม่พูด
- **#31 เสียงเครื่องยนต์** — เหลือง · ประธานมาทีหลัง: เรียง "สถานที่ → ประธาน → กริยา" เพื่อให้คำสำคัญได้การ์ดของตัวเอง
- **#32 บอกตำแหน่งคุณ** — กลับเป็น "คุณ" กลางเรื่อง = ยกเหตุการณ์ของเอกเป็นกฎสากล · ภาพกลางคืนเงาดำกลางร่องสวน
- **#33 ได้ไกลหลายร้อยเมตร** — VO พูดคลุม ("หลายร้อย") จอให้ตัวเลขชัด (100/300) → VO ไม่ต้องรับภาระความแม่น
- **#34 และเอก ไม่ได้อยู่ที่นี่** — misdirect: โครงประโยคแบบหนังสยอง ("he's not alone") · ตัดภาพแรงสุดของคลิป กลางคืน→ไก่กลางวัน + สติง + เบสหายทั้งหมด = เปลี่ยนโทนใน 1 เฟรม
- **#35 คนเดียว** — payoff คำเดียว · เพลงเบาลง = comic beat

**BEAT 4 · สัตว์ (45–56 วิ)**
- **#36–39 ไก่ 30 ตัว / เป็ด 12 ตัว / ปลาในบ่ออีกเป็นร้อย / และหมาไทยหลังอาน** — ลิสต์ 4 รายการ เรียง "นับแม่น → ประมาณ → ตัวเดียวแต่สำคัญสุด" (หมาอยู่ท้ายเพราะเป็นตัวปัญหา) · HUD นับสะสมมุมซ้ายบนเหมือน inventory ในเกม · "หมาไทยหลังอาน" ระบุพันธุ์ = รายละเอียดท้องถิ่นเพิ่มความจริง · **ไม่มี "แต่" ในลิสต์ = ช่วงหย่อนสุดของเรื่อง** (ไม่มีสติงเลย 44.9–52.6)
- **#40 ที่เห่า ทุกอย่างที่ขยับ** — เหลือง + "โฮ่ง!" ในภาพ = เสียงเดียวที่ตัวละครมี · อนุประโยคขยายหมา เปลี่ยนลิสต์ให้กลายเป็นปัญหา
- **#41 แปลว่า การทำให้สวนเงียบ** — "แปลว่า" = ผู้เล่าสรุป logic ให้ คนดูไม่ต้องคิดเอง · ค้าง · มุมสูงวงเสียงซ้อนทั้งสวน
- **#42 แทบเป็นไปไม่ได้** — แดง + สติง + เบสกลับ · "แทบ" = hedge แบบเดียวกับ "แห่งหนึ่ง"

**BEAT 5 · ลงมือ + ความปลอดภัยจอมปลอม (56–64 วิ)**
- **#43 เขาจึงล็อกประตูรั้ว** — "จึง" = การ์ดแรกที่เอกทำถูก · SFX โซ่ = foley เด่นสุดในคลิป
- **#44 ต้อนสัตว์ เข้ามาใกล้บ้าน** — action ล้วน ไม่อธิบาย (คนดูต่อเองได้จาก beat 4)
- **#45 แล้วเริ่มนับ** — การ์ดสั้นสุด 0.6 วิ ค้าง · props สมุด+ไฟฉาย+กุญแจ บอกว่าเตรียมกลางคืน
- **#46 ของทุกอย่างที่มี** — HUD เสบียง น้ำ 168 ล. / ข้าว ~30 วัน / ดีเซล 2 ถัง = ตัวเลขชุดใหญ่สุด VO ไม่อ่านสักตัว
- **#47 บนกระดาษ** — วลี foreshadow ("ตามทฤษฎี") → คนดูรู้ทันทีว่าความจริงจะต่าง
- **#48 เขาอยู่ที่นี่ได้** — ค้าง
- **#49 เป็นเดือน** — เหลือง · สติง + เสียงดังสุดช่วงท้าย = พีกของความปลอดภัยก่อนดรอป · ภาพเดียวที่เอกนั่งนิ่ง (แสงเย็น หมาข้าง ๆ)

**BEAT 6 · TWIST (64–69 วิ)**
- **#50 มีปัญหา อยู่อย่างเดียว** — หยุด 0.46 วิ + เบสเป็นศูนย์ก่อนพูด · โคลสอัพหมาหูตั้งหันมอง (หมา = คนดูในเรื่อง รู้ก่อนเอก) · โครงประโยคล้อ #10 "แค่เรื่องเดียว" → loop ปิดสวยพอดี
- **#51 มีใครบางคน** — "ใครบางคน" ไม่ใช่ "ซอมบี้" = ไม่เฉลยชนิดภัย · สติง · โรงเก็บกลางคืน
- **#52 อยู่ในรั้ว** — ย้อน #43 (เพิ่งล็อกรั้ว) → ทางแก้ที่ถูกกลายเป็นกับดัก ล็อกตัวเองไว้กับภัย = ironic reversal
- **#53 มาก่อนแล้ว** — แดง · "แล้ว" ย้อนเวลา: ภัยอยู่ตั้งแต่ก่อนเรื่องเริ่ม → คนดูย้อนคิดทั้งคลิปใหม่ · ประตูแง้ม ตาเรืองแสง + เสียงประตู + drone ไต่ขึ้น
- **การ์ดตอน 2** — "มีบางอย่างอยู่ในโรงคัดทุเรียน": เปลี่ยน "ใครบางคน" → "บางอย่าง" (คน→สิ่ง) ยกระดับความไม่แน่นอน · ระบุสถานที่เฉพาะผูกกับ setting สวนทุเรียน · CTA "กดติดตาม แล้วมารอดวันแรกไปด้วยกัน" ใช้ "ด้วยกัน" = เชิญเข้าร่วม ไม่ใช่ขอร้อง

## E. กติกาที่ถอดได้ (ใช้เขียนบทใหม่)

1. 1 การ์ด = 1 ข้อมูลใหม่ (1 คำนาม/ตัวเลข/คำสั่ง) ≤ 11 พยางค์ · เฉลี่ย 1.3 วิ
2. ทุก 3 การ์ด ให้ 1 การ์ดค้าง (จบด้วย ใน/คือ/ราว/ก่อน/ได้)
3. ทุก beat (~10 วิ) ปิดด้วยการ์ดแดง = ปัญหาใหม่ · ไม่มี beat ไหนจบสบายใจ
4. ก่อนการ์ดแดงใหญ่: การ์ดสั้นลงเรื่อย ๆ (2.2→1.8→1.2→0.8) แล้วคำเดียว
5. "คุณ" สำหรับกฎ · "ตัวละคร" สำหรับความผิดพลาด
6. ตัวเลขทุกตัวไปอยู่บน HUD · VO พูดตัวเลขเฉพาะที่เป็นจุดหักของเรื่อง (ที่นี่คือ 30 นาที)
7. Plant ทุก twist ไว้ก่อน ≥ 20 วิ ในรูปมุกหรือ action ที่ดูไม่สำคัญ (ล็อกรั้ว / ไม่ได้อยู่คนเดียว)
8. Twist = ดึงออก ไม่ใช่อัดเข้า: หยุดเสียง 0.4–0.5 วิ + เบสหาย + ภาพมืดลง แล้วพูดช้าลง
9. ภาพตัดพร้อมหรือก่อนคำใหม่เสมอ ไม่ตามหลัง
10. Hedge 1 คำต่อ beat (ราว/แทบ/แห่งหนึ่ง) ให้เสียงผู้เล่าเป็นสารคดี ไม่ใช่โฆษณา
