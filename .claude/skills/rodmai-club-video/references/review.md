# ตรวจงานเองก่อนส่ง (ทำทุกครั้ง อย่าให้ผู้ใช้เป็นคนตรวจ)

ผู้ใช้จับผิดเก่งมาก ทุกข้อในไฟล์นี้มาจากสิ่งที่ผู้ใช้เคยจับได้ หรือที่ตรวจเจอเองก่อนส่ง ทำตามลำดับ

## สารบัญ
1. ภาพนิ่งทุกช็อต
2. ตรวจเต็มขนาดทีละภาพ
3. เครื่องมือตรวจอัตโนมัติ
4. สตอรี่บอร์ด
5. เสียง

## 1. ภาพนิ่งทุกช็อต

```bash
python3 -c "import json;S=json.load(open('schedule.json'));print(' '.join(str(round(s['start']+s['dur']/2,2)) for s in S['shots']))" > snap_times.txt
node $K/snap.cjs <port> snap $(cat snap_times.txt)       # กลางทุกช็อต ต้องไม่มี PAGEERROR
python3 $K/sheet.py snap snap/sheet.jpg 6                  # ดูทั้งตอนในภาพเดียว
```
ดูภาพรวมก่อน:
- ขนาดภาพสลับกันจริง ไม่มีสองช็อตติดกันที่หน้าตาเหมือนกัน
- สีและแสงต่อเนื่องตามเวลาในเรื่อง (เช้า → บรรยากาศหลอน) · ไม่มีภาพดำหรือภาพว่าง
- ฉากที่ยังเป็นตัวแทน (stub) หมดแล้ว

แล้วถ่าย**จังหวะสำคัญ**เพิ่มของช็อตที่มีเหตุการณ์ (เวลากลางช็อตไม่พอ):
มือเอื้อมสุด · เข็มนาฬิกากำลังหมุน · น้ำขึ้นสุด (ราว 0.35–0.5 ของช็อต) · เส้นขาวตอนท้าย · ตัวเลือกตอนถูกดึง · 0.3 วิหลังประโยคที่พูดถึงของในภาพ

## 2. ตรวจเต็มขนาดทีละภาพ

ครอปหรือย่อ 3 ภาพต่อแถว (540×960) แล้วไล่ทีละข้อ:
- [ ] **ฮุก:** ภาพที่ 0 / 1 / 2 / 3 วิ เห็นของล่อใจตั้งแต่เฟรมแรก และคำสั่งขึ้นภายใน ~3 วิ (`hookcheck.py`)
- [ ] **สิ่งที่บทพูดถึงต้องเห็นในภาพ** ณ วินาทีที่พูด
  - "ห่วงยางผม!" → ห่วงยางต้องอยู่ในจอ (เคยวางไว้นอกจอ)
  - "แล้วคนก็เดินลงไปเก็บของ" → ต้องมีคนเดินลงบันได (เคยว่าง)
  - คลื่นแรก → น้ำท่วมรอบร้านต้องอ่านออก (เคยเล็กจนมองไม่เห็น ต้องดันกล้องเข้า)
- [ ] **ใครพูด:** คนพูดอยู่ในภาพหรือเดาได้ · ประโยคตัวละครอยู่ใน “ ” · **ประโยคผู้บรรยายไม่มี “ ”** (ช็อตที่มีทั้งสองแบบใช้ `[...caps(k, [0], { quote: true }), ...caps(k, [1])]`)
- [ ] **ซับไม่บังหน้าหรือของสำคัญ** (แถบ y 1480–1700) · ล่าง 220 px ไม่มีป้ายสำคัญ
- [ ] **การวางตัวละคร:** ยืนบนพื้นจริง ขนาดตามระยะ ไม่ยืนทับของที่ต้องอยู่หน้า (เคาน์เตอร์) หันหน้าหากันตอนคุย
- [ ] **หัวและผม** ครอปขยาย 3 เท่าทุกตัวละครใหม่ (V4) · มือถือของจริง
- [ ] **ความต่อเนื่อง:** ระดับน้ำ เส้นขาว ประตูเปิด ของที่หล่น เหมือนกันทุกช็อตหลังเหตุการณ์ (ทะเลลด: ทะเล .35 → 1.6 → 1.7 เส้นขาว 0 → .4 → 1)
- [ ] **กราฟิก:** ป้ายและชิปไม่ซ้อนกัน ข้อความอ่านออกที่ขนาดจอมือถือ ไอคอนครบทุกชิ้นตอนค้างจอ

แก้แล้วถ่ายใหม่เฉพาะช็อตที่แก้ ที่เวลาเดิม แล้ววางคู่ก่อน/หลังดู

## 3. เครื่องมือตรวจอัตโนมัติ

```bash
node $K/origin_check.cjs <port> body.part     # จุดหมุนทุกตัวอยู่บน element จริง (กันของพุ่งมาจากนอกจอ)

```

## 5. เสียง

- ทุกบรรทัดผ่าน `voice_qa.py` (CER ≤ 0.25) และคำสำคัญฟังเองหรือถอดความเทียบ
- หลังมิกซ์: −14 LUFS ±0.5 · พีก ≤ −1 dB · ไม่มีเสียงซ่า
- บรรทัดที่มีเสียงประกอบดังทับ: ตัดช่วงนั้นจาก `mix.wav` แล้วถอดความด้วย Whisper (faster-whisper รับ numpy array ได้)
  คำต้องยังครบ ถ้าหายให้ลด gain ของ SFX หรือขยับเวลาออกจากคำ

## 6. วิดีโอหลังเรนเดอร์

- `bash $K/qa_video.sh <HQ.mp4> mix.wav` → 1080×1920 · 60/1 · ความยาวภาพ = เสียง = mix (±0.05 วิ) · −14 LUFS
- เปิดแถบภาพ `<mp4>.qa.jpg` ดูจริง: ไม่มีเฟรมดำ ไม่มีช็อตผิดฉาก ไม่มีป้ายค้าง
