# คลังของที่สร้างแล้ว (ใช้ซ้ำได้ ก่อนสร้างใหม่ให้ดูที่นี่)

`setup_workspace.sh` ก๊อปทุกไฟล์ข้างล่างไปไว้ใน `hf/lib` แล้ว · ทุกไฟล์มีหัวไฟล์อธิบาย option และ id ครบ: อ่านแค่หัวไฟล์ก็ใช้ได้
(`head -60 hf/lib/<ไฟล์>`) · ฉากเก่าบางเรื่องเป็นงานรุ่นแรก ถ้าจะใช้ซ้ำให้ยกระดับตามกติกา V10 ก่อน

## ระบบหลัก

| ไฟล์ | มีอะไร |
|---|---|
| `engine.js` | `Engine` แปลงลิสต์ช็อตเป็น timeline: ฉาก กล้อง parallax นักแสดง ซับ ฟองคำพูด look (vignette grain) |
| `rig.js` + `rig2.js` | โครงตัวละคร (ท่า `MODES`, ตา `EYES`, ปาก `MOUTH`) + หน้าตาแบบวาดมีแสงเงา (rig2) |
| `fx.js` | เอฟเฟกต์จอ: หัวใจเต้น อุโมงค์สายตา แถบดำ glitch zoom punch ไฟกะพริบ |
| `grain.js` | ลายเกรนฟิล์ม · `hands.js` มือการ์ตูนสำหรับภาพใกล้ · `pov.js` มุมมองคนที่หนึ่ง (หายใจ กะพริบตา) |
| `sets.js` | `Sets` + gradient กลาง (ฉากบ้านผีรุ่นแรก) |
| `maps.js` + `mapsdata.js` | `Sets.mapTH` แผนที่ประเทศไทยจริง + `Maps.route` (เส้นทาง พาหนะ หมุด) · `Sets.mapVillage` หมู่บ้านมุมสูง |
| `opener.js` / `openers.js` | ฉากเปิด EP.1 แบบเก่า (ชื่อเรื่องบนฟ้า, ควัน, แสง, น้ำ) เรื่องใหม่ต้องคิดฉากเปิดของตัวเอง (S2) |
| `ui.js` `gameui.js` `mokui.js` `phraiui.js` | การ์ดรุ่นเก่า (ยังโหลดใน template ห้ามลบ) |
| `voice.py` / `voice_qa.py` | สร้างเสียง Gemini TTS ผ่าน fal.ai / ตรวจด้วย Whisper |
