# ภาพ: ภาษาภาพ แสง สัดส่วน ผี และ UI

โค้ดและ API ของทุกอย่างในไฟล์นี้อยู่ใน `engine-v2.md`

## สารบัญ
1. หน้าตาแบบมืออาชีพ (look)
2. ภาษากล้อง
3. สัดส่วนและการวางตัวละคร
4. ความถูกต้องของการเคลื่อนไหว

## 1. หน้าตาแบบมืออาชีพ (look)

- **ชั้นภาพ** sky / far / mid / set / act / fg ให้ความลึกด้วย parallax และเบลอแบบชัดตื้น
  - ภาพกว้าง `blur: { far: 2, fg: 8 }`
  - ภาพใกล้ `blur: { sky: 4, far: 6, mid: 4, set: 4, fg: 10 }`
- **แสงมีที่มาเสมอ:** ดวงอาทิตย์ จันทร์ ตะเกียง ไฟเตา จอมือถือ หรือหน้าปัดรถ
  - ตั้ง `light` ของช็อตให้มาจากทิศของแหล่งนั้น (preset ใน `engine-v2.md`)
  - rim light สีของแหล่งแสง เงาโทนเย็น/ม่วง ไม่ใช้เทาเปล่า
- **ความมืด `dark`:** ค่าเริ่มต้นของ engine คือ 0.35 ซึ่งทำให้ฉากกลางวันหม่นเทา **ตั้งเองทุกช็อต**
  - กลางวัน 0 · เย็น 0.05–0.1 · กลางคืน 0.06–0.22
- **เกรดสี:** grade top/bottom ตามเวลา (GDAY GDUSK GNIGHT GLATE GFIRE …) + vignette + grain ทุกช็อต
- **บรรยากาศ:** หมอกพื้น ฝุ่นในลำแสง หิ่งห้อย ไอน้ำ ฝน (`Pop2.particles`) ใส่ให้ทุกช็อตมีอะไรขยับ แต่ห้ามมีเสียงซ่าตาม
- **ฉากต้องมีรายละเอียดที่บอกว่าเป็นที่ไหน:**
  - บ้านใต้ถุนสูงมีบันได เปล ตุ่มน้ำ ฟืน
  - ครัวมีเตาอั้งโล่ หม้อแกง ตะเกียง
  - โรงพยาบาลมีเสาน้ำเกลือ จอ ECG ม่าน นาฬิกา
- **ขนาดใหญ่:** บ้าน/กระท่อมต้องใหญ่สมจริง (ผู้ใช้ขอ "บ้านหลังใหญ่ๆ" มา 2 ครั้ง)
- **มิติ (กฎ V10, ตึกโยก EP.1):** ทุกชิ้นมีด้านสว่าง ด้านเงา ขอบไฮไลต์ และเงาสัมผัส
  - ฉากต้องมีของพอให้เชื่อว่ามีคนอยู่ ตัวอย่างห้อง 2714:
    - หน้าต่าง: ระเบียงกับกระถาง ม่านผูกทับม่านโปร่ง
    - กลางห้อง: พรมขอบลาย และบนโต๊ะมีโทรศัพท์ สมุดการบ้าน สีเทียน ทิชชู แจกันดอกไม้
    - ครัว: กระเบื้อง ราวแขวน กาต้มน้ำ หม้อหุงข้าว
    - ตู้พระ: พวงมาลัย กระถางธูป แจกัน
  - ไอคอนเป็นเหรียญ 2.5D · แผนที่และแผนผังใช้กล้อง 3 มิติจริง · วิธีทำอยู่ใน `engine-v2.md` ข้อ 8

## 2. ภาษากล้อง

**เมนูช็อต** (ใช้ให้หลากหลาย ห้ามมุมเดียวทั้งตอน):

| ช็อต | ใช้เมื่อ | วิธีใน engine |
|---|---|---|
| establishing / extreme wide | เข้าฉากใหม่ทุกครั้ง | `fr(x, y, 0.6–0.9)` + `glide` เลื่อนช้าๆ |
| wide / medium | การกระทำ บทสนทนาหลายคน | `fr(…, 1.0–1.6)` |
| close-up | อารมณ์ ประโยคสำคัญ | `CU(x, y, s)` ซูม 2.0–2.6 |
| insert / macro | ของสำคัญ ความรู้ เบาะแส | ฉาก close-up เฉพาะ (`mushHero`, `feet2`) |
| top-down | ของบนโต๊ะ รอยเท้า หม้อ | ฉากมุมบน (`potTop`, `testsTop`, `printsTop`, `benchTop`) |
| มองผ่านช่อง/หน้าต่าง/กระจก | แอบดู ลุ้น | `gap2`, `cab2`, หน้าต่างใน `village2` |
| ข้ามไหล่ / มือถือ | ตัวละครดูอะไรบางอย่าง | `PopUI.phone({ mode: "camera" })` |
| ตำนาน | อธิบายผี | `legend2` (หนังตะลุง) |
| POV | จังหวะวิกฤตสั้นๆ เท่านั้น | กล้องสั่น + มือในเฟรม |

**กติกา**
- เข้าที่ใหม่ → establishing ก่อนเสมอ
- คุยกัน → สลับ medium/close
- ความรู้ → insert ของจริง
- ฉากน่ากลัว → กล้องนิ่ง แล้วตัดฉับ
- ตัดตามการกระทำหรือตามเสียง · กล้องเลื่อนต้องมีเหตุผล (ตามคน เผยของ ดันเข้าหาความน่ากลัว)
- ช็อตเดียวเปลี่ยนมุมได้ด้วย `split(k, at, A, B)` หรือ `cam.keys` หลายจุด (ตัดฉับ หรือ `glide` เลื่อน)

## 3. สัดส่วนและการวางตัวละคร

ตัวละคร rig ที่สเกล `c` สูง ~620·c หน่วย (ไม่รวมหมวก) = ผู้ใหญ่ 1.65 ม. → **1 เมตร ≈ 376·c หน่วย**
- จุดสำคัญของร่าง (เท้าอยู่ที่ y): หัวกลาง −500·c · คาง ~−430·c · ไหล่ ~−430·c · สะโพก ~−290·c
- เด็ก 8 ขวบใช้สเกลราว 0.72–0.77 ของผู้ใหญ่

| ของ | ขนาดจริง | หน่วยในฉาก (คูณ c) |
|---|---|---|
| ประตูบ้าน | สูง 2.0 ม. | 750 |
| เพดานห้อง | 2.6–2.8 ม. | ~1000 |
| ใต้ถุนบ้าน (คนเดินลอดได้) | 2.0–2.5 ม. | 750–940 |
| โต๊ะ / ที่นั่งเก้าอี้ | 0.75 / 0.45 ม. | 280 / 170 |
| ขั้นบันได สูง/ลึก | 0.18 / 0.25 ม. | 68 / 94 |
| ตุ่มน้ำ | 0.8–1.0 ม. | 300–375 |
| กระบะ (`Pop2.truck`) | ยาว 5.3 สูง 1.85 ล้อ Ø0.76 ม. | ใช้ `s ≈ 2.25·c` |
| รถเก๋ง | สูง 1.45 ม. (ราวไหล่คน) | 545 |
| มอเตอร์ไซค์ | ยาว 1.9 เบาะ 0.76 ม. | 715 / 285 |

**การวางตัวละคร** ถามตัวเองทุกช็อต: "ใคร อยู่ไหน ทำอะไร ถืออะไร ทำไม และช็อตก่อนหน้าอยู่ตรงไหน"
- **รถไทยพวงมาลัยขวา:**
  - รถหันหัวไปทางขวาของจอ = เห็นฝั่งคนขับ
  - คนขับอยู่ในรถ ที่นั่งขวา ไม่ใช่ยืนข้างรถ
  - มองจากหน้ารถเข้าไป คนขับอยู่ซ้ายของภาพ
- **คนนั่งท้ายกระบะ** เห็นแค่หัวกับไหล่พ้นขอบกระบะ · วาดขอบกระบะหรือประตูซ้ำทับนักแสดงใน `L.glow`
- **คนนั่งต้องมีของรองนั่ง** คนนอนต้องมีที่นอน · เท้าแตะพื้น · มือแตะของที่ใช้ (พวงมาลัย ประตู คนที่อุ้ม)
- **ของในมือ** อยู่ในมือหน้าเท่านั้น (`oneHand`) และต้องเป็นของที่บทหรือเรื่องต้องใช้
- **ห้ามมีตัวละครเดียวกันสองตัวในช็อต** (เงาคนขับ + คนเดียวกันยืนนอกรถ = ผิด)
- **ร่างต้องต่อกัน** หัว คอ ไหล่ แขน แม้เห็นแค่ครึ่งบน · ผีก็เช่นกัน (มือพรายต้องติดกับตัว)

## 4. ความถูกต้องของการเคลื่อนไหว

- นาฬิกา: หน้าปัดอยู่กับที่ หมุนแค่เข็ม (เข็มยาวเร็ว เข็มสั้นช้า) · หน้าปัดรถ: เข็มขยับ
- ทุกการหมุนหรือซูมของชิ้นส่วน หมุนรอบจุดของชิ้นนั้นเอง (ตรวจด้วย `scripts/origin_check.cjs`) ไม่พุ่งมาจากนอกจอ
- รถวิ่ง: เสาข้างทาง/ทุ่งเลื่อน (`drive()`) ตัวรถสั่นเล็กน้อย · ห้ามรถวิ่งแต่ถนนนิ่ง
- คนเดินตามพื้น บันได และทางจริง (`path`) ไม่ลอยเหนือขั้นบันได
- ไฟเปิด/ดับต้องต่อเนื่องทุกช็อตหลังเหตุการณ์ · ไฟดับแล้วแสงที่ตกกระทบในฉากต้องหายด้วย (ทั้งตะเกียงและแสงสะท้อน)
- รอยเท้า: แยกรอยซ้ายขวาสลับกัน มีนิ้ว ย่อตามระยะไกล (`Pop2.trail`) ไม่ใช่ก้อนต่อกันเป็นแท่ง

## 5. ผีและฉากน่ากลัว

- **รูปลักษณ์:** ตัวดำสนิท ตาเขียวเรือง (`Pop2.eyePair`, gradient `pbEye`) + จุดเด่นของตนนั้น 1–2 อย่าง (ผมยาว นิ้วยาว ตัวผอมงอ)
  - ออกแบบใหม่ทุกเรื่อง ห้ามยืมผีเรื่องอื่น ห้ามหน้าขาวตาโบ๋แบบหน้ากาก
- **โชว์ให้น้อย:** เงาไกลๆ ตาสองจุด เสียง ร่องรอย · ไม่โชว์ผีเต็มตัวสว่างค้างนาน
- **เผยตัวด้วยไฟดับ:** ไฟในบ้านกะพริบ 2–3 ครั้ง (`tl.set` เปลี่ยน opacity เป็นจังหวะ ไม่ fade) → หน้าต่างดำสนิท → ตาค่อยๆ สว่าง → กะพริบตาหนึ่งที
  - ใช้ใน เห็ดปอบ EP.3 ช็อต `last`: `#v20-lamps` `#v20-panes` `#v20-eyes`
- **จัมป์สแกร์ (สูตรกองกอย EP.3):** มืดเกือบทั้งจอ ผีนิ่ง 2–4 วิ (เสียงหัวใจช้า ดนตรีเงียบ) → ตาดับ เงียบ 0.3–0.6 วิ → หน้า/มือพุ่งประชิดเลนส์ 0.15–0.25 วิ + sting → ตัดดำทันที
  - glitch/flash/punch ใช้ครั้งเดียวตอนตูม
- **ภาพผ่านกล้องมือถือ** เป็นสีปกติ ไม่ใช่เขียวทั้งจอ

## 6. UI ไอคอน ซับ

- **ไอคอน:**
  - วัตถุหลักชิ้นเดียว เส้นหมึกหนา 3–4 สีแบน 3–4 สี อยู่ในวงกลม (กล่อง 100–120 หน่วย)
  - เครื่องหมายสำคัญ (วงห้ามแดง ลูกศร ตัวเลข) อยู่ครบ 100% ตอนจบแอนิเมชัน
  - ก่อนเรนเดอร์ครอปการ์ดเฟรมท้ายมาดูที่ขนาดจริงทุกครั้ง
- **มาตรฐาน motion graphics** (ผู้ใช้ชมว่า "ดีมาก เฟี้ยว" 28 ต.ค. 2026 · โค้ด `video/mm/lib/mmui.js`):
  - หน้าตา: เส้นหมึก 4–5 · สีแบน + เงา 1 ชั้น + ไฮไลต์ 1 ชั้น · เงาตกนุ่ม · ป้ายเม็ดยา (pill) สีบอกความหมาย (เขียว = ปกติ/ถูก, แดง = อันตราย)
  - ไอคอนอยู่ในวงกลม ตัดภาพด้วย clipPath ห้ามแขนหรือของยื่นออกนอกวง · ใช้ท่ามาตรฐานของสัญลักษณ์ (มุมข้างของคนนอน มือตรงลงกลางอก)
  - การเคลื่อนไหว: เข้าด้วย back.out / elastic.out / bounce.out · ไล่ทีละชิ้นห่าง 0.12–0.15 วิ · หลังเข้าต้องมีการเคลื่อนไหวรองวนไปจนจบช็อต
  - กลไกความรู้ซิงก์กัน: หัวใจบีบตรงยอด R ของ ECG · หัวกวาดของจอวิ่งตามเส้นจริง · ตรายางกระแทกพร้อมกระดาษสะเทือน
  - ตรวจไอคอนที่ขนาด 3 เท่าก่อนส่ง (เคยเจอ: หน้าอกในไอคอน CPR ดูเหมือนก้น, คนชักแต่ยิ้ม)
- **การ์ด/กราฟิก** วาดด้วยลายมือหรือของพิมพ์ในโลกของเรื่อง (สมุดยายคำ กระดานหมอ ภาพพลิก อสม. บัตรห้อยคอ ป้ายกระดาษปักดิน) ไม่ใช่กล่องแอปทั่วไป
  - UI ขึ้นเฉพาะสิ่งที่บทพูด และต้องเล่นตามที่พูด
- **ฟอนต์:** Kanit = ซับ/UI · Mali = ลายมือบนการ์ดและกระดาน · Sriracha = คำเสียง (ปัง! เอี๊ยด!)
- **ซับ:**
  - กล่องเข้มอยู่ราว y 1480–1700 ห้ามบังหน้าตัวละครหรือของสำคัญ (ถ้าบัง ให้เลื่อนกล้อง ไม่ใช่เลื่อนซับ)
  - คำพูดตัวละครใส่ “ ” (`caps(k, undefined, { quote: true })`)
- **ชิปที่มา** อยู่ล่างสุดราว y 1810 ข้อความสั้น "ที่มา: หน่วยงาน (วันที่)"
- **ขอบจอ:** ห้ามมีป้าย ปุ่ม ซับ หรือการ์ดหลุดขอบ (ตรวจด้วย `scripts/edgecheck.cjs`)
