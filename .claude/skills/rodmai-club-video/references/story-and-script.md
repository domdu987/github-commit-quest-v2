## 1. เลือกเรื่องใหม่

**เรื่องที่ดีของช่อง = ตำนานผีไทยที่เป็น "อุปมา" ของอันตรายจริง** คนดูจะจำความรู้ได้เพราะผีทำแบบเดียวกับอันตราย:

| เรื่อง | ผี | อันตรายจริง | ทำไมเข้ากัน |
|---|---|---|---|
| เห็ดปอบ | ปอบ (กินตับไตไส้พุง) | เห็ดระโงกหิน (amatoxin ทำลายตับ) | พิษกินตับจากข้างใน เหมือนปอบ |
| เต็นท์ผีอำ | ผีอำ (ทับอก ขยับไม่ได้) | CO จากเตาถ่านในเต็นท์ | อาการขาดออกซิเจนเหมือนโดนผีอำ |
| แสงกระสือ | กระสือ (แสงลอยกลางคืน) | ไฟฟ้ารั่วตอนน้ำท่วม | แสงที่ห้ามเข้าใกล้ |
| มือพราย | พราย (ดึงคนลงน้ำ) | จมน้ำ / ช่วยคนจมน้ำผิดวิธี | น้ำดึงคนลง |
| เสียงกอย | กองกอย (ขาเดียว เลือดนิ้วเท้า) | ทาก น้ำป่า เที่ยวป่า | สูตรหลักของช่อง |

เกณฑ์เลือก (ต้องผ่านทุกข้อ):
- อันตรายเกิดได้จริงกับคนไทยทั่วไป มีข่าว/สถิติ และมี **คำแนะนำทางการที่ช่วยชีวิตได้** อย่างน้อย 3 ข้อ (ตอนละข้อ)
- ความรู้มี "ความเชื่อผิดๆ" ให้หักล้าง (เช่น ต้มกับข้าวสารแล้วรู้ว่าเห็ดพิษ) เพราะเป็นจุดหักที่ดีที่สุด
- มีอาการหรือผลที่ "มาทีหลัง" ให้ทำปมค้างข้ามตอน
- ผีไทยตนนั้นยังไม่ถูกใช้ในช่อง และอธิบายลักษณะได้ใน 2–3 ประโยค
- ไม่ใช่สงคราม ไวรัส ไซไฟ (หลุดสูตร ผู้ใช้สั่งพักเรื่องทหาร)

เรื่องที่ทำแล้ว (ห้ามซ้ำ): ค่ายคืนสุดท้าย, เสียงกอย (กองกอย), ชั้น 23 (ซอมบี้), หมอกลง (หมอก/ขับรถ), ควันหลง (ไฟไหม้หอ),
มือพราย (จมน้ำ), แสงกระสือ (น้ำท่วม/ไฟฟ้า), เห็ดปอบ (เห็ดพิษ), เต็นท์ผีอำ (CO), ผีแม่ม่าย (หัวใจหยุดตอนหลับ CPR/AED),
ตึกโยก (แผ่นดินไหวในคอนโด ไม่มีผี EP.1), ทะเลลด (สึนามิ ไม่มีผี กำลังทำ EP.1) · พักไว้: ไข้ศึก (ทหาร), รั้วสุดท้าย (ซอมบี้ 20 ตอน)
สถานะล่าสุดอยู่ใน `video/STATUS.md`
ดูรายการเต็มใน `video/HANDOFF.md` หัวข้อ 8

ถ้าผู้ใช้ให้เลือกเอง: เลือกตัวที่ผ่านเกณฑ์ดีที่สุด แล้วบอกเหตุผลสั้นๆ พร้อมตัวสำรอง 1–2 ตัวในข้อความเดียว (ไม่ต้องหยุดรอ)
ถ้าผู้ใช้ยังไม่ได้ให้เลือก: เสนอ 2–3 ตัวด้วย AskUserQuestion พร้อมตัวที่แนะนำ

## 2. ยืนยันความรู้

- แหล่งภัยพิบัติ (ตึกโยก ทะเลลด): ปภ., กรมอุตุนิยมวิทยา, กรมทรัพยากรธรณี, NOAA, UNESCO-IOC, USGS, ข่าวที่อ้างหน่วยงานโดยตรง (Thai PBS)
- แหล่งที่ใช้ได้: กรมควบคุมโรค (ddc.moph.go.th) และ สคร. เขต, กรมอนามัย, กรมการแพทย์, สถาบันการแพทย์ฉุกเฉินแห่งชาติ (1669),
  ศูนย์พิษวิทยารามาธิบดี (1367), สภากาชาดไทย/สถานเสาวภา, ราชวิทยาลัยแพทย์, WHO, CDC, ราชบัณฑิตยสภา (ความหมายของผี)
- วิธี: ค้นด้วย WebSearch แล้วให้ agent `web-fetch` อ่านหน้าเว็บและคัดข้อความ **ตรงตัว** (ห้ามสรุปจากความจำ)
  curl ตรงบางเว็บโดนบล็อก
- เก็บใน ARC.md: `S1 — URL (วันที่ของหน้า)` แล้ว quote ภาษาไทยตรงตัว · ทุกบรรทัดความรู้ในบทต้องชี้ไปที่ quote ได้
- ขัดกันระหว่างแหล่ง (เช่น ทำให้อาเจียนไหม): ใช้ข้อที่ปลอดภัยกว่าและล่าสุด จดเหตุผลไว้ใน ARC.md
- ข้อที่ยืนยันไม่ได้ **ตัดทิ้ง** แม้จะฟังดี

## 3. ARC.md (ต้นแบบล่าสุด: `video/tide/ARC.md` มีตาราง S13 + S14 + ตัวละคร + แหล่งอ้างอิงครบ)

```
# <ชื่อเรื่อง> — ARC
## แนวคิด: ผี <X> = อุปมาของ <อันตรายจริง> (1 ย่อหน้า)
## แหล่งอ้างอิง (S1…Sn: URL, วันที่, quote ตรงตัว)
## ตัวละคร (ชื่อ อายุ นิสัย มุก เสียง Gemini, หน้าตา/สีเสื้อผ้าที่จำง่าย)
## ผี (ลักษณะ 2–3 ประโยคสำหรับ EP.1, รูปลักษณ์: ตัวดำ ตาเขียว + จุดเด่นของตนนั้น)
## กฎของ <ผู้ใหญ่> (3 ท่อนคล้องจอง ตอนละข้อ)
## เบาะแสข้ามตอน (วางที่ไหน เฉลยที่ไหน)
## EP.1 / EP.2 / EP.3: ชื่อตอน, ความรู้ (อ้าง S#), beat ทีละช็อต, ปมค้าง, ตัวเลือก, การ์ดท้าย
```

## 4. โครงของแต่ละตอน (~1:50)

| เวลา | beat | หมายเหตุ |
|---|---|---|
| 0–3.5 วิ | **hook** "ถ้าวันหนึ่ง… คุณ…" + คำสั่งสวนสัญชาตญาณ (กติกา H) | EP.1 = ฉากเปิดชื่อเรื่องของเรื่องนั้น · EP.2–3 = ภาพต่อจากท้ายตอนก่อน |
| 5–20 | ตัวละคร + มุก + สถานการณ์ปกติที่ซ่อนภัย | ภัยที่คนดูเห็นก่อนตัวละคร |
| 20–40 | ความรู้ 1 (ภาพในโลกเรื่อง + ชิปที่มา) | เหตุ → ผล + ตัวเลข |
| 40–55 | หักมุม ("แต่…") ปัญหาใหม่ | EP.1: ตำนานผีแบบหนังตะลุง |
| 55–75 | ความรู้ 2 + **การ์ดกฎของตอน** | การ์ดขึ้นตอนตัวละครทำตามกฎ |
| 75–95 | สัญญาณผี (เสียง เงา ตา) → จุดลุ้นสุด | ผีโชว์น้อยที่สุด |
| 95–110 | ปมค้าง (หลักฐานในภาพ) + ประโยคปิด 2 ท่อน | ตอนจบ: เฉลยด้วยเบาะแสที่วางไว้ |
| 110–118 | ตัวเลือกที่ถูกดึง → ตัดดำ → การ์ดท้าย ~2 วิ | ตอนจบ: ไม่มีตัวเลือก การ์ด "ตอนจบ" |

ช็อตเฉลี่ย 3–4 วิ (~30 ช็อต/ตอน) · ช็อตแอ็คชั่นไม่มีเสียงพูด 1.4–2.4 วิ · บทตัวละครราว 35–40% (กติกา S3; ตัวเลข 30% ใน RETENTION.md เก่ากว่า ให้ใช้ S3)

**EP.2 ขึ้นไป** (ต่างจาก EP.1):
- เปิดที่ภาพค้างของตอนก่อน (ยังเป็นฮุกตามกติกา H) ไม่มีฉากชื่อเรื่อง
- ทวนเรื่องในประโยคเดียวผ่านปากตัวละครหรือผู้บรรยาย และเรียกชื่อตัวละครในบทช่วงแรก ให้คนที่เริ่มดูจากตอนนี้ตามทัน
- การ์ดกฎ: ข้อที่ผ่านติ๊กถูก ข้อของตอนนี้ไฮไลต์ (S4)
- ตอนสุดท้ายเฉลยเบาะแสที่วางไว้ทุกตอน ไม่มีตัวเลือก จบด้วยการ์ด "ตอนจบ"
- งานที่ผู้ใช้สั่งแค่ "วางแผน" เก็บเป็น `video/<เรื่อง>/epN/PLAN.md` แล้วส่งสรุปให้ผู้ใช้ก่อนอัดเสียง
- ประมาณความยาวก่อนอัด: ผู้บรรยาย tempo 1.2 ราว 0.2–0.25 วิต่อพยางค์ (ทะเลลด n01 11 พยางค์ = 2.6 วิ)

## 5. เขียนบท `lines.json`

```json
[{"id": "n01", "text": "ถ้าวันหนึ่ง… คุณเจอเห็ดขาวสวยในป่า", "voice": "Puck", "style": "<style ผู้บรรยาย>", "tempo": 1.2,
  "cap": "ถ้าวันหนึ่ง… / คุณเจอ[เห็ดขาวสวย]ในป่า", "frags": [0, 1.2]}]
```
- `id`: ผู้บรรยาย `n01…` ตัวละครใช้อักษรตัวแรกของชื่อ (`m01` มิ้นท์) ถ้าชนกันให้ใช้อักษรอื่นแล้วจดใน ARC (ทะเลลด: `j` จูน `t` ตังค์ `y` ยาย `c` ตาจุ่น `x` คนอื่น) · `cap` แตกท่อนด้วย ` / ` ใส่ `[เหลือง]` `{แดง}` · `frags` (วินาทีเริ่มของแต่ละท่อน) ใส่เมื่อซับตัดผิดท่อน
- ประโยค 2–5 คำ ท่อนแรกต้อง "ค้าง" · ผู้บรรยายพูดกับ "คุณ" · บทตัวละครราว 40% มีมุกแบบคนจริง
- ก่อนสร้างเสียงไล่ checklist ใน `video/RETENTION.md` หัวข้อ 5 ให้ผ่านทุกข้อ
- TTS ปฏิเสธ (422) บ่อยเมื่อขึ้นต้นด้วย "แต่…/และ…" + จุดไข่ปลา → เปลี่ยนถ้อยคำ

## 6. การ์ดกฎ ตำนานผี ตัวเลือกท้าย การ์ดท้าย

- **กฎ 3 ข้อคล้องจอง** เช่น "เห็ดไม่รู้จัก อย่าหักใส่ข้อง / กินแล้วเมา เอาเห็ดไปหาหมอ / ท้องหายปวด อย่าอวดว่าหาย"
  - แต่ละข้อมีไอคอนเฉพาะ ขีดเส้นใต้คำคล้องจอง
  - ใน v2 ใช้ `PopUI.rule(tl, L.light, t0, dur, { active, done, y, s, out })` (การ์ดสมุดของยายคำ) เรื่องใหม่ให้ออกแบบการ์ดใหม่ตามโลกของเรื่อง (กระดาษ ป้าย ใบสั่งยา ฯลฯ)
  - ขึ้นทุกตอน: `active` = ข้อของตอนนั้น, `done` = ข้อก่อนหน้า, ข้อที่เหลือจาง
- **ตำนานผี (EP.1)** ใช้ฉากจอหนังตะลุง (`Sets.legend2` ใน v2) ผู้บรรยาย 2–3 ประโยค: รูปร่าง/สี/จุดเด่น + วิธีล่อ + วิธีทำร้าย
- **ตัวเลือกท้าย (EP.1–2)** `PopUI.choice({ q, a, b, secs, possessed: { at, side, glitch, who } })`
  - วางคำที่จะถูกดึงไว้ฝั่ง a
  - ช่องตัวเลือกถูก "สิง" กระตุก ตัวหนังสือเพี้ยน แล้วตัดดำทันที
- **การ์ดท้าย** = ของในโลกของเรื่อง (ป้ายป่าชุมชน + กระดาษโน้ตในเห็ดปอบ: `Sets.sign2`) บอก "ตอนที่ N + ชื่อตอน" หรือ "ตอนจบ"
  - ห้ามเป็นตัวหนังสือบนพื้นดำ และห้ามหน้าตาเหมือนคลิปต้นแบบ
