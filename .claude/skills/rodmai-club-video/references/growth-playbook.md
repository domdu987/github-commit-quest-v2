## 1. ทำไมเขาโตเร็วกว่าเรา (เรียงตามน้ำหนัก)

4. **เปิดตัวด้วยเรื่องที่พิสูจน์แล้วว่าไวรัล** (ดัดแปลงโดยได้รับอนุญาต) แล้วโพสต์ตอนต่อทันที

- เขาใช้เครื่องมือชุดเดียวกับเรา (Claude Code + HyperFrames + หุ่น SVG + HUD) จึงชนะที่ความสวยหรือเครื่องมือไม่ได้ ต้องชนะที่เรื่อง ความถี่ และความน่าเชื่อถือ

## 6. ผลิตให้ทันความถี่ (ปรับ pipeline ของเรา)
- **เอาแค่สูตร ห้ามลดคุณภาพภาพ** (ผู้ใช้สั่ง 31 ต.ค.: "ผมให้เอาแค่สูตรมา ไม่ใช่ทำภาพกากลง") · มาตรฐานภาพเท่ากับทะเลลดหรือดีกว่า
  - มือต้องเป็นมือจริง (ฝ่ามือ นิ้วสองข้อ เล็บ รอยพับ นิ้วโป้ง แขนงอข้อศอกได้) ใช้ `handBack` / `arm` / `handAt` ใน `video/sink/ep1/hands.part` · ห้ามวงกลมหรือแท่งยาวแทนมือ
  - คนนั่ง (ในรถ บนเก้าอี้) ต้องดูนั่งจริง: หุ่นในคลังเป็นท่ายืน ให้บังช่วงล่างด้วยเบาะ คอนโซล แดชบอร์ด พวงมาลัย แล้ววาดแขนเอง (จับพวงมาลัย เกาะเบาะ) ห้ามเห็นขายืน
  - ตรวจภาพนิ่งทุกช็อตแบบซูมเต็มก่อนเรนเดอร์ ไม่ใช่ดูแค่แผ่นรวมย่อ
- ผู้บรรยายเป็นหลัก: เสียงน้อยบรรทัด ตรวจเร็ว · ราว 15 ช็อต ช็อตละ 3–6 วิ (การ์ดและ HUD ใช้เสริมช็อตที่มีการกระทำจริง ไม่ใช่แทนฉาก)
- ใช้ฉาก ตัวละคร และ HUD เดิมซ้ำทั้งซีรีส์ · หน้าตาช่องต้องเหมือนกันทุกคลิป
- ตรวจแบบเร็ว: แผ่นรวมย่อ + `hookcheck.py` + Whisper เฉพาะบรรทัดที่มีเสียงประกอบดังทับ
- ไม่แตก fork (playbook ข้อ 10) · ทำ 3 ตอนของซีรีส์ในรอบเดียวแล้วเรนเดอร์ต่อกัน
