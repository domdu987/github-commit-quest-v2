# v2: pure 2D pipeline for the reference look (procedural SVG, Chromium raster)

Everything on screen is SVG generated by Python 3 (standard library only) and rasterised by headless Chromium through
Playwright. No 3D, no downloaded assets. numpy, Pillow and cv2 are used only by the measuring tools in `tools/`.
ffmpeg does the three things that happen outside the browser: scaling the supersampled frames, mixing dissolves, encoding.

    ./make.sh              # rebuilds everything for shots/s01.py (about 2 minutes): out/proto_v2.mp4 and the review files
    DRAFT=1 ./make.sh      # the same at deviceScaleFactor 1 (about 1 minute)
    tools/draft.sh         # frames only, no captions, with the staging checks (about 40 s): the review loop

## 1. How a frame is made

    shots/s01.py   keyframes  ->  frame spec (dict)        what is where on output frame g: set state, camera, actors
    compositor.py  scene(spec) -> one SVG document 720x1280  set layers + puppets + light + effects under one camera
    build.py       every frame of every shot -> out/svg/<shot>_<gggg>.svg, out/manifest.json, out/caps.json, out/qa.json
    render.js      one persistent Chromium page; each SVG replaces the stage content; screenshot -> out/raw/
    post.py        ffmpeg: bilinear 2x downscale, smoothstep mix of the dissolve frames -> out/frames/f_0001.png ...
                   (nothing is drawn outside the browser)
    assemble.py    (existing tool in the project folder, unchanged) burns the captions last and encodes H.264

World convention (shared with `puppet/` and `sets/`): unit D = head diameter, x right, y DOWN, floor contact line y = 0,
x = 0 = centre of the wall map. A camera is (cx, cy, zoom px per D[, roll]): `screen = (world - (cx, cy)) * zoom + (360, 640)`.

### compositor.py
`scene(spec, with_info=False)` returns the SVG (and, with `with_info`, the solved world and screen anchors of every actor).
The spec keys are documented at the top of the file. What it does, bottom layer to top:

1. set layers `bg`, `mid` from `sets/office.py` (`build` or `build_insert_map`) under the camera, each with its parallax;
2. the part of the set's light layer below world y = -4.2 (window shaft, dust), screen-blended onto the set only;
3. contact shadows, then the actors back to front (sorted by floor y). Each actor has a world floor position, a scale
   (1 at the wall; a figure nearer the lens is larger and stands lower on the floor perspective) and optional world-space
   hand targets: `hands={"r": {"tip": (wx, wy), "prop": "pencil", "angle": -60}}`. The compositor converts the target into
   the puppet's local frame (scale, squash and the puppet's own mirror included), solves the arm, and plants the feet with
   the puppet's `feet_y`. `place={"anchor": "shoulder_r", "at": (wx, wy)}` pins another anchor instead (insert shots);
4. the `fg` set layer (parallax 1.12), then actors with `layer="front"`;
5. the part of the light layer above the split (the pendant-lamp halos): the bloom of real emitters lies over set and
   actors; the window shaft does not, so it cannot wash out the ink of a puppet and no head glows;
6. speed lines (`focus`) and any `overlay`.

Blur is applied to the set groups only, never to actors:
- `bg_blur`: Gaussian defocus in px for a tight close-up (reference 3.6 to 7 px);
- motion blur, automatic from `cam_prev -> cam`: it fades in between 34 and 46 px of plate travel per frame. A pan gets a
  directional Gaussian along the motion (sigma = 0.75 x travel / sqrt 12); a zoom gets 3 or 4 averaged sub-frames plus a
  small Gaussian that fuses them.

All ids are prefixed (set `of` / `ofi`, each actor its `uid`, compositor filters `cmb_`, `cbb_`, `clp_`), so nothing collides.

### shots/anim.py and shots/s01.py
`anim.py` holds the timing helpers: `ease` (sine, quint, cubic_out, back_out ...), `keys` (piecewise eased keyframes),
`cam_keys` (centre linear, zoom geometric), `blink` (three one-frame drawings: half, closed, half), `swap`, `pulse`.
A shot file defines, in OUTPUT frame numbers g:
- `SHOTS`: name, `out_start`, `out_end`, `head` / `tail` handle frames (rendered beyond the range for transitions);
- `SHOT_FN[name](g) -> spec` and `CAM_FN[name](g) -> camera` (the camera function is also called for g - 1: motion blur);
- `TRANSITIONS`: `{"kind": "dissolve", "a", "b", "first", "frames"}` (mixed in post.py with P*P*(3-2P), P = i / (n + 1))
  or `{"kind": "whip", ...}` (a hard cut that both cameras cover with a blurred pan; nothing to mix);
- `source_of(g)`: which raw frame(s) make output frame g; `CAPS`: (t0, t1, text) phrases; `FPS`, `N_FRAMES`.

### render.js
`node render.js out/manifest.json [--dsf 1|2] [--jpg] [--quality 98] [--only s02]`. One browser, one page, fonts awaited
(`document.fonts.ready`, the set's lettering is system DejaVu Serif Bold), no timers and no randomness. Final frames use
deviceScaleFactor 2 with JPEG q98 intermediates and a bilinear downscale: measured edge softness 1.61 px against
1.48 to 1.86 px in the reference (deviceScaleFactor 1: 1.34 px, too crisp). See `out/METRICS.md` section 3.
Measured: 0.15 to 0.21 s per frame at dsf 1. At dsf 2 an ordinary frame takes 0.41 s (two-shot) to 0.48 s (insert); the
22 raw frames with the zoom blur (3 or 4 sub-frames) take about 1.8 s each, so the whole film averaged 0.67 s per frame
on the shared machine. `DRAFT=1` renders at dsf 1 and post.py then softens with a 0.45 px Gaussian (same measured edge
softness, 1.59 px), which is the fast way to stay under 0.5 s per frame; supersampling is kept for the final because it
also anti-aliases the thin map lines under the moving camera.

### Captions
`out/caps.json` holds the phrases. `out/caps_burn.json` is the same list with the libass size override `{\fs70}` in front
of each phrase, and that file is what make.sh hands to the unchanged `assemble.py`: the tool asks for "Fontsize 50", which
libass measures on the font's line box, so the plain file renders Work Sans Black at 0.71 of the reference width
("The whole court": 280 px against 396 px in b/t05.5; with the override 393 px).

## 2. How to add a new shot

1. Copy `shots/s01.py` to `shots/s02.py` (or add to the same file). Give the shot a name, `out_start`, `out_end`, and
   handles: `tail=5` on the outgoing side and `head=5` on the incoming side of an 11-frame dissolve; none for a cut.
2. Write the camera function with `cam_keys`: one eased key pair for the drift (6 to 10 percent per second, never
   linear, already moving on the first frame), one optional snap of 14 to 24 frames (x1.4 to x3, "sine" or "quint"),
   velocity near zero 12 frames before the end. Start from the set's anchors: `office.build()["anchors"]` has
   `cam_wide`, `cam_two_shot`, `cam_medium_hero`, `map_ny`, `hero_mark`, `boss_mark`, the ledge props and so on.
3. Write the shot function: `state` (`line`, `erase`, `t = g / 30`), the camera, and the actors. Pose numbers come from
   `keys(g, [...])`; faces are discrete (`expr`), so change them on the closed frame of a `blink(g, [start])`. Put a
   prop on a world point with `hands`; stage in depth with `y` (floor) and `scale` (near figure about 1.4 x the far one).
   Keep the acting figure travelling 0.15 to 0.34 D and the other under 0.04 D; no mouth shapes unless quoted.
4. Add the transition to `TRANSITIONS` and the phrases to `CAPS` (1 to 3 words, 0.2 to 0.6 s, no gaps).
5. `SHOTS=shots/s02.py tools/draft.sh` (or edit the default in `build.py`), read the printed checks (pencil and eraser
   registration, head sizes and heights, whole heads above y = 880, static frames, snap list, blur frames), look at
   `python3 tools/sheet.py frames out/frames tmp/sheet.jpg 0-149:3 9 177`, fix, repeat. `python3 tools/pop_check.py`
   lists one-frame jumps. Then `./make.sh`.

A new set needs only a module with the same shape as `sets/office.py` (`build(state, uid)` returning `layers`, `defs`,
`anchors`) and one line in `compositor.build_set`. A new character is a new entry in `puppet.CAST`.

## 4. Deliberate deviations from spec/LOOK_SPEC.md

- The plate is the code-drawn SVG office (the way clip B uses illustrated plates), not a Blender render; puppets are
  live SVG over it in the same document, so there is no depth matte: occlusion is the layer order (`mid` or `front`).
- No per-shot character tint in the day office (the spec's interior-day head value is the untinted `#fef7f6`).
- The light layer is split at world y = -4.2 (see 1, steps 2 and 5).
- The caption size override described above.
