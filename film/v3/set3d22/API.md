# set3d22 full set API (builder A part; B appends its own section)
See `FULL_SET_BRIEF.md`. 1 unit = 1 D (head), Z up. One location per process: `beck.build(location, light, shot)`.

## Registry (beck.py, builder A)
- Each module exports `SHOTS = {'sNN': {...}}` and `LOCATIONS = {'name': {...}}`. `beck.ALL_SHOTS` / `beck.ALL_LOCATIONS` lazily merge the 4 modules (beck_london, beck_hq, beck_under, beck_map); a module that is missing or fails to import is skipped (`beck.ALL_SHOTS.errors`).
- `LOCATIONS['name'] = dict(build=fn(scene, P), light='LODGINGS' (a key of beck.LIGHTS; london also takes DUSK / NIGHT aliases), sky=False|True, cam=dict(loc, look_at, lens))`. Your builder uses `beck.STATE['C'|'TX'|'E'|'CARD']`, `beck.Part`, `beck.plane`, etc. exactly as beck.build_platform does. Light presets (`beck.LIGHTS`) can be added by you at import time: `beck.LIGHTS['PLATFORM_EVE'] = dict(beck.LIGHTS['PLATFORM'], ...)`.
- `SHOTS['sNN'] = dict(location='name', light='KEY', f0=<first film frame>, f1=<last+1>, cam=[(frame_local, (x,y,z) loc, (x,y,z) look_at, lens[, roll_deg]), ...] (Hermite through the keys, end speed continues in the 6 handle frames), marks={'beck': (x,y,z,yaw_deg), ...}, state={'setter_name': value}, animate={'setter_name': fn(local_frame, n)}, shift_y=0.0)`.
- Setters: `beck.SETTERS[name] = fn(value)` (decorator `@beck.setter('name')`). Shot `state` applies them at build time; `animate` fns are called per frame by `beck.render_frame`.
- `beck.key_camera('sNN', f0)` keys the camera (one key per frame, handles 6). `beck.build(loc, light, 'sNN', quality, frame)` builds + positions at `frame` (default f0). `python3 beck.py shot sNN start|mid|end|<frame> [preview] [out.png]`.
- Ownership: beck.py and beck_tex.py are builder A's (B: put new painters/helpers in your own modules; B textures should go in your own painter module, cache `tex_beck/`).
