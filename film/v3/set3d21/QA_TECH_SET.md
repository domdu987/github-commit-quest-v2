Inputs: contact.jpg (15 tiles cropped at 720x1280, tile origin x=(i%5)*730, y=(i//5)*1338), hue.md, API.md, per-tile JSON, shot_plan.md.
Pixel positions are in tile coordinates (720x1280). Cyan line = y 880.

## Script and render checks
- `python3 t_hooks.py`: `ok 21 bad []`, 4.2 s wall (one harmless warning "CUEW initialization failed", no GPU). PASS.
- Draft render, documented CLI: `python3 stirling.py render bridge_deck <out.png> draft` -> `bridge_deck 11.2s build 3.5s tris 497985`, wall 15.9 s, no error, 360x640 PNG + .json written. PASS.
- The command as given in the QA brief, `render bridge_deck - <out.png> draft`, does NOT work from the docs: `-` is taken as the output path and the real path as `mode`, so it silently runs a 720x1280 FINAL render (over 120 s, killed by me, no output). See issue 20.
