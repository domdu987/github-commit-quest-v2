# set3d20: the 3D set of film 20 ("ไอ้ช่างหมุด", Eiffel's tower and the artists' protest, Paris 1887-1910)

Files: `set3d20.py` (PUBLIC API, dispatch), `core20.py` (shared helpers, contract below), `kit20.py` (tower lattice by height slices, scaffolds, creeper cranes, props, Paris backdrop), `site20.py` (SITE), `tower20.py` (TOWER), `int20.py` (CAFE + RESTO, other builder, `API_int.md`), `make_contact.py`, `hue20.py` (cast-shadow hue), `contact.jpg` / `contact_small.jpg`, `hue_report.txt`, `cost_report.txt`, `work/final/*.png|json` (tiles).
Grown from the QA-approved board `styleboard/sb.py` (tower() profile, haus / city_ring / trocadero / seine / bridge, materials). Bpy 5.3, Cycles CPU, 8 spp + OIDN, direct light + sky ambient (no diffuse bounce outdoors), **no depth of field, no text anywhere**.

## Use
```python
import sys; sys.path.insert(0, 'film/v3/set3d20'); import set3d20 as S, bpy
A = S.build('tower_dusk', light='NIGHT')          # one location per process; light optional; 'cafe_*' / 'resto_*' go to int20
S.setup_render(S.scene(), 'final')                 # 720x1280 ('preview' 360x640)
cam = S.make_camera(A['cams'][A['cam_name']])      # start pose (22 mm, shift_y where noted); every named camera of the preset is in A['cams']
S.stage_placeholders(A, A['cam_name'])             # cast20 stand-in cards at the marks (contact sheet / tests)
S.set_stage(2, frame=40) ; S.spark_gap(True, frame=40) ...   # hooks key when frame=n is given
wall, cpu = S.render('/tmp/x.png');  S.project(world_pt); S.head_pixels(cam_name); S.clear_keys()
```
`A = {'preset','light','loc','cam_name','cam','cams','marks','marks_m','staging','hooks'}`: `A['marks'][name] = (x, y, ground_z)` world D, `A['marks_m']` the same in metres; `A['hooks']` maps hook names to callables. CLI: `python3 set3d20.py stills|final [preset[:LIGHT] ...]` (output `work/stills|final`).
Build time is 15-45 s (once per process); render at final 720x1280 is the number in cost_report.txt.

## Scale (important)
**1 world unit = 1 D = head. Adult puppets 3.2 D = 1.7 m, so 1 metre = 1.88 D (`core20.SC`)**; the tower is authored in metres (300 m = 564 D tall, base 125 m = 235 D square, first platform 57 m = 107 D, second 115 m = 216 D, spire top 300 m). Props are real size except where noted (SITE wide cameras enlarge hand props x1.6-2.4, `site20.PROP_SCALE`, so the yard reads at phone size; close cameras use x1.0). Marks are standing points in world D; `A['marks_m']` in metres.

**Foreground:** every SITE camera has 2-3 foreground items 1-2 D from the lens (post / girder end / rail / keg / hook), kept at the edges and above y 880, in cast shade (invisible shadow casters, see `site20._shade_casters`); the nearest ground is shaded the same way (bottom-eighth luma, see hue_report.txt).

## Recipes
* **Snap / state change on a frame:** `S.set_stage(2, frame=n)`, `S.spark_gap(True, frame=n)` ... keyed CONSTANT (visibility) or LINEAR (numbers). Key every hook on every rendered frame once it is keyed. `S.clear_keys()` resets.
* **Camera moves** are the render team's: interpolate `loc` / `look_at` / `lens` of `A['cams'][name]`; do not change the 22 mm for a push, move the camera. `shift` (lens shift_y) is part of the camera dict and must be kept (`make_camera` applies it).
* **Whip-tilt (shot 19):** keep `loc` of `tower_dusk_summit`, lerp `look_at` from the summit to `tower_dusk_summit_end['look_at']` on 7-10 frames (ease-in).
* **Crash pull-out (shot 27):** lerp from `tower_window_pull` to `tower_window_end` (use a log-like ease so the first frames move fastest); the window room stays lit at every distance.
* **Actors:** the cards are the render team's cast20 cards at the marks; `S.stage_placeholders(A, cam)` is for the contact sheet / tests only.

## core20 contract (for int20.py: CAFE / RESTO)  -- `film/v3/set3d20/core20.py`, import with `sys.path.insert(0, HERE); import core20 as C`
**Scale.** 1 world unit = 1 D (head). Adult puppets 3.2 D = 1.7 m, so **1 metre = C.SC = 1.88 D**. `C.W((x,y,z)_metres)` -> D. Everything the render team touches (cameras, marks, actors, lights) is in world D.
Two authoring modes: (a) metres under the scaled empty `C.root()`: `mb = C.MB('name', parent=C.root())` (textures keep metre object coordinates, as on the style board, hull thickness in metres); (b) directly in D: `C.MB('name')` (then `mat(..., scale=)` noise frequencies are per D: use ~SC x smaller scale numbers than the board).
**Start of build():** `M = C.reset(loc, preset, light, spp=None, dbounce=0)` wipes the scene, clears `C.MATS` / `C.STATE`, creates the world (`C.sky_world()`: keyable node names skyramp / skybg / ambbg), the sun `STATE['sun']` and returns the palette dict `M` (board palette + film-20 extras: iron, ironlt, redlead, stone, timber, plank, brick, soot, coal, rivet, metal, dark, earth2, hess, crimson, crimdk, floor, bent, navy, cloth, cream, gold, brass, brassb, mirror, glasswine, wineg, wineamb, lamp, lampsm, hwall (day windows) / hwalld (lit windows) / hwallt / hwalltd, galwall, wallres, wallpan, awn_r, flag_r/b/w ... see `palette()` / `palette_ext()`). New materials: `C.mat(name, '#hexA', '#hexB', scale, aniso, rough, emit, emit_k, zgrad, wave, sheen, contrast)`, `C.mat_emit(name, hex, k)`, `C.mat_glow(name, hex, k, alpha)`, `C.mat_windows(...)`.
**Light.** Set your light dict `P` (keys: `sky` = 7 hex colours at `C.SKYPOS` = [0, .05, .14, .30, .52, .76, 1] = sin(elevation): stop 0 = horizon AND everything below it, stop 6 = zenith, `sky_k`, `amb=(hex, strength)`, `key=(r,g,b,energy)`, `key_dir` (direction the sun travels, world), `sun_angle`, `exposure`, `sat`; extra numeric keys such as `lamp` interpolate) and call `C.apply_P(P, frame=None)` (keys sun, sky, ambient, exposure and every `STATE['lamps'][group]` scaled by `P[group]` when frame is given). `C.lerpP(Pa, Pb, k)` blends two light dicts. Lamps: `C.lamp(name, p_world_D, (r,g,b), energy, size=0.25, kind='POINT'|'AREA', rot=, area=(w,h), vis_cam=False (lights are NOT seen by the camera: draw the lamp body with an emissive mesh), group='lamp')`: energy is authored as for a metre scene (x SC^2 inside).
**Render / camera.** `C.setup_render(scene, 'final'|'preview')` (720x1280 / 360x640, Cycles CPU, `STATE['spp']` (default 8) + OIDN, max bounces 2, diffuse bounce `STATE['dbounce']` (0; set 1-2 indoors), 2 threads, film grade sat from P['sat'] via spec/grade_compositor), `C.make_camera({'loc','look_at','lens'[,'roll','shift']})` (22 mm, DOF off), `C.render(path)` -> (wall s, cpu s), `C.project(world_pt)` -> (x_px, y_px), `C.head_pixels(cam_name)`.
**Hooks.** `C.key(idb, path, frame, interp)`, `C.keysock(socket, value, frame)`, `C.setv(ob, vis, frame)`, `C.show(objs, vis, frame)`, `C.keyxf(ob, frame, loc, rot, scl)`, `C.clear_keys()`; every hook must key itself when `frame=n` is given (LINEAR; visibility CONSTANT), as in set3d16.
**Actors.** `C.placeholder_actor(role, mark, face_to=None, tilt=0, name=None, pose=None, height=None)`: cast20 puppet card; roles = cast20 names (`C.HEIGHT`): eiffel eiffel_old maupassant painter20 composer20 architect20 poet20 riveter_tongs riveter_hammer riveter_forge telegraphist officer official waiter lady20 gent20 child20; `pose=dict(...)` merges puppet pose keys (e.g. `dict(napkin=1, expr='blissful')`). Staging for the contact sheet: your build() fills `A['staging'][cam_name] = [(role, mark_name|xyz[, opts])]` (opts: pose, face_to, tilt, height); `C.stage_placeholders(A, cam_name)` makes the cards, `C.head_pixels(cam_name)` measures them (caption rule: chin y < 880).
**Props / ink.** `MB.finish(shadow=True, hull=None)`: `hull=t` adds an inverted-hull ink outline of thickness t (parent units) to every object of that MB (bible: t = 0.00384 x camera distance in D, so in metres under root: 0.00384 x dist_m).
**The dict build() returns (A):** `{'preset', 'light', 'loc', 'cam_name', 'cam': {loc, look_at, lens}, 'cams': {name: {loc, look_at, lens[, roll, shift]}}, 'marks': {name: (x, y, ground_z)}, 'staging': {...}, 'hooks': {name: callable}}`. The window position of the RESTO for the TOWER exterior glimpse: see "tower_window_pull" below.

**For int20.py (make_contact picks these up):** expose `PRESETS` (dict or list of preset names, all starting `cafe_` / `resto_`) and `TILES = [(tile_name, preset, light, hooks_code, label, camera_name_or_None[, extras_code])]`; `hooks_code` is exec'd after `build(preset, light)` with `S` (= set3d20), `A`, `C`, `bpy` in scope (e.g. `"S.set_light_mix('DAY','NIGHT',0.5)"`), `camera_name` picks a camera of `A['cams']` (None = `A['cam_name']`). Tiles that share (preset, light) are rendered by ONE process (build once, hooks per tile), so give every tile that changes a hook an explicit value for it. `python3 make_contact.py run` renders every missing tile (SITE + TOWER + yours) and writes contact.jpg / contact_small.jpg / hue_report.txt / cost_report.txt; `python3 make_contact.py run NAME ...` renders only those (`FORCE=1` re-renders existing ones, `WORKERS=1` for one process).

## Interior overview

The interior half of the film-20 set. Built on `core20.py` (materials, `MB`, sky / sun / lamps, render setup, camera, placeholder actors, keying) and on the QA-approved board code (`styleboard/sb.py`: tower lattice, Haussmann blocks, Trocadero, Seine, bridge, bentwood chair, palm, plane trees). `set3d20.build('cafe_*' | 'resto_*', light)` calls `int20.build(preset, light)`. bpy 5.3, Cycles CPU, 8 spp + OIDN, diffuse bounce 1, **no depth of field, no text anywhere** (newspapers and the protest sheet are greeked: rows of ink dashes on paper, signatures are scribbled strokes).

```python
import sys; sys.path.insert(0, 'film/v3/set3d20'); import int20 as I, core20 as C, bpy
A = I.build('cafe_low', light='DAY', view='stub')   # 'stub' (default) | 'full' = the finished tower in the window (shots 16-17)
C.setup_render(bpy.context.scene, 'final'); cam = C.make_camera(A['cams'][A['cam_name']])
C.stage_placeholders(A, A['cam_name'])               # cast20 stand-ins at the marks (contact sheet / tests)
A['hooks']['set_window_view']('full', frame=n); A['hooks']['smoke'](0.8, frame=n); A['hooks']['add_signature'](12, frame=n)   # CAFE hooks (also module functions I.set_window_view ...)
```
`A = {'preset','light','loc','cam_name','cam','cams','marks','marks_m','staging','hooks','P','state'(= core20.STATE)}` (+ `'window_world'` for RESTO). `A['cams'][name] = {loc, look_at, lens 22[, shift]}` and `A['marks'][name] = (x, y, ground_z)` are in **world D** (1 D = head, 1 m = 1.88 D = `core20.SC`); `A['marks_m']` is the same in metres. Authoring is in metres under the scaled `core20.root()`; the lights are authored in metres (`core20.lamp` scales the power). `int20.PRESETS` and `int20.TILES` (12 tiles for `make_contact.py`) are exported. One location per process (build 25-50 s; a render is 25-50 s on the shared machine, see int_hue.txt).
Test: `python3 int20.py final|draft <preset ...>` (`MEASURE=1` adds the numbers of int_hue.txt, `CAM=x,y,z,lx,ly,lz[,shift]` overrides the camera in metres, `TAG=_x` suffixes the file), `int_work/runall.sh final` (all 8), `python3 int_work/t_hooks.py` (hook test, prints ALL OK, 12 checks), `python3 int_work/make_hue.py` (writes int_hue.txt).
