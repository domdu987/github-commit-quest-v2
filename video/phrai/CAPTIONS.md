## EP.1 อย่าก้มคว้า

**ชื่อคลิป (YouTube):** คืนลอยกระทง มีเหรียญในกระทงลอยมา… อย่าก้มลงไปเก็บ | มือพราย EP.1

```
ถ้าวันหนึ่ง… กระทงลอยมาตรงหน้า มีเหรียญส่องแสงอยู่ข้างใน 🪷 อย่าก้มลงไปเก็บ!

"ของลอยมา อย่าก้มคว้า / ได้ยินเสียงพราย อย่าว่ายตาม / โดนดึงลงน้ำ… ให้นอนหงาย"

ถ้าเห็นน้องตกน้ำต่อหน้า… คุณจะกระโดดลงไปช่วยไหม? 👇

## EP.2 อย่าอุ้มพาดบ่า

**ชื่อคลิป (YouTube):** ช่วยคนจมน้ำขึ้นมาได้ แต่เขาไม่หายใจ… อย่าอุ้มพาดบ่า | มือพราย EP.2

```
ถ้าวันหนึ่ง… คุณช่วยคนจมน้ำขึ้นมาได้ แต่เขาไม่หายใจ 🌊 อย่าอุ้มพาดบ่า!

"ของลอยมา อย่าก้มคว้า / ได้ยินเสียงพราย อย่าว่ายตาม / โดนดึงลงน้ำ… ให้นอนหงาย"

ในคลิปมีความรู้ใช้ได้จริง: ช่วยคนจมน้ำขึ้นฝั่งแล้วต้องทำอะไรทีละขั้น ตั้งแต่โทร 1669 จนถึงกดหน้าอกสลับเป่าปาก

ถ้าคนที่พายเรือมารับ… ไม่ได้ใช้ไม้พายเลย คุณจะขึ้นเรือไหม? 👇

มือพราย EP.2/3
#มือพราย #ผีไทย #เอาตัวรอด #ปฐมพยาบาล #RodMaiClub
```

```

ไม่อุ้มพาดบ่าหรือกดท้องให้น้ำออก (ไม่จำเป็น อาจสำลัก และทำให้ช่วยชีวิตช้า) / โทร 1669 / วางบนพื้นแข็งเรียบ / เขย่าไหล่เรียก / กดหน้าผาก เชยคาง เป่าปาก 2 ครั้ง / กดหน้าอก 30 ครั้ง (นาทีละ 100) สลับเป่าปาก 2 ครั้ง จนหายใจเอง / จับนอนตะแคง ห่มผ้า ห้ามกินหรือดื่ม แล้วรีบส่งโรงพยาบาล: กรมควบคุมโรค "ตะโกน โยน ยื่น" (Drowning Victims: Rescue and First Aid)
