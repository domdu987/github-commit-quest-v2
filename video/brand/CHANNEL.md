## ขั้นตอนเปิดช่อง (ทำเอง ~5 นาทีต่อแพลตฟอร์ม)

1. **สร้างอีเมลใหม่ 1 อัน สำหรับช่องโดยเฉพาะ** (เช่น Gmail) ใช้สมัครทุกแพลตฟอร์ม **ยกเว้น Facebook** แล้วเปิดยืนยันตัวตนสองชั้น (2FA) ทุกบัญชี
2. **YouTube:** เข้า YouTube ด้วยอีเมลนั้น → สร้างช่อง → ตั้งชื่อ Rod Mai Club และ handle @rodmaiclub → ใส่รูปโปรไฟล์ แบนเนอร์ คำอธิบาย
3. **TikTok:** สมัครด้วยอีเมลนั้น → ตั้งชื่อบัญชี → ใส่รูปและ bio → (ถ้ามีให้เลือก) เปลี่ยนเป็นบัญชีครีเอเตอร์/ธุรกิจ เพื่อดูสถิติ
4. **Instagram:** สมัครด้วยอีเมลนั้น → ตั้งเป็นบัญชีมืออาชีพ (ครีเอเตอร์) → ใส่รูปและ bio → เปิด Threads ด้วยบัญชีเดียวกันได้
5. **Facebook Page:** สร้างจากบัญชี Facebook ส่วนตัวเดิมของเจ้าของ (ไม่ต้องเปิดบัญชีใหม่ ไม่ต้องเพิ่มอีเมลใหม่) → สร้างเพจ → ชื่อ Rod Mai Club หมวด "ครีเอเตอร์วิดีโอ" หรือ "ความบันเทิง" → ตั้งชื่อผู้ใช้เพจ → ใส่รูป ปก และ bio
   - **ห้ามเปิดบัญชี Facebook ส่วนตัวอันที่สองด้วยอีเมลใหม่:** Meta ให้มีบัญชีส่วนตัวได้คนละ 1 บัญชี ใช้ชื่อจริง ถ้าบัญชีที่สองโดนปิด เพจจะหายไปด้วย
   - เพจไม่มีอีเมลหรือรหัสของตัวเอง เข้าโดยสลับโปรไฟล์จากบัญชีส่วนตัว ชื่อเจ้าของไม่ขึ้นในโพสต์ของเพจ
   - เพิ่มแอดมินสำรอง 1 คนที่ไว้ใจได้ (การตั้งค่า → การเข้าถึงเพจ → สิทธิ์ควบคุมทั้งหมด) และเปิด 2FA บัญชีส่วนตัว ถ้าบัญชีส่วนตัวโดนล็อก แอดมินสำรองยังดูแลเพจได้
6. **X:** สมัครด้วยอีเมลนั้น → ชื่อบัญชี @rodmaiclub → ใส่รูป ปก และ bio
7. **ลิงก์ข้ามช่อง: ใส่ในโปรไฟล์เท่านั้น** (ช่องลิงก์ทางการของแต่ละแอป ไม่โดนลดการมองเห็น)
   - TikTok: ปุ่ม Instagram/YouTube ในหน้าแก้ไขโปรไฟล์ (ถ้าแอปมีให้เลือก) · ลิงก์เว็บใน bio กดได้เมื่อมี 1,000 ผู้ติดตาม หรือเป็นบัญชีธุรกิจ
   - YouTube: ลิงก์ในหน้าช่อง (โชว์ใต้ชื่อช่อง ใกล้ปุ่มติดตาม) · ลิงก์ในคำอธิบายและคอมเมนต์ของ Shorts กดไม่ได้ตั้งแต่ ส.ค. 2023

## อัปโหลดให้ภาพคม

1. **ใช้ไฟล์ `*-HQ.mp4` เท่านั้น** (1080×1920 60fps ภาพจากเรนเดอร์ต้นฉบับ ไม่ถูกบีบซ้ำ ~6–7 Mbps) ไฟล์ `*-share.mp4` ใน repo เป็นตัวเก็บสำรองที่บีบเล็กแล้ว ห้ามเอาไปลง
2. **ย้ายไฟล์เข้ามือถือแบบไม่บีบ:** Google Drive, AirDrop หรือสาย USB · ห้ามส่งผ่านแอปแชต (LINE, Messenger) เพราะแอปแชตบีบวิดีโอ
3. **อัปโหลดตอนต่อ Wi-Fi** และปิดโหมดประหยัดดาต้าของแต่ละแอป
4. **TikTok:** หน้าโพสต์ → ตัวเลือกเพิ่มเติม (More options) → เปิด "อนุญาตการอัปโหลดคุณภาพสูง" (Allow high-quality uploads) ต้องเปิดทุกคลิป · TikTok แสดงสูงสุด 1080p
5. **Instagram:** การตั้งค่า → การใช้ข้อมูลและคุณภาพสื่อ → เปิด "อัปโหลดด้วยคุณภาพสูงสุด" (Upload at highest quality)
6. **Facebook:** การตั้งค่า → สื่อ → คุณภาพวิดีโอ → เลือกคุณภาพสูงสุด
7. **YouTube:** อัปโหลดผ่านแอปหรือ YouTube Studio ได้เลย หลังอัปโหลดใหม่ๆ อาจเห็นภาพไม่คมสักพัก เพราะ YouTube ทำความละเอียดต่ำเสร็จก่อน รอสักครู่ HD จะขึ้นเอง

ชื่อเมนูอาจต่างกันตามเวอร์ชันแอปและประเทศ ถ้าหาไม่เจอให้ค้นคำว่า "คุณภาพ" หรือ "quality" ในหน้าการตั้งค่า

### อัปโหลดจากคอม (แนะนำ: ไฟล์ไม่ต้องย้ายเข้ามือถือ ไม่โดนบีบระหว่างทาง ตั้งเวลาโพสต์ได้)

- **TikTok:** tiktok.com → ล็อกอิน → ปุ่ม Upload (TikTok Studio) → ลากไฟล์ HQ → ใส่แคปชัน → โพสต์ หรือเปิด Schedule ตั้งเวลา
- **YouTube:** studio.youtube.com → สร้าง (Create) → อัปโหลดวิดีโอ → คลิปแนวตั้งยาวไม่เกิน 3 นาทีจะเป็น Shorts
- **Facebook + Instagram พร้อมกัน:** business.facebook.com (Meta Business Suite) → สร้างรีล (Create reel) → อัปโหลด → เลือกลงทั้งเพจและ IG → โพสต์ หรือตั้งเวลา (ต้องเชื่อม IG กับเพจก่อน)
- **Instagram อย่างเดียว:** instagram.com → สร้าง (+) → โพสต์ → เลือกไฟล์ (วิดีโอจะลงเป็น Reels)
- **X:** x.com → โพสต์ → แนบวิดีโอ (บัญชีฟรีลงคลิปได้ไม่เกิน 2:20)
