# ฉากเปิด EP.1 ของเรื่องใหม่: ชื่อเรื่องบนท้องฟ้า แล้วกล้องดิ่งลงมาเริ่มเรื่อง

ผู้ใช้สั่ง (24 ต.ค. 2026): "ตอนเริ่มเรื่องใหม่ ให้คลิป ep1 เปิดชื่อเรื่องพร้อม ep1 มุมกล้องบนท้องฟ้าแล้วซูมลงมาเริ่มเรื่อง"

- `opener.js`: โค้ดกลาง (`Opener.extra` / `Opener.cam` / `Opener.fx`) ก๊อปไป `hf/lib/` แล้ว (workspace.sh ทำให้)
  - head.part ต้องโหลด `<script src="assets/opener.js"></script>` หลัง engine.js และ make.py ต้องก๊อป "opener.js"
- `shots.part`: ตัวอย่างการเรียกใช้ (ช็อตแรกของ หมอกลง EP.1 ใช้ฉาก mountainRoad)
- `mix.py`: เสียงช่วงดิ่ง (swell ตอนเปิด, whoosh ตอนเริ่มดิ่งและตอนทะลุเมฆ, boom ตอนลงถึงพื้น)
- `opener-demo.mp4`: คลิปตัวอย่าง 5.8 วิ 60fps ใช้เสียงจริงของ หมอกลง EP.1 ("ถ้าวันหนึ่ง… คุณขับรถในหมอก มองไม่เห็นทาง / อย่าเปิดไฟสูง")

ค่าที่ปรับได้: `title`, `ep`, `name` (ชื่อตอน), `kick` (บรรทัดเล็กเหนือชื่อ), `land` (= `fr(...)` มุมกล้องของฉากแรก),
`at` (เริ่มดิ่งวินาทีที่เท่าไร), `glide` (ดิ่งนานกี่วินาที), `rise` (เริ่มสูงกว่าจุดลงจอดกี่ px, ค่าเริ่ม 2600),
`night:false` (กลางวัน), `tint`/`glow` (สีป้าย EP และแสงรอบชื่อ), `cloud`/`rim` (สีเมฆ)
