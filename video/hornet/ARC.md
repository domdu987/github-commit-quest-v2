## แนวคิด: "ทหารของเจ้าที่" = ฝูงต่อหัวเสือ
- ยายบัวเล่าว่าต้นมะขามหลังศาลตายายมีเจ้าที่ และเจ้าที่มี "ทหาร" เฝ้า **ใครปัด ใครตี ทหารจะตามไปทั้งฝูง** — คำเตือนคนแก่ที่ถูกหาว่างมงาย แต่ตรงกับความรู้จริง (S13 ข้อ 2):
  ปัดแล้วโดนต่อย (S1) · ถูกรุมต้องวิ่งเข้าที่ร่ม/ในบ้าน (S1) · ลงน้ำไม่รอดเพราะมันรอเหนือน้ำ (S1) · พิษมาทีหลังถึงในสองวัน (S4 S5 S7)
- ภาพผี: ไม่มีตัวผี ใช้จอหนังตะลุง "เจ้าที่กับทหาร" (S5) และเงาฝูงต่อในตอนลุ้น · ความมืดและตาเขียวไม่ใช้ เพราะภัยมากลางวัน
- เรื่องสมมติทั้งหมด หมู่บ้านสมมติ "บ้านโนนมะขาม"

  "Remain calm and still if a single stinging insect is flying around. Swatting at an insect may cause it to sting. **ไม่ใช้ (ยืนยันกับแหล่งทางการไม่ได้หรือแหล่งขัดกัน):**
- ระยะที่ต่อไล่ตาม (เมตร) · ฤดูที่รังใหญ่/ต่อยมากที่สุด · ต่อบินตามแสงไฟกลางคืน · การโทร 199 ให้เอารังออก (มีแค่บล็อกสถานีดับเพลิง)
- สารเตือนภัยจากต่อที่ถูกบี้ (มีแค่ในผึ้ง และงานวิจัยของ *V. velutina*) → ในเรื่องไม่อ้างว่า "ตีตัวเดียวแล้วเรียกทั้งรัง" พูดแค่ "การปัดทำให้มันต่อย" (S1)
- เหล็กใน: รามาธิบดีเขียนรวมผึ้ง/ต่อว่าเห็นเหล็กในคา แหล่งต่างประเทศบอกต่อไม่ทิ้งเหล็กใน → ไม่พูดเรื่องเหล็กในเลย
- ยาพื้นบ้านเฉพาะ (ปูนแดง ยาสีฟัน มะนาว) ไม่มีแหล่งทางการไทยระบุ → ไม่ยกชื่อ ใช้แค่ "ล้างน้ำกับสบู่ ประคบเย็น" (S1 S2 S5)
- จำนวนแผลที่ต้องนอนโรงพยาบาล: แหล่งไม่ตรงกัน (S4 >10 · S5 ผู้ใหญ่ 30–40 เด็ก 5–10 · หน้าเว็บรามาธิบดี >500 น่าจะเป็นตัวเลขผึ้ง) → ใช้ข้อที่ปลอดภัยกว่า:
  "โดนต่อยหลายแผล ต้องไปให้หมอดู แม้ยังไม่มีอาการ" + "เกินสิบแผล เสี่ยงอาการรุนแรง" (S4)

## สูตรคลิปยอดวิว (S13) ครบ 8 ข้อ
| ข้อ | ในเรื่องนี้ |
|---|---|
| 1 ของล่อใจ/สิ่งที่คนดูเกือบทำเอง | มือที่ยกขึ้นปัดต่อตัวแรกที่บินวนหน้า (EP.1) · สระน้ำตรงหน้าตอนโดนรุม (EP.2) · คำว่า "ไม่เป็นไร" ของยาย (EP.3) |
| 2 ผี = อันตรายจริง | "ทหารของเจ้าที่" ตามทั้งฝูงเมื่อมีคนปัด = ฝูงต่อหัวเสือ (S1) |
| 3 หักล้างความเชื่อ | "ปัดไล่ได้" (S1) · "โดดน้ำหนีรอด" (S1) · "ไม่มีอาการ = ไม่เป็นไร" / "ประคบแล้วหาย" (S4 S5 S7) |
| 4 ครอบครัวไปบ้านยาย | เตย (พี่สาวปากแข็ง) · ปาล์ม (น้องชายมั่นใจเกิน) · ยายบัว (กฎคล้องจอง) · ลุงสิงห์ (ข้างบ้าน ใส่แขนยาวกลางแดด เด็กๆ หาว่าบ้า) |
| 5 คนดูรู้ก่อน | EP.1 กล้องเห็นรังต่อขนาดเท่าโอ่งบนกิ่งมะขาม ก่อนที่ปาล์มจะยิงหนังสติ๊กใส่ฝักมะขามข้างรัง |
| 6 ปิดตอน | หลักฐานในภาพ + ประโยคเดียว: ฝูงต่อพุ่งจากปากรัง / ยายนั่งที่ศาล แขนเต็มไปด้วยแผล "ยายไม่เป็นไร" |
| 7 เฟรมแรก/ปก | ต่อหัวเสือตัวใหญ่บินวนตรงหน้ากล้อง ฉากหลังคือรังเท่าโอ่งบนต้นมะขามกับศาลตายาย |
| 8 ตรงช่วงเวลา | ปิดเทอม ต.ค.–พ.ย. (เด็กกลับบ้านยาย) |

## กฎของยายบัว (คล้องจอง ตอนละข้อ · การ์ด = ผ้ายันต์/ใบลานผูกที่เสาศาล ติ๊กทีละข้อ)
1. **ต่อบินมาวน อย่าลนอย่าปัด** (EP.1 · S1)
2. **ต่อรุมให้วิ่ง อย่าทิ้งตัวลงน้ำ** (EP.2 · S1)
3. **ต่อยหลายแผล อย่าแค่นอนรอ ต้องไปหาหมอ** (EP.3 · S4 S5 S6)

## ความพลาดที่ฝังไว้ (ช่วงวิ 46–52 ทุกตอน: "เขาพลาดไปแล้ว… ตั้งแต่วินาทีที่ X / คุณเห็นไหม?" + ช็อตย้อนเทป)
- EP.1 วิ 4: หินจากหนังสติ๊กปาล์ม กระดอนจากฝักมะขามไปโดนกิ่งที่รังห้อย รังแกว่ง
- EP.2 วิ 3: ประตูบ้านยายเปิดอยู่ข้างหลังเตย เธอวิ่งผ่านไปทางสระ
- EP.3 วิ 2: ยายดึงผ้าขาวม้าคลุมแขนที่มีแผลต่อยเป็นสิบ

## เบาะแสข้ามตอน
- ลุงสิงห์แขนยาว/บูท/แผลเป็นหลังมือ (EP.1 EP.2) → EP.3 เฉลย: ปีก่อนแกโดนรุม บอกทุกคนว่า "ไม่เป็นไร" แล้วไปนอนโรงพยาบาล
- ศาลตายาย: ยายเปลี่ยนมาลัยทุกเช้า (EP.1) → EP.2 ยายหายไปตอนต่อรุม เพราะอยู่ที่ศาล → EP.3 แผลบนแขนยาย

## EP.1 อย่าปัดมัน (~68 วิ)
ความรู้: ยืนนิ่งเมื่อมีตัวเดียว การปัดทำให้มันต่อย (S1) · ข้างหลังมันคือทั้งรัง
beat: ฮุก (ต่อวนหน้ากล้อง + ป้ายชื่อเรื่องบนแผ่นไม้ตอกรั้วศาล) → "อย่าปัดมัน" (วิ 4: หินกระดอนโดนกิ่ง) → เหตุผล → ปิดเทอมที่บ้านยาย (แผนที่ กทม. → บ้านโนนมะขาม) → ปาล์มยิงมะขาม / เตยหาเน็ต → รังเท่าโอ่งเหนือศาล (คนดูเห็นก่อน) → ยายตั้งกฎ + การ์ดกฎ → ตำนานจอหนังตะลุง → เตยปัดตก → ลุงสิงห์แขนยาวกลางแดด "ลุงบ้าแน่เลย" → ต่อตัวแรกวนหน้าปาล์ม ปาล์มยืนนิ่ง (พลิก) → เตยปัดแทน โดนต่อย → "เขาพลาดไปแล้ว… ตั้งแต่วินาทีที่ 4" ย้อนเทป → ปากรังฝูงต่อทะลัก → การ์ดตอนต่อไปบนแผ่นไม้ "ต่อรุม อย่าลงน้ำ"
ปมค้าง: ฝูงต่อพุ่งออกจากปากรัง

## EP.2 ต่อรุม อย่าลงน้ำ (~68 วิ)
ความรู้: ถูกรุมให้วิ่งหนี (S1) · เข้าในบ้าน ที่ร่มดีกว่าที่โล่ง (S1) · อย่ากระโดดลงน้ำ มันรอเหนือน้ำ (S1) · ป้องหน้าและหัว **ไม่มีในแหล่ง ไม่พูด** (ให้ภาพแค่วิ่ง)
beat: ต่อฝูงพุ่ง เตยวิ่ง → "อย่ากระโดดลงน้ำ" (วิ 3: ประตูบ้านยายเปิดข้างหลัง) → ภาพตัดขวางสระ: ต่อวนรอเหนือน้ำ คนต้องโผล่หายใจ (ภาพ "ถ้าทำแบบนั้น" จาง+ขอบมืด) → วิ่ง เข้าบ้าน ที่ร่มดีกว่าที่โล่ง → การ์ดกฎข้อ 2 → เตยจะโดด → ลุงสิงห์คลุมผ้า ดึงเข้าเพิง ปิดประตู ต่อชนมุ้งลวด → ปาล์มวิ่งเข้าบ้านยายได้ "ยาย! ยายอยู่ไหน?" → "เขาพลาดไปแล้ว… ตั้งแต่วินาทีที่ 3" → ยายนั่งที่ศาล แขนแผลเต็ม "ยายไม่เป็นไรหรอก" → การ์ดตอนต่อไป "ยายบอกว่าไม่เป็นไร"

## EP.3 อย่าเชื่อคำว่าไม่เป็นไร (ตอนจบ ~70 วิ)
ความรู้: ล้างน้ำกับสบู่ ประคบเย็น 20 นาที ถูกแล้วแต่ไม่พอ (S1 S2 S5) · พิษจากการถูกรุมต่อยทำร้ายไตได้ภายในสองวัน ปัสสาวะสีเข้ม/ออกน้อย (S5 S7) · เกินสิบแผลเสี่ยงอาการรุนแรง (S4) · หายใจลำบาก ปากบวม เป็นลม → 1669 (S2 S3 S6 S8)
beat: ยาย "ไม่เป็นไร" (วิ 2 ดึงผ้าคลุมแขน) → "อย่าเชื่อ" → เหตุผล → ปฐมพยาบาลถูกต้อง แต่ไม่พอ → ตกค่ำ ปาล์มเห็นยายฉี่ออกน้อย สีเข้ม → การ์ดกฎข้อ 3 → ปาล์มโทร 1669 → ลุงสิงห์ขับกระบะพาไปโรงพยาบาล (แผนที่) → "เขาพลาดไปแล้ว… ตั้งแต่วินาทีที่ 2" → ลุงสิงห์เล่า "ปีก่อน ลุงก็บอกว่าไม่เป็นไร" (ข่าวลือกลับด้าน) → ยายรอด ปาล์มเปลี่ยนมาลัยที่ศาลแทนยาย → การ์ดจบซีรีส์ กฎครบ 3 ข้อ

## สิ่งที่ห้ามทำ
- ห้ามวาดคนตาย ห้ามฉากเผารัง/ตีรังเป็นวิธีที่ถูก · ห้ามอ้างชื่อแหล่งในคลิป (อยู่ในคอมเมนต์ปักหมุด) · ไม่มีชิป HUD
- ห้ามใช้วลี "ทุกอย่างถูกหมด ยกเว้นเรื่องเดียว"
