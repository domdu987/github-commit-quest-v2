# ค่ายคืนสุดท้าย — โครงเรื่อง 3 ตอน

ตัวละคร: **ปิ่น** (ใจกล้า ใจร้อน), **กล้า** (ชื่อกล้าแต่ขี้กลัว), **พี่โจ้** (หัวหน้าค่าย), **ลุงชัย** (เจ้าหน้าที่อุทยาน)
กฎของเรื่อง: "หลังสองทุ่ม อย่าออกนอกแคมป์ — ได้ยินใครเรียกชื่อ อย่าขาน"

## EP.1 เสียงเรียก (ตอนนี้)
แคมป์วันสุดท้าย → ลุงชัยเตือน → รถตู้สตาร์ทไม่ติด ไม่มีสัญญาณ → พี่โจ้เดินไปตามคนที่ป้อม
→ สามทุ่ม พี่โจ้ไม่กลับ → เสียงพี่โจ้เรียกจากในป่า → ปิ่นเลือกตามเสียงไป → หลงป่า (หยุด·คิด·สังเกต·วางแผน)
→ เป่านกหวีด 3 ครั้ง → มีเสียงตอบจากข้างหลัง → กลั้นหายใจ → ไฟฉายเจอ "พี่โจ้" ตาเรืองแสง
→ "ทำไม… ไม่ขานล่ะ" → ตัวเลือก ขานรับ / วิ่งหนี ถูกดึงไปที่ "ขานสิ…" → ตัดดำ

ความรู้: ห้ามแยกกันเดินในป่ากลางคืน · หลงป่าให้หยุดอยู่กับที่ · นกหวีด 3 ครั้ง = ขอความช่วยเหลือ · ตาคนไม่สะท้อนแสงไฟฉาย

## EP.2 ตาสีเขียว
เปิดด้วยผลของตัวเลือก (วิ่งหนี) มุมมองบุคคลที่ 1 วิ่งฝ่าป่า → ทั้งคู่พลัดกัน กล้าได้ยินเสียงปิ่นเรียก
→ ต้องถามคำถามที่ปิ่นตัวจริงเท่านั้นที่ตอบได้ → เจอฝูงช้างป่า: หลบหลังต้นไม้ใหญ่ QTE เงียบไว้
→ ปิ่นโดนงูเขียวหางไหม้กัด → ปฐมพยาบาล → เห็นแสงไฟหน่วยพิทักษ์ป่า
ค้างไว้: วิทยุในกระท่อมที่ล็อกอยู่ ดังเป็นเสียงพี่โจ้ "กล้า… เปิดประตูให้พี่หน่อย"

ความรู้: เจอช้างระยะใกล้ อย่าส่งเสียงไล่ หลบหลังต้นไม้ใหญ่ ค่อยๆ ถอย · งูกัด ห้ามกรีด ดูด ขันชะเนาะ ให้นิ่ง รีบไปโรงพยาบาล

## EP.3 อย่าขาน
ลุงชัยตัวจริงอยู่ในกระท่อม เรียกรถฉุกเฉิน (1669) → มือถือมีสัญญาณ ข้อความพี่โจ้ตัวจริงส่งตั้งแต่ 15:12
"ติดธุระในเมือง คืนนี้ขึ้นไปไม่ทัน" → สิ่งนั้นวนรอบกระท่อม เลียนเสียงทุกคน → อยู่ในที่มีไฟ รอจนสว่าง
→ รถกู้ภัยมาถึงตอนเช้า ทุกอย่างกำลังจะจบ… หักมุม: โทรศัพท์กล้าดัง ชื่อผู้โทร "ปิ่น" ทั้งที่ปิ่นนั่งอยู่ข้างๆ
