## แนวคิด

- **ผีคือนางตะเคียน ในฐานะความเชื่อ:**
  - ยายหอมเล่าว่า "อย่าเข้าใกล้ต้นตะเคียนตอนฟ้ามืด นางจะเอาตัวไป"
  - เรื่องเล่าเป็นความเชื่อ ไม่ใช่ข้อเท็จจริง
- **อันตรายตัวจริงในร่างตำนาน** (S13 ข้อ 2):
  - ต้นไม้สูงต้นเดียวกลางที่โล่ง คือที่ที่ฟ้าผ่าลงก่อน (K2, K3)
  - คนที่หลบใต้ต้นไม้โดนไฟกระโดดเข้าตัวหรือโดนกระแสที่วิ่งไปตามดิน (K4)
  - "นางเอาตัวไป" จึงเป็นภาษาคนแก่ที่ใช้เล่าสิ่งที่เคยเห็นจริง
- **ตำนานใน EP.1 (S5)**
  - เล่า 2–3 ประโยคบนภาพจิตรกรรมแบบผ้าพระบฏ ที่แขวนหลังศาลเพียงตา **ไม่ใช้หนังตะลุง**:
    > "นางตะเคียนผมยาวสยาย ห่มสไบเขียว สิงอยู่ในต้นตะเคียนกลางนา · ฟ้ามืดเมื่อไร นางจะเรียกคนให้เข้าไปหลบใต้ร่มนาง · ใครเข้าไป นางเอาตัวไปทุกราย"
  - แล้วตัดเป็นภาพตัดขวางวิทยาศาสตร์: ฟ้าผ่ายอดไม้ → ไฟกระโดดเข้าคน → วงกระแสในดิน
- **ฉาก:** บ้านโนนตะเคียน (ชื่อสมมติ) ทุ่งนาภาคกลางหรืออีสาน บ่ายแก่หน้าฝน
  - กลางนามีต้นตะเคียนยักษ์ต้นเดียว พันผ้าแพร 7 สี มีพวงมาลัยและศาลเพียงตา
  - มีควายผูกหลักใกล้ต้นไม้ เถียงนาหลังคาจากอยู่ห่างออกไป และรถกระบะจอดที่ถนนดินขอบนา (ที่ปลอดภัยจริง K7)
- **ความยาว** (growth-playbook): ตอนละ ~75–85 วิ ราว 16–19 ช็อต
  - ผู้บรรยาย Puck tempo 1.2 พูดกับ "คุณ"
  - ตัวละครพูดราว 40% ตามที่ผู้ประสานงานสั่ง (S3) ประโยคสั้น 2–5 คำ
- **ห้าม:**
  - เลือดหรือศพแบบโหด: ลุงล้มนิ่ง มีควันจาง แล้วกลับมาหายใจ
  - แบรนด์จริง · ป้าย HUD หรือตัวเลขบนจอ · ประโยค "พลาดตั้งแต่วินาทีที่ X" · การย้อนเวลา
  - กบ: ไม่ให้คล้าย "กบทั้งทุ่งเงียบ" ของคู่แข่ง

## EP.1 "อย่าวิ่งไปหลบใต้ต้นตะเคียน" (~80 วิ)

- **เดิมพันก่อนทิป:** ต้องดำนาแปลงสุดท้ายให้เสร็จก่อนค่ำ และควายของลุง "ราคาเท่ารถ" ผูกอยู่ใต้ต้นไม้
- **อันตรายสะสม 3 ระดับ:**
  1. ลมแรง ฝนตก
  2. ฟ้าแลบไกลขอบทุ่ง
  3. ฟ้าผ่าต้นไม้ แล้วไฟวิ่งไปตามดิน

| วิ | จังหวะ | ภาพ / บท |
|---|---|---|
| 0–3 | ฮุก A | "ถ้าวันหนึ่ง… คุณติดพายุกลางทุ่งนา" ทั้งบ้านวิ่งฝ่าฝนตามคันนาเข้าหาต้นตะเคียน ฟ้าผ่าข้างหลัง → **{อย่าวิ่งไปหลบใต้ต้นตะเคียน!}** ที่ ~3.0 วิ |
| 3–8 | เหตุผล | ผู้บรรยาย: "อยู่ใต้ต้นไม้ คือสาเหตุอันดับสองที่คนโดนฟ้าผ่า" (K2) · ยายกระชากแขนพลอยหยุด |

| 52–64 | อันตรายระดับ 3 | ทุกคนอยู่ในรถ หมาซุกใต้ท้องรถ · ลุงเห็นควายดิ้นเชือก วิ่งกลับไป "แค่แก้เชือก" · คนดูเห็นแสงแลบในเมฆเหนือยอดต้นไม้ → ฟ้าผ่าต้นตะเคียน ไฟวิ่งไปตามดินถึงลุง ลุงล้ม (ไม่มีเลือด มีควันจาง) |

| 74–80 | การ์ดตอนต่อไป (ในฉาก) | กระดาษโน้ตเปียกปลิวติดกระจกรถ: "ถ้าวันหนึ่ง… คนข้างคุณโดนฟ้าผ่า" |

## EP.2 "อย่ากลัวจับตัวเขา" (~85 วิ)

- **เดิมพันก่อนทิป:** ชีวิตลุงเปี๊ยก หัวใจหยุด รถพยาบาลอีกไกล
- **อันตรายสะสม 3 ระดับ:**
  1. ไม่มีใครกล้าแตะ
  2. ไม่หายใจ และฝนยังตก
  3. ฟ้าผ่าซ้ำตอนที่ทุกคนคิดว่าจบแล้ว (F6)

| วิ | จังหวะ | ภาพ / บท |
|---|---|---|
| 0–3 | ฮุก C | เปิดต่อจากภาพค้างของ EP.1 (H1): "ถ้าวันหนึ่ง… คนข้างคุณโดนฟ้าผ่า" ทุกคนกลัวไฟดูด → **{อย่ากลัวจับตัวเขา!}** ~3.0 วิ |
| 3–8 | เหตุผล | "ตัวคนเก็บไฟฟ้าไว้ไม่ได้ จับได้ทันที" (K9) |
| 8–16 | **ความรู้แรก + การ์ดกฎ 2** · กลับบทบาท | ต้นวิ่งไปวางมือบนอกลุงก่อนใคร ท่องกฎ 2 · พลอยตามไป |
| 16–30 | ความรู้ชุดเซฟเก็บ | พลอยเช็กว่าไม่หายใจ (K10) → โทร **1669** เปิดลำโพง วางมือถือบนหญ้า → มุมบน: มือประสานกลางอก กดลึก 5–6 ซม. 100–120 ครั้ง/นาที ตามจังหวะแร็ปของต้น (K13) |
| 30–38 | **หักมุมแรก** (ก่อน 40 วิ) | ยายจะลากลุงไปหลบใต้ต้นไม้ให้พ้นฝน → พลอย: "ไม่! ต้นนั้นแหละที่ผ่า" แล้วผลัดกันปั๊มกลางคันนาโล่งแทน (คนดูเห็นว่ายายเกือบพลาดกฎของตัวเอง) |

| 70–80 | เฉลยท้าย | ควันจางเผยให้เห็นรอยไหม้เก่าหลายทางบนลำต้น (มีมาตั้งแต่เฟรมแรก EP.1) · รูปขาวดำในศาลคือตาของพลอย · ยาย: "นางไม่ได้เอาตัวใครไปหรอก… ฟ้าต่างหาก" |

## เบาะแสข้ามตอน

1. **รอยไหม้เก่าบนลำต้นเป็นทางยาว:** เห็นในเฟรมแรก EP.1 (ต้องเพิ่มในฉากตอนผลิต) → เฉลยใน EP.2 ว่าฟ้าผ่าต้นนี้ซ้ำมาแล้ว
2. **รูปขาวดำในศาลเพียงตา:** EP.1 ช็อตตำนาน → EP.2 คือตาของพลอย
3. **กระบะ + กุญแจห้อย:** EP.1 ช็อตเปิด → เป็นที่หลบที่ถูกต้อง (K7)
4. **นาฬิกาจับเวลาของเล่นของต้น:** EP.1 ใช้จับเวลาดำนา → EP.2 ใช้นับ 30 นาที
5. **ต้นแร็ปกฎยาย:** EP.1 เป็นมุก → EP.2 ทำให้ต้นกล้าจับลุง และเป็นจังหวะ CPR
6. **ควายผูกใกล้โคนต้น:** EP.1 ทำให้ลุงกลับไปที่ต้นไม้ → EP.2 ทำให้ต้นกลับไปที่ต้นไม้

## สิ่งที่ต้องเก็บตอนผลิต (จาก style frames)

- **เรือนยอดตะเคียน:** ยังเป็นก้อนกลม ต้องทำทรงใบเรียวแหลมแบบตะเคียน กิ่งโผล่ระหว่างก้อน และเพิ่มรอยไหม้เก่าบนลำต้น
- **ฉาก CPR มุมบน:** ร่างลุงยังแข็งเป็นแท่ง ต้องทำไหล่โค้ง แขนต่อไหล่ และเปลี่ยนเป็นมือจริง (`realHands` / `armK` ตาม growth-playbook ข้อ 6)
- **ฮุก C เฟรม 1:** พลอยใช้ท่า point แทนการเอื้อมแล้วชะงัก ต้องทำท่าเอื้อมมือที่มีข้อศอกงอ
- **การ์ดและป้ายที่ยังไม่ได้ทำ:**
  - แผ่นไม้กฎ 3 แผ่น
  - ผ้าพระบฏนางตะเคียน
  - ภาพตัดขวางไฟกระโดดข้างและกระแสในดิน
  - จอ "ถ้าทำแบบนั้น"
  - กระดาษโน้ตตอนต่อไป
- **กระบะ:** ภาพตัดข้างรถตามมาตรฐาน `Sets.carCut` หุ่นนั่งเบาะ (V3/V4)
