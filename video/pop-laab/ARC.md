# ผีปอบร่วมวงลาบ — โครงเรื่อง 2 ตอน (ด่านก่อนผลิต · ร่าง v1 · 2 พ.ย. 2569)

- **เจ้าของสั่ง:** "ทำตลกๆ" (2 พ.ย. ~15:00) ผ่านผู้ประสานงาน
- **แนว:** ตลกก่อน น่ากลัวทีหลัง
  - สูตร "ตัวละครที่ทุกคนรู้จักมาอยู่ในชีวิตธรรมดาแบบไทย"
  - ตัวที่ทุกคนรู้จักคือ **ผีปอบ** (ตำนานไทย ไม่มีลิขสิทธิ์)
- **คำถามที่คนอยากรู้:** ทำไมกินหมูดิบแล้ว "หูดับ"
  - คำตอบ: เชื้อ *Streptococcus suis* ขึ้นสมอง → หูหนวกถาวร หรือถึงตาย
  - แหล่ง: `SOURCES.md`
- **ห้าม:**
  - ห้ามล้อวัฒนธรรมอาหารอีสาน: ตัวตลกคือปอบ ไม่ใช่คนกิน · ลาบสุกยังอร่อยและเป็นทางออกในเรื่อง
  - ห้ามตัวละครมีลิขสิทธิ์ · ห้ามแบรนด์จริง (ขวดเหล้าไม่มีฉลาก) · ห้ามเลือดสยอง
- **ช่วงลง:** ปลายฝนต้นหนาว
  - ตรงงานบุญ / ออกพรรษา / กฐิน ที่หมู่บ้านล้มหมูทำลาบ
  - ข้อมูล DDC: ผู้ป่วยมากสุดในภาคอีสานและภาคเหนือ

## ตัวละคร (S3 / S13 ข้อ 4)
- **ผีปอบ "ปอบ"**
  - ออกแบบใหม่ ไม่ซ้ำปอบผอมดำของเห็ดปอบ
  - ตัวกลมหัวโต สีเขียวเซจ หูใหญ่เหมือนใบตอง ตาเหลืองมัน ยิ้มกว้างเขี้ยวเล็ก
  - ผ้าขาวม้าพันคอ ช่วงล่างเป็นควัน
  - **ยิ่งกินดิบ หูยิ่งตก** (ภาพบอกอาการ)
  - สายกินดิบตัวพ่อ คำติดปาก "ของดิบต้องดิบ!"
- **ลุงทิด (55)**
  - ทำลาบเก่งที่สุดในหมู่บ้าน อวดว่า "ลาบต้องดิบถึงจะหวาน"
  - นิ้วมีแผลพลาสเตอร์ แต่ขยำหมูด้วยมือเปล่า
- **ยายบัว (72)** ผู้ใหญ่ที่ตั้งกฎคล้องจอง ชาวบ้านว่ายาย "หัวโบราณ ขี้บ่น"
- **แพร (17)** พี่สาวปากแข็ง กลับบ้านยายช่วงงานบุญ · มุก "ไม่มีเน็ตเลยเหรอ"
- **ต้นกล้า (10)** น้องชายมั่นใจเกิน "ปีนี้ผมจะกินลาบดิบให้เหมือนลุง!" · คนดูจะเดาว่าเขาคือเหยื่อ
- **คนขายหมูกระบะ** (โผล่สั้นๆ) "หมูตายเมื่อเช้า ขายถูก" — เบาะแสหลัก

## EP.1 "ปอบร่วมวงลาบ" (~1:40)
- **เดิมพัน:** ต้นกล้าอยากพิสูจน์ว่าเป็นผู้ใหญ่ด้วยการกินลาบดิบเหมือนลุง · ลุงทิดภูมิใจในฝีมือ
- **ฮุก (0–3 วิ):**
  - ภาพ: ใต้ถุนบ้านคืนงานบุญ จานลาบหมูดิบสีแดง ปอบหูใหญ่ยื่นข้าวเหนียวจิ้มลาบมาที่กล้อง
  - เสียง: "ถ้าวันหนึ่ง… ผีปอบมาร่วมวงลาบหมูดิบกับคุณ" → **{อย่ากินหมูดิบ}** ~2.8 วิ
  - H6: "ไม่ใช่เพราะกลัวผี…" แล้วตัด "12 ชั่วโมงก่อน"
- **ก่อนงาน:**
  - กระบะขายหมูจอดหน้าบ้าน ป้าย "หมูสด ราคาถูก" คนขาย "ตายเมื่อเช้า ขายถูก" (เบาะแส 1)
  - ปอบตัวเล็กไกลๆ ดมกลิ่นตามกระบะมา (คนดูเห็น ตัวละครไม่เห็น)
- **ลุงทิดสับลาบ:** นิ้วบาดเลือดซิบ แปะพลาสเตอร์ แล้วขยำหมูด้วยมือเปล่าต่อ (เบาะแส 2)
- **ยายบัว:**
  - บอกกฎข้อ 1 "หมูต้องสุก ไม่ใช่สุกแค่มะนาว"
  - ทุกคนหัวเราะ ลุง "บีบมะนาว ใส่พริก กินกับเหล้า ฆ่าเชื้อหมดแล้วยาย!"
  - การ์ดหักล้าง: มะนาวแค่ทำให้เนื้อเปลี่ยนสี ไม่ฆ่าเชื้อ
- **วงลาบ (มุกหลัก):**
  - ปอบแทรกตัวนั่งวง พันผ้าขาวม้าปิดหูเหมือนชาวบ้าน · ไม่มีใครสังเกตเพราะมืดและเมา
  - ปอบกินลาบดิบหมดถาด "ของดิบต้องดิบ!" ลุงทิดชอบใจ "คอเดียวกัน!"
  - ต้นกล้าเอื้อมจะกิน แพรตีมือ "ยายบอกแล้ว!" · ต้นกล้าแอบกินคำหนึ่ง (คนดูเห็น)
- **เช้าวันบุญ (มุกฟังผิด):**
  - (ไม่มีพระในมุกนี้ · ผู้ประสาน 2 พ.ย.)
  - ชาวบ้านตีหม้อไล่ ปอบได้ยินแค่ "ตึ้บ ตึ้บ" แล้วโยกหัวตามจังหวะ
  - หมอผีชี้ "ไปให้พ้น!" ปอบหูตกได้ยินเป็น **"ใส่ให้ล้น!"** แล้วตักลาบใส่จานจนล้น ยื่นให้หมอผี
  - ปอบเริ่มเซ ทรงตัวไม่ได้ (อาการ: เวียนหัว ทรงตัวไม่ได้)
- **S5 ตำนาน (หมอลำบนเวทีงานบุญ):** หมอลำร้องกลอนตำนาน "ปอบชอบของดิบ… กินจนหูดับ" (อยู่ในโลกของเรื่อง เป็นอีสาน) → เฉลยความรู้: เชื้อในหมูดิบ / หมูป่วยตาย ขึ้นเยื่อหุ้มสมอง → หูดับ
- **เหมือนจบดี (F6):** ปอบเซหนีออกจากหมู่บ้านเอง ชาวบ้านไชโย "ไล่ปอบได้แล้ว!" ต้นกล้าก็ไม่เป็นอะไร
- **แต่… (หักมุม ~82%):**
  - การ์ด **"3 วันต่อมา"** (DDC: ส่วนใหญ่ 3–5 วันหลังกิน ช่วง 1–14 วัน)
  - ลุงทิดนั่งกุมหัว ปวดหัวรุนแรง คอแข็ง ไข้ขึ้น
  - ยายเรียก "ทิด! ทิด!" ลุงหันมา "หา? พูดอะไรนะ"
  - ปมในภาพ: พลาสเตอร์ที่นิ้วชุ่มน้ำลาบ
- **ประโยคหลอน + ตัวเลือก (S9):**
  - "ไม่ใช่ปอบที่ทำให้หูดับ… ปอบแค่เป็นคนแรกที่ไม่ได้ยิน"
  - ตัวเลือก: "พาลุงไปหาหมอตอนนี้ หรือรอให้หมอผีมาไล่ปอบออกจากตัวลุง?"
- **คนดูจะเดาว่า / ที่จริง:**
  - เดาว่าต้นกล้า (คนกินลาบดิบให้เห็น) จะหูดับ → ที่จริงคือลุงทิด คนทำลาบที่มีแผลที่มือ + กินมากสุด
  - พลิกบทบาท: ผู้เชี่ยวชาญเรื่องลาบคือคนที่พลาด · เด็กที่มั่นใจเกินยังรอด (ตอนนี้)

## EP.2 "บอกหมอว่ากินดิบ" (~1:40)
- **ฮุก:**
  - ต่อจากเฟรมค้าง: ลุงทิดคอแข็ง ตาลอย
  - เสียง: "ถ้าวันหนึ่ง… คนที่กินลาบดิบกับคุณ ไข้ขึ้น คอแข็ง" → **{อย่ารอให้หาย}**
  - คำถาม: ทำไมรอแค่คืนเดียวก็อาจหูหนวกตลอดชีวิต
- **ความลุ้นสะสม 3 ระดับ:**
  1. ชาวบ้านว่า "ปอบเข้า!" จะเรียกหมอผีมาทำพิธีทั้งคืน · ยายบัวกับแพรยืนยันไปโรงพยาบาล
  2. รถกระบะฝ่าฝนกลางดึกไปโรงพยาบาลอำเภอ (แผนที่ S12) · ลุงอาเจียน เซ หูอื้อ
  3. ห้องฉุกเฉิน: หมอถาม "กินอะไรมา?" ลุงอายตอบแค่ "เป็นไข้ครับ"
     - ต้นกล้าตะโกน **"ลุงกินลาบดิบครับ!"** → หมอให้ยาฆ่าเชื้อทันที
     - การ์ดกฎข้อ 3 "ไข้ขึ้น คอแข็ง บอกหมอว่ากินดิบ"
- **มุก:** ปอบหูดับเดินเข้า ER มาด้วย ยืนต่อคิวหน้าพยาบาล ไม่ได้ยินใครเรียกชื่อ (ไม่มีใครเห็นนอกจากต้นกล้า)
- **ความรู้:**
  - อาการ 3–5 วันหลังกิน (ช่วง 1–14 วัน)
  - ตัวเลข DDC ปี 2569 ถึง 8 ก.ค.: ป่วย 647 ราย เสียชีวิต 41 ราย
  - กฎ 3 ข้อติ๊กครบ
- **เหมือนจบดี (F6):**
  - ลุงรอด แต่หูข้างหนึ่งดับถาวร (ผลจริง ไม่ใช่ happy ending ล้วน)
  - กลับบ้าน ยายทำลาบคั่ว (ลาบสุก) วงลาบใหม่ทุกคนหัวเราะ ปอบนั่งกินลาบสุกด้วยหน้าบึ้ง "ไม่ดิบ… ไม่อร่อย"
- **แต่… (หักมุมจบเรื่อง):**
  - ต้นกล้าเงยหน้า "ยายครับ… ทำไมผมได้ยินยายไม่ค่อยชัด"
  - 2 วิ: แพรจูงน้องเข้าห้องตรวจทันที บอกหมอ "น้องกินลาบดิบค่ะ" (กฎข้อ 3 · ไม่รอให้หาย)
  - เบาะแส: คำที่ต้นกล้าแอบกินใน EP.1 + ไข้ต่ำๆ ตอนนั่งรถไป รพ. ที่ถูกมองข้าม
  - แล้วตัดไปที่กระบะหมูคันเดิมวิ่งออกไปงานบุญหมู่บ้านถัดไป ป้าย "หมูสด ราคาถูก" มีปอบนั่งท้ายกระบะ โบกมือ
  - ปิด: การ์ด "ตอนจบ"
- **คนดูจะเดาว่า / ที่จริง:**
  - เดาว่าจบที่ลุงหาย ครอบครัวเข้าใจกฎ → ที่จริงคำเดียวที่เด็กแอบกินก็พอ และต้นเหตุ (หมูป่วยตาย) ยังเดินทางต่อ
  - ทั้งเรื่องคนดูเห็นปอบเป็นตัวตลก แต่ปอบคือภาพแทนเชื้อที่ไปกับหมูป่วย

## เบาะแสข้ามตอน
1. ป้าย "หมูสด ราคาถูก" + "ตายเมื่อเช้า" (EP.1 ต้น) → กระบะคันเดิมไปหมู่บ้านถัดไป (EP.2 จบ)
2. พลาสเตอร์ที่นิ้วลุงทิด (EP.1 ต้น) → ลุงป่วยก่อนคนอื่น (EP.1 จบ)
3. ต้นกล้าแอบกินคำเดียว (EP.1 กลาง) + ไข้ต่ำในรถ (EP.2 กลาง) → ได้ยินไม่ชัด (EP.2 จบ)
4. หูปอบตกทีละนิดในทุกฉากที่ปอบกินดิบ
