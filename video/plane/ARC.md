# รอดคนเดียว (เครื่องบินตก) · เลน D · 31 ต.ค. 2569

เจ้าของสั่ง (31 ต.ค. 2569): "ถ้าวันหนึ่งคุณนั่งเครื่องบินไปเที่ยว…… ถ้าเครื่องบินตกมีคุณรอดชีวิตคนเดียว คุณจะทำยังไง"
+ "ทำเรื่องเวอร์ๆด้วยตามในหนัง" · "เรื่องล่ะ1 หรือ2ก้ได้" · "มันไม่ใช่หนังผีก็ไม่ต้องทำแบบหนังตะลุง" · "Icon เอฟเฟค ขยับอย่ากาก ทำดีๆดิ"
+ แชทประสานงานส่งโจทย์ที่เจ้าของแก้ (31 ต.ค. 23:2x): "…มีคุณรอดชีวิตคนเดียว บนเกาะแอดแสนตก คุณจะทำยังไง" → เกาะหินภูเขาไฟกลางมหาสมุทรแอตแลนติก
  · แบ่งความรู้กับเลน C (เรือล่มติดเกาะ): เลน D = เครื่องตก → ออกจากเครื่อง → รอดที่ซาก → ส่งสัญญาณให้คนมาเจอ · ห้ามสอนน้ำ/อาหาร/ที่พัก/ไฟ/อย่าดื่มน้ำทะเล
→ 2 ตอน ตอนละ 1 กฎ · ดูเดี่ยวรู้เรื่อง · แนวหนังภัยพิบัติ ไม่มีผี ไม่มีจอหนังตะลุง · โครงบท 69 วิ (growth-playbook) · ภาพแบบช่อง (ทะเลลด/นาทีก่อนจม)
สายการบินสมมติ "ฟ้าราม แอร์" (FR 623 ลิสบอน → นิวยอร์ก ข้ามแอตแลนติก) เครื่องสมมติ ไม่มีโลโก้จริง · ไม่มีศพ ไม่มีความรุนแรงแบบสยอง · ไม่ลอกหนัง/อุบัติเหตุจริงเรื่องใด

## ฮุกที่แชทประสานงานเลือก (F5 · 1 พ.ย. 2569) และตอนจบแบบ F6
- EP.1 ฮุก A: ในห้องโดยสาร หน้าต่างเห็นเครื่องยนต์ไฟลุก หน้ากากหล่น คิวกรีดร้องกอดกระเป๋า (ป้ายห้อยกระเป๋า = ชื่อเรื่อง) "ถ้าวันหนึ่ง… เครื่องยนต์ไฟลุก ตอนคุณบินกลางแอตแลนติก / {อย่าคว้ากระเป๋า}เด็ดขาด"
- EP.2 ฮุก B: คิวยืนริมหินมองไฟวิบวับอีกฝั่งอ่าว "ถ้าวันหนึ่ง… คุณเห็นไฟอีกฝั่งอ่าว ตอนติดเกาะ / {อย่าเดินไปหามัน}"
- EP.1 จบ: ออกมาได้ (โล่งใจ) → ไม่มีท่อนหน้า มีแค่เกาะ → "แต่อีกฝั่งอ่าว… มีควันลอยขึ้นมา"
- EP.2 จบ: เฮลิคอปเตอร์เจอ "เจอแล้ว!" (โล่งใจ) → "ซากส่วนหน้า… ว่างเปล่า!" → ย้อนตีสี่: ไฟฉายคือผู้รอดท่อนหน้า ที่เห็นไฟมือถือของคิว (ฝังไว้ในช็อตคืนแรก ลำแสงมือถือส่องออกจากประตูซาก)
  แล้วเดินออกจากซากมาหาเขากลางดึก → "คิวรอด… เพราะเขาอยู่กับซาก / แต่คนที่เดินออกไป… ยังไม่มีใครหาเจอ" (แทนตอนจบเดิม "ไม่ได้รอดคนเดียว")

## แนวคิด
เครื่องบินหักลงบนเกาะหินภูเขาไฟกลางแอตแลนติก ท่อนหางที่ คิว นั่งอยู่คนเดียว (เขาย้ายไปแถวหลังสุดที่ว่างเพื่อนอน) ไถลลงชายหินฝั่งหนึ่งของอ่าว แยกจากท่อนหน้า
EP.1 ของล่อใจคือ **กระเป๋ากล้องที่มีงานทั้งปี** · EP.2 ของล่อใจคือ **แสงไฟ "หมู่บ้าน" อีกฝั่งอ่าว** ที่ชวนให้เดินออกไป
หักมุมจบเรื่อง: แสงนั้นคือไฟฉายของผู้รอดจากท่อนหน้า ที่รออยู่กับซากเหมือนกัน · คิว "ไม่ได้รอดคนเดียว"

## กฎคล้องจอง (การ์ดความปลอดภัยในช่องหน้าที่นั่ง ที่คิวไม่เคยหยิบอ่าน · ขึ้นทุกตอน)
1. **ทิ้งกระเป๋า ก้าวออกไว** (EP.1 + นับแถวไปทางออก หน้า-หลัง)
2. **อยู่กับซาก อย่าจากไป** (EP.2 + ทำให้ซากเด่น ของสีสด/สะท้อนแสง)
- เรื่องนี้ไม่มีผู้ใหญ่ตั้งกฎ (คิวอยู่คนเดียว) กฎจึงมาจากการ์ดความปลอดภัยในโลกของเรื่อง ซึ่งเป็นของที่ "คนดูเกือบไม่อ่านจริง" (S13 ข้อ 2 แบบเรื่องไม่มีผี: ของที่ถูกมองข้าม แต่ที่จริงถูก)

## ความพลาดที่ฝังไว้ (ประโยคประจำช่อง "เขาพลาดไปแล้ว… ตั้งแต่วินาทีที่ X คุณเห็นไหม")
- EP.1 วิ ~5: คิวย้ายไปแถวหลังสุด ใส่หูฟัง ตอนแอร์ชี้ทางออกข้างหลัง → ในควันวิ่งไปข้างหน้าหาไฟ
- EP.2 วิ ~4: คิวใส่เสื้อชูชีพสีส้มไว้ใต้แจ็กเก็ตกันหนาว → เฮลิคอปเตอร์ผ่านไปไม่เห็น

## EP.1 ทิ้งกระเป๋า (~70 วิ)
ฮุก "ถ้าวันหนึ่ง… เครื่องบินของคุณกำลังตก / {อย่าหยิบกระเป๋า}" · ความรู้: 90 วินาที (S1) · เกือบครึ่งหยิบกระเป๋า + ขวางทางบ่อยที่สุด (S2) · นับแถวไปทางออก หน้าและหลัง (S3)
beat: ห้องโดยสารเอียง หน้ากากออกซิเจนหล่น กระเป๋าหล่น ป้ายห้อย "รอดคนเดียว EP.1" → มือเอื้อม กล่องแดง → 40 นาทีก่อน คิวย้ายแถว (ความพลาด) →
แผนที่ ลิสบอน→นิวยอร์ก ข้ามแอตแลนติก → เครื่องยนต์ซ้ายระเบิด → "ก้มหัว!" → เครื่องกระแทกยอดไม้ หักสองท่อน (แฟลช กล้องสั่น เศษ) → ควัน → คิวคว้ากล้อง →
การ์ด 90 วิ / เกือบครึ่ง / ขวางทาง → สายติดเก้าอี้ ไฟลาม → ทิ้ง วิ่งไปข้างหน้า (ไฟ) → "เขาพลาดไปแล้ว…" ย้อนเทป → ทางออกข้างหลังแถวเดียว →
การ์ดนับแถว → กระโดดออก → ควันจาง ไม่มีท่อนหน้า มีแค่เกาะกลางทะเล (ควันลอยอีกฝั่งอ่าว = เบาะแส) → การ์ดตอนต่อไป
## EP.2 อยู่กับซาก (~70 วิ)
ฮุก "ถ้าวันหนึ่ง… คุณรอดจากเครื่องบินตก… คนเดียว / {อย่าเดินออกไปหาคนช่วย}" · ความรู้: ซากเป็นที่หลบ (S5) · ซากหาง่ายกว่าคน ค้นตามเส้นทางบิน (S4) · ของสีสด/สะท้อนแสงบนซาก (S4)
beat: ซากหางบนชายหิน ลมหนาว แสงไฟอีกฝั่งอ่าว → กล่องแดง → คืนแรก หลบลมในซาก เสื้อชูชีพใต้แจ็กเก็ต (ความพลาด) → ตีสี่ แสงไฟ "หมู่บ้าน!" → คนจากฟ้า vs ซากจากฟ้า →
"ผมรอตรงนี้" → เช้า เฮลิคอปเตอร์บินผ่าน → "เขาพลาดไปแล้ว…" ย้อนเทป → วางเสื้อส้ม แผ่นโลหะสะท้อนแสงบนปีก → แสงวาบ เฮลิคอปเตอร์วกกลับ →
"เจอแล้ว!" → แสงเมื่อคืนคือไฟฉายของผู้รอดท่อนหน้า → "คิว… ไม่ได้รอดคนเดียว" → การ์ดจบ (กฎ 2 ข้อติ๊กครบ)
