# ท่อนซุงลงเขา: บทเรียนหลังถอดออก (เลน B · 1 พ.ย. 2569)

เจ้าของดูตัวที่ตัดใหม่แล้วตอบว่า "แย่มาก… ฮุกไม่ผ่าน" จึงถอดออก ไม่ลงคิว 3 พ.ย. ทั้งเรื่อง

## ฮุก 3 วิแรกของ EP.1 ที่ส่งไป (ตาม schedule และไฟล์ HQ)
| เวลา | ภาพ | เสียง / ข้อความบนจอ |
|---|---|---|
| 0.00 | มุมคนขับมองผ่านกระจกหน้า วันแดดจ้า รถบรรทุกซุงอยู่กลางจอ ห่างพอสมควร ครึ่งล่างของจอเป็นคอนโซลกับพวงมาลัย | เสียงโซ่ขาด (SFX) |
| 0.02–0.30 | โซ่เส้นหน้าดีดออก มีประกายไฟเล็กๆ ซุงท่อนบนกระโดดขึ้น | 0.15 ผู้บรรยายเริ่มพูด · ซับ "ถ้าวันหนึ่ง…" |
| 0.30–0.85 | ซุงหัวทิ่มหมุนเข้าหากล้อง จนหน้าตัดวงปีเต็มกระจกหน้า แล้วแฟลชขาว | ซับ "คุณขับตาม[รถบรรทุกท่อนซุง]" (เริ่ม 1.18) |
| 0.90–3.38 | ตัดไปท่อนซุงเป็นท่อนยาวกระแทกถนน กระดอนสองครั้ง แล้วกลิ้งไปค้างที่ราวกันตก กล้องจิกตอนเบรก | ซับ "ลงเขา" (2.9) |
| 3.38 | ตัดไปภาพมุมข้างขบวนรถที่สงบ และป้ายเขียวชื่อเรื่อง | คำสั่ง {อย่าขับชิดท้ายมัน} ที่ **3.43 วิ** |

hookcheck ผ่าน แต่เป็นการตรวจแค่ตามตัวอักษรของกฎ: S1 ขึ้นต้นด้วย "ถ้าวันหนึ่ง… คุณ", H2 เริ่มพูดที่ 0.15 วิ, H4 ขึ้นไม่เกิน 3.5 วิ แต่ส่วนที่ทำให้คนหยุดดูไม่ผ่าน

## ทำไมไม่ผ่าน (F5: "ฮุกต้องผ่านก่อนทำต่อ" · เฟรมแรกต้องเป็นภัยใหญ่ถึงชีวิตแบบหนัง เห็นทันที คนแปลกหน้าที่เลื่อนผ่านต้องหยุด)
1. **เฟรมแรกไม่น่ากลัว**
   - เฟรม 0 คือรถบรรทุกจอดนิ่งๆ กลางวันแดดใส อยู่ไกล มีคอนโซลกินครึ่งจอ
   - อันตรายคือโซ่เส้นเดียว ใหญ่ราว 5% ของจอ บนมือถือมองไม่ออก
   - คนที่เลื่อนผ่านเห็นแค่รถบรรทุกธรรมดา ไม่ใช่ภัยถึงชีวิต
2. **ภาพจุดพีกอ่านเป็นแผ่นไม้**
   - ซุงที่พุ่งเต็มจอเป็นวงกลมสีน้ำตาลมีวงปี คนดูอ่านเป็นจานไม้หรือแผ่นไม้ ไม่ใช่ท่อนซุงหนักเป็นตันที่กำลังจะทะลุกระจก
   - ไม่มีกระจกร้าว ไม่มีเงาหรือขนาดให้รู้ว่าหนัก ไม่มีแรงกระแทก
   - เป็นปัญหาเดียวกับที่เจ้าของติไอคอนว่า "เหมือนไม้"
3. **ไม่มีคนอยู่ในเฟรม**
   - ฮุกเป็นมุมกล้องคนขับล้วน ไม่มีหน้าคน ไม่มีสีหน้ากลัว ไม่มีใครให้เอาใจช่วย
   - ฮุกที่ผ่าน (ทะเลลด) มีคนกับของล่อใจอยู่ในเฟรมแรก
4. **อันตรายจบเองภายใน 3 วิ**
   - วิ 1–3 ซุงกระดอนไปค้างราวกันตก ไม่มีอะไรเกิดกับใคร เป็นจังหวะหักพลังตรงที่ควรตึงที่สุด
   - คนดูได้คำตอบว่า "ไม่เป็นไร" ก่อนจะได้ยินคำสั่ง
5. **คำสั่งไม่สวนสัญชาตญาณ และมาช้า**
   - "อย่าขับชิดท้ายมัน" เป็นเรื่องที่ทุกคนรู้อยู่แล้ว ไม่ได้ทำให้คนสงสัยว่า "ทำไมถึงห้าม"
   - ของทะเลลด "อย่าลงไปเก็บ (ปลา)" มีของล่อใจที่คนดูอยากทำเอง
   - คำสั่งขึ้นที่ 3.43 วิ หลังตัดไปภาพมุมข้างที่สงบ จังหวะเลยตกพอดีตอนที่ควรพีก
6. **หัวข้อ (F5)**
   - รถซุงลงเขาไม่ใช่ฉากที่คนดูตามหาเอง ภาพที่คนจำได้คือฉากซุงในหนัง Final Destination 2 แต่เราห้ามลอก จึงเหลือแค่ "รถบรรทุกบนทางลงเขา"
   - เทียบคู่แข่งที่วิวสูง (PROMPTKUB หัวข้อ 2: ซอมบี้ในสถานที่ไทย) ฮุกนี้แพ้ชัด
   - ไม่ได้เสนอฮุก 3 แบบให้เลือกตามขั้น F5 · ฮุกได้รับอนุมัติเป็นประโยค แต่ภาพเฟรมแรกไม่เคยถูกทดสอบในขนาดจอมือถือก่อนผลิต

## เทียบกับฮุกที่เจ้าของชอบ (ทะเลลด EP.1)
| | ทะเลลด | ท่อนซุงลงเขา |
|---|---|---|
| เฟรม 0 | ของล่อใจกำลังขยับ (ปลาดิ้นบนพื้นทะเลที่น้ำถอย) + สิ่งผิดปกติชัด (ทะเลถอยไกลเกิน) | รถบรรทุกนิ่งๆ ไกลๆ อันตรายเล็กจนมองไม่เห็น |
| คนในเฟรม | มี กำลังจะเดินลงไป | ไม่มี |
| ชื่อเรื่อง | อยู่ในโลกตั้งแต่เฟรมแรก (กดบนทราย) | อยู่บนป้ายเขียวที่ 3.4 วิ |
| คำสั่ง | สวนสัญชาตญาณ ขึ้นที่ 3.0 วิ ตรงจังหวะที่ภาพตึงที่สุด | เป็นสามัญสำนึก ขึ้นที่ 3.43 วิ หลังภาพคลายแล้ว |
| ตอนจบของ 3 วิ | อันตรายยังรออยู่ (คลื่นกำลังมา) | อันตรายจบไปแล้ว (ซุงค้างราว) |

## ครั้งหน้าต้องทำ
- ก่อนเขียนบท ส่งฮุก 3 แบบเป็น**ภาพนิ่งขนาดจอมือถือ**ที่วิ 0 / 1 / 2 / 3 พร้อมประโยค ให้เจ้าของเลือก ไม่ใช่ส่งแค่ข้อความ
- เฟรม 0 ต้องมีภัยใหญ่กินครึ่งจอขึ้นไป และมีคนที่กำลังจะโดน ตัวอย่างสำหรับเรื่องแนวนี้: ซุงทั้งกองไหลลงมาเห็นเต็มกระจกหน้า กระจกเริ่มร้าว หน้าคนขับตะโกนอยู่ในเฟรม
- ภาพต้องอ่านได้ใน 0.5 วิ ว่าหนักและอันตราย ใช้ขนาดเทียบกับคนหรือรถ ใช้กระจกแตก และมีเงากับแรงกระแทก ห้ามให้หน้าตัดไม้เต็มจอเฉยๆ
- อันตรายต้องยังค้างตอนวิ 3 ห้ามคลี่คลายในฮุก
- คำสั่งต้องสวนสัญชาตญาณจริง (คนส่วนใหญ่จะทำผิด) และต้องยืนยันแหล่งได้ ถ้าหาคำสั่งแบบนั้นที่มีแหล่งไม่ได้ ให้เปลี่ยนหัวข้อ
- hookcheck ผ่านไม่ได้แปลว่าฮุกผ่าน ต้องดูภาพนิ่งทุกครั้ง แล้วถามตัวเองว่า "ถ้าเลื่อนผ่าน จะหยุดไหม"

## 1. เนื้อเรื่อง

**โครงที่ทำไป**
- **EP.1 (70 วิ):** ซุงท่อนเล็กหล่นแล้วค้างราว → ป้าย 8 กม. → นับ 2 วิ → แตรลมจากคันหลัง → ป้าย 5 กม. ล้อมีควัน → แขนคนขับรถซุงโบก → เจ๋งจะเบรกแช่ → เกียร์ต่ำ → โค้งสุดท้าย → ก้านรัดดีด กองซุงเอียง
- **EP.2 (62 วิ):** ซุงไหลลงถนน → หยุดทัน → ซุงค้างราว → เจ๋งจะลงไปยก หนิงห้าม → โทร 3 เบอร์ → ปั๊มตีนเขา เซลฟี → รถก๊าซเลี้ยวเข้า → ป้ายส้ม → ถอยห่าง → คำถาม

**ปัญหา**
- **มันคือทิปขับรถเรียงต่อกัน มีฉากหนังแปะไว้**
  - ทุก 4–6 วิมีผู้บรรยายสอน 1 ข้อ (ระยะห่าง กระจก เกียร์ โทร ป้ายส้ม) แล้วภาพก็แค่ประกอบคำสอน
  - ตัวละครไม่ได้ตัดสินใจอะไรที่มีราคาต้องจ่าย มีแค่ "จะเบรกแช่" กับ "จะลงไปยก" ซึ่งโดนห้ามในประโยคเดียวแล้วจบ
- **เดิมพันไม่ชัด**
  - ไม่รู้ว่าเจ๋งกับหนิงกำลังไปไหน รีบเพราะอะไร หรือถ้าพลาดใครจะเสียอะไร
  - ไม่มีเวลาบีบ (ต้องไปให้ทัน ต้องพาใครไปส่ง)
  - ไม่มีความสัมพันธ์ให้ห่วง ตัวละครเป็นแค่คนพูดบรรทัดสอน
- **ความลุ้นไม่ต่อเนื่อง**
  - อันตรายเกิดแล้วจบทันที 3 ครั้ง: ซุงท่อนแรกค้างราว, คันหลังจี้แล้วก็แค่จี้, ซุงไหลแล้วหยุดทัน
  - "นาฬิกา" 8 → 5 → 2 กม. เป็นแค่ป้ายผ่านตา ไม่มีอะไรรอที่ปลายทาง
  - ทางหนีภัยที่ควรเป็นเส้นชัยถูกตัดออก เพราะหาแหล่งยืนยันไม่ได้ แต่ไม่ได้หาอะไรมาแทน
- **F6 กับเบาะแส**
  - ฝังเบาะแสไว้จริง (กระจังใหญ่ในกระจกมองหลัง ขอบป้ายส้ม เสียงฟู่)
  - แต่เบาะแสเป็นแค่ "รถใหญ่คันหนึ่ง" ภาพเดิมๆ ซ้ำทุกช็อต คนดูไม่มีเหตุให้สงสัยว่ามันคืออะไร
  - การเผยที่ปั๊มเป็นแค่รถจอดเฉยๆ กับควันที่ล้อ ภัยไม่ได้ใกล้ตัวละครจริง จึงไม่ระทึก
  - ตอนจบไม่ได้ทิ้งคำถามว่า "แล้วจะเกิดอะไรต่อ"
- **ฟีล Final Destination ไม่ถึง**
  - หัวใจของแนวนี้คือโชคชะตาไล่ล่า: ลางบอกเหตุ ความตายที่เกือบเกิดหลายครั้ง และอุบัติเหตุลูกโซ่ที่คนดูเห็นก่อนตัวละคร
  - เรื่องนี้ไม่มีลาง ไม่มีโมเมนต์ "เกือบตาย" ที่ใกล้จริง มีแต่ภัยที่ถูกกฎจราจรแก้ได้ทุกครั้ง
- **เทียบกับเรื่องที่คนดูเยอะ**
  - **ทะเลลด:** มีของล่อใจที่คนดูอยากทำเอง (ปลาดิ้นบนหาด ไลฟ์ไวรัล) ตำนานละบูนเป็นตัวแทนผี มีคนที่ห่วง (ยาย) ปมข้ามตอน และหักมุมที่ผูกกับความสัมพันธ์ (คอมเมนต์ยายพร)
  - **มือพราย / เห็ดปอบ:** ผีไทย 1 ตนเป็นภัยที่มีเจตนา ตัวละคร 3–4 คนพูด 40% มีมุก กฎคล้องจองของยาย และความเชื่อผิดที่ถูกหักล้างด้วยหลักฐาน
  - **ท่อนซุงลงเขา:** ภัยไม่มีเจตนา (ของหล่นตามกฎฟิสิกส์) ตัวละครพูดน้อย ไม่มีมุก ไม่มีของล่อใจ และกฎเป็นกฎจราจรที่ทุกคนรู้แล้ว

## 2. ภาพ (ดู postmortem-frames.jpg)

- **มุมกล้อง**
  - มุมคนขับใช้ไป 9 ช็อตจาก 18 ช็อตของ EP.1 โดยคอนโซลกับพวงมาลัยกินครึ่งล่างของจอ
  - สิ่งที่สำคัญ (รถซุง) อยู่ในแถบกลางจอที่สูงแค่ราว 25% ของจอ (เฟรม EP1-0:00, 0:00.6)
  - ฉากมุมข้างเป็นภาพกว้างนิ่ง รถตัวเล็ก (EP1-0:19)
  - ฉากปั๊มเป็นภาพกว้างระดับสายตาแบบเดิมเกือบทุกช็อต (EP2-0:37, 0:48)
- **ไม่มีโคลสอัพสีหน้า**
  - หน้าตัวละครใหญ่สุดคือในช็อตสองคนผ่านกระจกหน้า ราว 10% ของจอ มีพวงมาลัยกับคอนโซลบัง (EP1-0:06, EP2-0:06)
  - ไม่มีช็อตตา มือ หรือเท้าเหยียบเบรกระยะใกล้ ช็อตที่ควรพีกจึงเป็นแค่หน้าการ์ตูนอ้าปาก
- **แสงและบรรยากาศ**
  - กลางวันแดดจ้า ท้องฟ้าฟ้าใส มีเมฆขาว ทั้งเรื่องไม่มีเงามืด ฝน หมอกจริงจัง หรือแสงไฟหน้ารถตัดความมืด
  - EP.2 เป็นแสงเย็นสีม่วงชมพูที่ดูสบาย ภัยใหญ่ที่สุดของเรื่อง (รถก๊าซ) จึงอยู่ในบรรยากาศที่ผ่อนคลายที่สุด
- **ขนาดภัยในเฟรม**
  - โซ่ขาดราว 5% ของจอ
  - ซุงที่หล่นท่อนเดียวมีขนาดพอๆ กับรถ และกลิ้งออกไปข้างทาง
  - รถก๊าซในฉากเผยตัวเล็กกว่าตัวละคร และไกลกว่าตัวละคร (EP2-0:48)
  - ไม่มีช็อตที่ภัยกินจอมากกว่าครึ่งพร้อมกับมีคนอยู่ในเฟรม ยกเว้นซุงหน้าตัดที่ 0.6 วิ ซึ่งอ่านเป็นแผ่นไม้
- **ตัวละครแข็ง**
  - ในห้องโดยสารนั่งตรงนิ่ง เปลี่ยนแค่ตาและปาก
  - ที่ปั๊มยืนตรงคู่กันเกือบทุกช็อต ท่าเดียวคือยกมือถือ ไม่มีการหันหลังวิ่ง ดึงแขน หรือถอยหนีจริง (ใช้ moveTo เลื่อนตัวทั้งตัว)
- **ความลึกและกล้อง**
  - ส่วนใหญ่เป็นฉากแบนวางเป็นชั้นขนานกับจอ กล้องแค่ซูมช้าๆ หรือแพนเล็กน้อย กับสั่นแบบ rumble
  - ไม่มีกล้องที่เคลื่อนผ่านของ ไม่มีมุมต่ำหรือมุมสูงแบบหนัง ไม่มีการเปลี่ยนมุมเร็วตอนพีก
  - ฉากในรถเป็นกล้องตัวเดียวมองจากหน้ารถทุกครั้ง
- **เทียบเรื่องที่ผ่าน**
  - ทะเลลดกับมือพรายมีตัวละครเต็มตัวขยับในฉาก มีภัยตัวใหญ่ใกล้กล้อง มีแสงที่บอกอารมณ์ (กลางคืน ไฟฉาย คลื่นทะมึน) และมีของในโลกที่จับต้องได้
  - เรื่องนี้ทำของในโลกเพิ่มทีหลัง (ป้าย ฝาท้าย) แต่ตัวเรื่องหลักยังเป็นภาพรถวิ่งบนถนนกลางวัน

## ต้องทำต่างไปยังไงในเรื่องหน้า
1. **เดิมพันก่อนทิป:** ก่อนเขียนบท เขียน 1 ประโยคว่า "ใครจะเสียอะไร ถ้าพลาด และต้องไปให้ถึงไหนภายในเมื่อไร" ถ้าเขียนไม่ได้ ห้ามเริ่ม · ความรู้ต้องเป็นทางรอดของเดิมพันนั้น ไม่ใช่คำบรรยายแทรก
2. **ความลุ้นต้องสะสม:** วางอันตราย 3 ระดับที่ใหญ่ขึ้นเรื่อยๆ และห้ามให้อันตรายคลี่คลายเองก่อนตัวละครลงมือ แต่ละครั้งที่รอดต้องแลกด้วยอะไรบางอย่าง (เสียของ เจ็บ ทิ้งแผน)
3. **ภัยใหญ่ใกล้กล้องพร้อมคน:** ทุกตอนต้องมีอย่างน้อย 3 ช็อตที่ภัยกินจอเกินครึ่งและมีคนอยู่ในเฟรม · ทดสอบด้วยภาพนิ่งขนาดจอมือถือ ถ้ามองไม่ออกใน 0.5 วิว่าอันตราย ให้ทำใหม่
4. **โคลสอัพทุกจังหวะพีก:** ตา มือ เท้า หรือสีหน้าเต็มจอ ตัดสลับกับภาพกว้าง · ห้ามช็อตกว้างนิ่งเกิน 2 ช็อตติดกัน · ช็อตในรถห้ามให้คอนโซลกินเกิน 25% ของจอ
5. **แสงคือบรรยากาศ:** เลือกช่วงเวลาและอากาศที่น่ากลัวโดยตัวมันเอง (กลางคืน ฝน หมอกจริง ไฟหน้ารถ ไฟแดงกะพริบ) ห้ามกลางวันแดดใสในเรื่องระทึก เว้นแต่ใช้เป็นจังหวะ "โล่งใจ" ก่อนหักมุม
6. **ตัวละครต้องขยับเต็มตัว:** วิ่ง ดึง ล้ม หันหลัง เอื้อมมือ อย่างน้อย 1 ท่าใหญ่ต่อช็อตที่มีตัวละคร · ตัวละครพูด 30–40% และมีมุกแบบคนจริง (สูตรเสียงกอย)
7. **หักมุมต้องเข้าใกล้ตัว:** ตอนเผย ภัยต้องอยู่ใกล้ตัวละครที่เราห่วงในเฟรมเดียวกัน และเบาะแสที่ฝังต้องแปลกพอให้คนดูสงสัยตั้งแต่ครั้งแรก ไม่ใช่ภาพธรรมดาที่เห็นซ้ำ
8. **หัวข้อต้องมีภาพจำแบบหนัง:** ก่อนรับหัวข้อ ให้หาภาพเฟรมแรกที่คนดูจำได้ทันที (เทียบ PROMPTKUB) และคำสั่งที่สวนสัญชาตญาณจริงและมีแหล่ง · ถ้าความรู้ที่ยืนยันได้เหลือแต่เรื่องที่ทุกคนรู้ ให้แจ้งผู้ประสานงานว่าหัวข้อนี้ไม่พอ ก่อนลงมือผลิต
