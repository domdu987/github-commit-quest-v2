# ควันหลง: ผีหอพัก มุมมองคนที่หนึ่ง (3 ตอน)

**ผู้ใช้สั่ง (24 ต.ค. 2026):**
- "ทำเรื่องใหม่" + "มุมมองคนที่หนึ่ง"
- "เอาให้ดีกว่านี้ เอฟเฟค มุมกล้อง มิติภาพ ความสมูท การเดินเรื่อง icon ต่างๆ ขอแบบระดับเทพกราฟฟิก"
- เลือกเรื่องจากตัวเลือกแบบ "ไม่ระบุ" จึงใช้ตัวที่แนะนำ: **ไฟไหม้หอพักตีสอง**

**มุมมองคนที่หนึ่ง:**
- คนดูคือ "คุณ" เห็นผ่านตาตัวเอง ไม่เห็นหน้าตัวเองเลย
- เห็นแค่มือกลมสองข้าง (`Hands.fist`) มือซ้ายถือมือถือที่เปิดไฟฉาย
- ได้ยินเสียงหายใจและหัวใจตัวเอง
- กะพริบตา = ตัดฉาก, ไอ = จอสั่นและเบลอ
- ผู้บรรยาย (Puck) พูดกับ "คุณ" ทั้งเรื่อง ตัวเอกไม่มีเสียงพูด

**ตำนานในเรื่อง (แต่งขึ้น):**
- หอพักหญิงเก่าแปดชั้นกลางเมือง ไฟไหม้ชั้นเจ็ดเมื่อปี 2539
- นักศึกษาชื่อ **ดาว** ห้อง 714 ตายในคืนนั้น
- หลังประตูห้อง 714 ยังมีป้ายหนีไฟเก่าที่มีลายมือของเธอเขียนเพิ่มไว้
- คนในหอเล่าว่าทุกคืนที่มีควัน ดาวจะเคาะประตูชวนคนให้ "เปิด" ให้ "ขึ้นลิฟต์" ให้ "กลับขึ้นไป"

**กฎของเรื่อง** (ลายมือบนป้ายหนีไฟ, ขนานกันสามท่อน quote ได้):

> **ประตูร้อน อย่าเปิด / ลิฟต์มารับ อย่าขึ้น / ออกมาแล้ว… อย่ากลับ**

- บรรทัด 1 = EP.1 · บรรทัด 2 = EP.2 · บรรทัด 3 = EP.3

**ตัวละคร (ใหม่ทั้งหมด):**
- **คุณ**: นักศึกษาปี 1 ห้อง 714 (ไม่มีหน้า ไม่มีเสียง)
- **แพร** (19): รูมเมท ขี้ตกใจแต่กล้า · เสียง Callirrhoe
- **ดาว**: ผีนักศึกษาปี 2539 ชุดนักศึกษาไหม้เขม่า หน้าอยู่ในเงา ป้ายชื่อ "ดาว 714" · เสียง Achernar (ต่ำ ช้า ชัด ไม่กระซิบ)
- **เจ้าหน้าที่ดับเพลิง** (ปลายสาย / EP.3) · เสียง Charon

**การ์ดเปิด/ท้ายจากโลกของเรื่อง:**
- EP.1 เปิดด้วยฉากชื่อเรื่องบนท้องฟ้า (`Opener`) แล้วดิ่งลงมาที่หอพักที่ชั้นเจ็ดมีไฟ
- EP.2–3 เปิดด้วยแผนผังหนีไฟ "คุณอยู่ที่นี่ · ชั้น 7"
- การ์ดท้าย = พวงกุญแจห้อง "714" ด้านหลังเขียนด้วยลายมือ "ตอนที่ N+1 · …"
- ตอนจบ (EP.3) ไม่มีซิกเนเจอร์

**ยืนยันไม่ได้ (ห้ามพูดเป็นความรู้ในคลิป):**

- Red Cross (403) และ NFPA (ไม่มีเนื้อหา / 404) อ่านไม่ได้ ไม่ใช้

## โครงเรื่อง 3 ตอน

### EP.1 ประตูร้อน (~1:45)

- **hook:** ถ้าวันหนึ่ง… คุณตื่นมาตอนตีสอง ได้กลิ่นควัน แล้วมีคนเคาะประตูตะโกนว่าไฟไหม้ → **อย่าเพิ่งเปิด**
- **ความรู้ (Ready.gov):**
  - ไฟอันตรายถึงชีวิตได้ในสองนาที
  - แตะลูกบิดกับประตูก่อน ถ้าร้อนหรือมีควันลอดรอบประตู อย่าเปิด ใช้ทางอื่น
  - ควันกับแก๊สพิษฆ่าคนมากกว่าไฟ / ควันรวมที่เพดานก่อน → ก้มลงคลานต่ำ
  - ออกไม่ได้: ปิดประตู เอาผ้าอุดร่อง โทรแจ้งดับเพลิง บอกว่าอยู่ตรงไหน ส่งสัญญาณที่หน้าต่างด้วยไฟฉายหรือผ้าสีอ่อน
- **ตัวนับ:** นาฬิกาจับเวลา 2:00 มุมจอนับถอยหลังจริงตลอดตอน + แบตมือถือ + ระดับควันจากเพดานที่ลดลงมาเรื่อยๆ
- **ภัยที่คนดูเห็นก่อน "คุณ":**
  - ตอนคลานบนพื้น เห็นมือไหม้ดำห้อยลงมาจากเตียงของแพร
  - ตอนส่งสัญญาณที่หน้าต่าง เงาสะท้อนในกระจกเป็นผ้าห่มบนเตียงแพรค่อยๆ ลุกขึ้นนั่ง
- **ซิกเนเจอร์:** [ไม่เปิดประตูร้อน ✓, คลานต่ำใต้ควัน ✓, อุดร่องประตู ✓, ??? ✗]
- **หักมุม:**
  - คนที่เคาะประตูตั้งแต่แรกคือแพร รูมเมทตัวจริงที่ออกไปเข้าห้องน้ำรวมสุดทางเดิน
  - ส่วนคนที่นอนอยู่บนเตียงแพรทั้งคืนคือดาว: "ร้อนจัง… เปิดประตูให้พี่หน่อยสิ"
- **ตัวเลือกท้าย:** "เปิดประตู / อยู่ในห้องกับเธอ" ถูกดึงไป "เปิดประตู…"
- **การ์ดท้าย:** พวงกุญแจ 714 "ตอนที่ 2 · ลิฟต์มารับ"

### จำนวนตอน: 4 (ผู้ใช้ "ไม่จำกัด ep ทำเท่าไหร่ก็ได้ให้เนื้อเรื่องสมูท")

กฎสามบรรทัดแบ่งเป็นสี่ตอน: ประตู (EP.1) · ทางเดิน + ปิดประตูตามหลัง (EP.2) · ลิฟต์/บันได (EP.3) · ข้างนอก ห้ามกลับ + ความจริงของดาว (EP.4 ตอนจบ ไม่มีซิกเนเจอร์)
ผีทุกตัวเป็นแบบกองกอย (เงาดำ ผมเป็นเส้น ตาเรือง) · ประวัติดาวเล่าแบบหนังตะลุงใน EP.4

### EP.2 ทางเดินมืด (โครง)

- **เปิด:** ภาพเดียวกับท้าย EP.1 (ดาวนั่งบนเตียงแพร มือคุณอยู่บนลูกบิด)
- **hook:** ถ้าวันหนึ่ง… คุณต้องออกไปในทางเดินที่มีควัน → **เปิดช้าๆ**
- **ความรู้:**
  - Ready.gov: ลูกบิดเย็นลงแล้ว (เจ้าหน้าที่ฉีดน้ำทางเดิน) ถ้าจะเปิดประตู ให้เปิดช้าๆ พร้อมปิดทันทีถ้าเจอควันหนาหรือไฟ
  - Ready.gov: ไฟมืด ควันดำทำให้มองไม่เห็น → คลานต่ำ คลำผนังไป
  - USFA: ออกจากห้องแล้วปิดประตูตามหลัง (ปิดขังดาวไว้ในห้อง 714 → เสียงเคาะจากข้างในแทน)
  - USFA: ดึงสัญญาณเตือนไฟไหม้ระหว่างทาง
- **เรื่อง:** เจอแพรในทางเดิน จับมือกันคลาน
- **จัมป์สแกร์:** กดสัญญาณเตือน ประตูห้องทุกบานตลอดทางเดินเปิดออกพร้อมกัน มีตาเรืองแสงในแต่ละห้อง
- **ปมค้าง:** ลิฟต์ "ติ๊ง" เปิดรอ สว่าง ไม่มีควัน ดาวยืนอยู่ข้างใน "ลงด้วยกันไหม" → ตัวเลือก "ขึ้นลิฟต์ / ไปบันได" ถูกดึงไป "ขึ้นลิฟต์…"

### EP.3 ลิฟต์มารับ (โครง)

- **ความรู้:**
  - USFA: ใช้บันได อย่าใช้ลิฟต์ (เว้นแต่เจ้าหน้าที่ดับเพลิงสั่ง)
  - Ready.gov: เสื้อติดไฟ หยุด ล้มลง เอามือปิดหน้า กลิ้ง (ชายแขนเสื้อแพรติดไฟจากฝ้าเพดานที่ร่วง)
- **เรื่อง:** แพรดึงคุณออกจากลิฟต์ ประตูลิฟต์ปิดพร้อมรอยยิ้มของดาว ตัวเลขชั้นลงไป 1 แล้วขึ้นกลับมา 7
- **จัมป์สแกร์:** ในบันไดหนีไฟ ไฟฉายส่องไปเจอเงาดำห้อยหัวลงมาจากช่องบันไดชั้นบน
- **ปมค้าง:** ป้ายบันไดลงมาเรื่อยๆ 6, 5, 4… แล้วกลับเป็น "7" ข้างประตูมีกุญแจห้อง 714 แขวนอยู่

### EP.4 ออกมาแล้ว… ห้ามกลับ (ตอนจบ, โครง, ไม่มีซิกเนเจอร์)

- **ความรู้:**
  - USFA: ไปที่จุดรวมพลข้างนอกแล้วอยู่ตรงนั้น / บอกเจ้าหน้าที่ว่ามีคนติดอยู่ข้างใน
  - (ทบทวน) ไฟอันตรายถึงชีวิตได้ในสองนาที
- **เรื่อง:**
  - ออกมาถึงข้างนอกได้ เสียงแพรเรียกจากหน้าต่างชั้นเจ็ดให้กลับขึ้นไป ทั้งที่แพรยืนอยู่ข้างคุณ → ห้ามกลับ บอกเจ้าหน้าที่แทน
  - เจ้าหน้าที่เปิดรายชื่อ: "ห้อง 714 ไม่มีใครพักมาตั้งแต่ปี 2539"
- **เฉลย (หนังตะลุง):** ปี 2539 ดาวออกมาได้แล้ว แต่กลับขึ้นไปช่วยรูมเมท รูมเมทรอด ดาวไม่ได้ออกมา
- **ปมค้างปิดเรื่อง:** รูมเมทคนนั้นคือป้าศรี แม่บ้านที่ยืนอยู่ข้างคุณตอนนี้ ป้าศรียื่นกุญแจห้องใหม่ให้: "ห้อง 714 ว่างแล้วนะ"
