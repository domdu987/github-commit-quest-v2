### 2.2 เสียง

  - tempo: "เสียงกอย" 1.18, "ชั้น 23" 1.2, "เอาชีวิตรอด 99 วัน" **1.24** (วัดได้ ~11–12 ตัวอักษร/วิ เท่าคลิปต้นแบบใหม่ ใช้ 1.24 กับตอนใหม่)

- **ดนตรี:** `video/music/suno1.mp3` (Suno ที่ผู้ใช้อัปโหลด) อยู่ใต้เสียงพูดชัดเจน

- `craft{t,end,title,who,parts:[{icon,label,at}],build,result:{icon,label},stats:[{label,v,max}],upgrade:{at,part:{icon,label},label,stats:[{v}]},top}` สูตรประดิษฐ์: ช่องวาดด้วยปากกา → ชิ้นส่วนตกลงช่อง+ติ๊กแดงที่ `at` → `build`: ชิ้นส่วนกระโดดรวม หมึกกระจาย แฟลช ผลลัพธ์เด้ง ตรา "สำเร็จ" ขีดสถิติ (จังหวะกระแทก = build+0.55) → `upgrade.at`: ชิ้นพิเศษ + ตรา "+1" ชื่อเปลี่ยน ขีดแดงยืด (จังหวะ = at+0.85)
- `countdown{t,from,to,label,warn,end,top,tick}` นับถอยหลัง: กระดาษเลขปลิวทุกวินาที (`t + i*tick`) วงแดงวาดปิดตามเวลา ≤warn แผ่นแดง + ตรา "เร็ว!" + `#fxred` กะพริบ + สั่นแรงขึ้น · ถึง 0 แฟลช · ช็อตต้องทำเหตุการณ์จริงเอง (ตัดดำ/ประตูปิด) · ใช้ 2 ช็อตได้ (20→8 แล้วตัดไป 5→0 เหมือนเดโม) · เสียง: mix.py ใส่ `tick` ทุกวินาที + heartbeat ถี่ขึ้น
- **คราฟ = มุมคนที่ 1 (ผู้ใช้สั่ง):** ช็อต `craft` ในเดโม = โต๊ะเต็มเฟรมล่าง + ของวางบนโต๊ะ + `Hand.grip` สองข้าง (สีผิวจาก `Rig.CAST.<who>`) ขยับด้วย tween `attr:{transform}` เป็นสตริง `translate() rotate() scale()` รูปแบบเดียวกันทุกคีย์ · มือซ้าย = `translate(x,y) rotate(90) scale(-s,s)` มือขวา = `rotate(-90) scale(s,s)` (นิ้วโอบด้ามจากด้านล่าง ปลายแขนชี้ลงมุมล่างซ้าย/ขวา) · ของที่ถูกหยิบเป็นลูกของกลุ่มมือ (เปิด/ปิด opacity ตอนรับ-วาง) · พันเทปใช้ onUpdate วงรีรอบจุดต่อ · ยกพุ่งใส่กล้องด้วย scale/y บนกลุ่ม `cp-held` (กลุ่มที่ไม่มี attribute transform ของตัวเอง — **ห้ามผสม tween transform ของ GSAP กับ attr transform บน element เดียวกัน**)
- **กับดัก:** stroke-dasharray/dashoffset ที่จะ tween ด้วย `attr` ต้องอยู่เป็น attribute ใน markup ห้ามใส่ใน CSS (CSS ชนะ attribute → เส้นไม่โผล่) · `PAPERS()` pad เลขตามหลักสูงสุดของค่าที่ให้ ตอนหาแผ่นที่จะปลิวต้อง pad แบบเดียวกัน (เดโมเคยค้างที่ "5" เพราะ pad คนละแบบ) · ตรวจสถานะการ์ดที่เวลาใดๆ ด้วย `node video/tools/probe-card.js <file-url>` (Playwright seek แล้วอ่าน DOM)

### 2.5 สูตรเขียนบทให้ติดหูและลุ้น (ใช้ทุกเรื่อง)

> สูตรเต็ม หลักฐานวิจัย และ checklist ก่อนสร้างเสียงอยู่ใน **`video/RETENTION.md`** อ่านคู่กันเสมอ

1. **ประโยคสั้น 2–5 คำ** แตกหนึ่งความคิดเป็น 2–3 ท่อน ซับแตกตามท่อน
   - ข้อระวังใหม่: อย่าแตกจนเงียบบ่อย ดูหัวข้อ 2.2.1 ต้นแบบพูดต่อเนื่อง ~4 วิ
2. **hook = สถานการณ์ + คำสั่งสวนสัญชาตญาณ** ("ถ้าวันหนึ่ง… คุณโดนกัด / แผลแค่ถลอก / {อย่าล้างแค่แป๊บเดียว}")
3. **ความรู้ = เหตุแล้วผล มีตัวเลขจริง** และขึ้นกราฟิกตัวเลข (เช่น "4 ลิตร × 3 คน × 3 วัน = 36 ลิตร")
4. **จุดหักทุก 10–15 วิ** ("แต่…", "ปัญหาใหม่…") แก้ปัญหาหนึ่งได้ต้องเจอปัญหาใหม่ทันที
5. **ประโยค quote ได้ 1–2 ประโยคต่อตอน** และกฎของเรื่องต้องคล้องจอง (กอย/ถอย/คอย, บอก/ออก/ตอบ)
6. **คำกระแทกคำเดียวขึ้นกล่องแดง**
7. **ตัวนับที่ลดลงเรื่อยๆ** ตลอดเรื่อง
8. **ประโยคปิดตอนสั้นหลอน 2 ท่อน** + ตัวเลือกที่ถูกดึง
9. **เล่าเหมือนพูดกับคนดู ("คุณ")** บทพูดตัวละครน้อยและสั้น
10. **มีภัยที่คนดูเห็นก่อนตัวละคร** (ระเบิดใต้โต๊ะ) อย่างน้อย 1 ฉาก
11. **เหตุการณ์ในเรื่องต้องส่งผลกับทุกช็อตหลังจากนั้น** (ผู้ใช้จับได้: "มันต้องขึ้นทางบันไดมั้ยนะ")
    - คนดูถามเสมอว่า "ทำไมไม่ทำแบบง่ายๆ" ถ้าเหตุผลมีแค่ในหัวคนเขียน ต้องใส่ให้เห็นในภาพ
    - ตัวอย่าง ชั้น 23: ไฟดับ → ปั๊มน้ำหยุด **และ** ลิฟต์ตาย ก๊อกแห้ง ไฟเพดานดับ จอลิฟต์ดับ ทุกช็อตหลังจากนั้นต้องเป็นแบบนั้น
    - ก่อนเรนเดอร์ไล่เช็กทุกช็อตหลังเหตุการณ์ใหญ่ว่ายังมีอะไรที่ "ไม่ควรทำงานแล้ว" โผล่อยู่ไหม

### 6.1 `engine.js`: shot engine

```js
add("key", {
  set: "condo", setOpts: { id: "nw", time: "dusk" }, dark: 0.1, blur: { far: 4, mid: 6, set: 6, fg: 8 },
  cam: { keys: [{ t, ...fr(wx, wy, s, sx, sy), drift: { x?, y?, s? }, glide? }] },   // หรือ { from, to }
  shake: (t) => px,
  actors: [{ who: "khao", x, y, s, flip?, prop?, from?, until?, blinks?, moveTo?: { x, y?, at?, dur, ease? },
             track: [{ t, mode, opts?, blend?, eyes, mouth, look, startle? }] }],
  captions: caps("key"),                      // ซับแตกท่อนจาก schedule
  bubbles: [bub("key", lineIndex, x, y, tailX)],
  ui: [{ type: "...", t, end, ... }],         // GameUI
  extra(L, id) { /* ใส่ SVG ก่อนสร้างตัวละคร */ },
  fx(tl, id, t0, L) { /* tween หลังสร้างทุกอย่าง */ },
});
```

- **ชั้นภาพ:** sky / far / mid / set / act / fg (parallax), glow (ตาม set), light (screen-space ไม่ขยับตามกล้อง)
- **ตัวละครถูกสร้างหลัง `extra()`** ของที่ต้องอยู่หน้าตัวละครให้ย้ายด้วย `TOP(L, el)` ใน `fx()`
- **helper ใน head.part:**
  - `vo(k,i)`, `voEnd(k,i)`, `F(k,i,j)` (เวลาเริ่มท่อน j), `D(k)`
  - `fr(wx,wy,s,sx,sy)` วางจุดในฉากไว้ตำแหน่งบนจอ
  - `caps(k, lines?, {quote})`, `bub()`, `shakeH(t)`
- **helper ใน shots.part:**
  - `split(k, at, A, B)` = ช็อตเดียวสองฉาก, `capsFrom(k, at)`
  - `knocks(tl, sel, t0, n, gap)`, `taps()`, `TOP()`

## 7. กับดักที่เจอแล้ว (อย่าพลาดซ้ำ)

### Timeline และ lint

- ทุกอย่าง deterministic: สุ่มด้วย seeded LCG ห้าม `Math.random`/`Date`
- timeline ต้อง paused และ register ที่ `window.__timelines["main"]`
- tween ที่เริ่มทีหลังต้องใส่ `immediateRender:false`
  - คอมโพเนนต์ที่ต้องซ่อนก่อนเวลาให้ `tl.set(...,{opacity:0}, t0)` ด้วย
- lint ไม่ยอมให้มี template literal ใน `querySelector` → ใช้ `getElementById(id).querySelectorAll(".x")`
- โหมด Rig ที่ไม่มีจริงทำให้ทั้ง timeline พัง ต้องประกาศใน template ทุกตอนที่ใช้

### ลำดับการวาดและ GSAP

- `Fx.glitch` จบด้วย `clearProps`
- gradient ของแผงทับสีพื้น → ตั้ง `backgroundImage:"none"` ก่อนเปลี่ยนสี
- GSAP `y`/`rotation` บน `<g>` ที่มี transform translate+scale หรือ svgOrigin แปลกๆ อาจหาย/ค้าง → tween `attr: { transform: "..." }` แทน (เช่น เสื้อกันฝน ประตู)
- id ของ set ≠ id ของช็อต: ของที่ set สร้างต้องอ้างด้วย `setOpts.id`
- `mark()` ของ GameUI ใช้ใน template ไม่ได้ → `Ui.mark`
- **GSAP `x`/`y` (รวม `fromTo({x:0})`) บน `<g>` ที่มี attribute transform จะล้าง translate เดิมทิ้ง** ตัวจะกระโดดไปมุมจอ (เจอใน ชั้น 23 EP.2–3: ซอมบี้ในกระจก, ถูกฟาดกระเด็น, มือคลาน, รถในขบวน)
  → ใช้ `moveTo` ของ engine, `route()`, tween `attr.transform` หรือห่อด้วย `<g id>` ชั้นนอกที่ไม่มี transform แล้วขยับตัวนอก
- **GSAP x/y บน `<g transform="translate(...)">` ล้าง translate ทิ้ง (เจอซ้ำใน เอาชีวิตรอด 99 วัน EP.1 ถึง 8 จุด: หมุดแผนที่ มือเด็ก มือครูพิม นิ้วเจ๊หงส์ เป้ กระป๋องที่ปัด)** → ทุกอย่างที่มี transform attribute ให้ tween `attr: { transform }` หรือห่อ `<g id>` ชั้นนอก
- ของใน `L.fg` มี parallax 1.5 และ scale ต่างจาก set: พิกัดบนจอไม่เท่าพิกัดโลก (นิ้วเจ๊หงส์หลุดจอ) คำนวณจาก `translate(540 960) scale(1+(s-1)*1.5) translate(-540 - x*1.5, -960 - y*1.5)` หรือ snapshot เช็ก
- ของที่ลูกของ `<g transform>` ใช้พิกัด**สัมพัทธ์** (กระป๋องบนชั้นในตลาด) อย่าใส่พิกัดโลก
- ตะเกียง/ของตกแต่งบังของสำคัญ (ตะเกียงบังกระป๋องบวม) → เช็ก snapshot ทุกช็อตที่มีของสำคัญ
- `.bubble` วางด้วย `left:x` (ขอบซ้าย ไม่ใช่กลาง) ข้อความยาวล้นจอ → ใน head.part ใส่ `.bubble { white-space: normal !important; max-width: 640px; text-align: center; }`
- ตัวละครนั่งต้องมีของรองนั่ง (`STOOL(x)`, `CHAIR(x,d)` ใน shots.part ชั้น 23) ไม่งั้นลอย
- เลนส์ตาแมวอยู่ชั้น light (screen-space) แต่โลกซูมได้ → ตั้งกล้องให้หัวตัวละครอยู่กลางวง `fr(x, headY, s, 540, 960)`
- นิ้ว/ไม้เท้าที่ยาวเกินจะทะลุพื้น ใช้ไม้เท้าใหม่ใน template "เสียงกอย" EP.3 / "ชั้น 23"

### TTS และ Whisper

- TTS พูดซ้ำ → "พูดประโยคนี้แค่ครั้งเดียว ไม่พูดซ้ำ"
- 422: ขึ้นต้น "แต่…/และ…" + ellipsis, และ style ที่ใส่ "ออกเสียงตัวสะกดทุกคำให้ชัด" โดนปฏิเสธบ่อย
- 429 = rate limit (รอแล้วลองใหม่), 403 TOP_UP = เครดิตหมด
- faster-whisper ส่ง path ไฟล์ไม่ได้ (av เวอร์ชันไม่ตรง) → decode ด้วย ffmpeg เป็น numpy แล้วส่ง array
- Whisper เดาคำตามบริบท เสียง "ถูกทาก" ก็ถอดเป็น "ถูกทาง" → คำสำคัญที่ตัวสะกดกำกวม ให้ลากเสียงหรือให้ผู้ใช้ฟัง
- style ที่มีคำว่า "กระซิบ" ทำให้ฟังไม่ออก (d04 เดิม CER 0.37) → ใช้ "พูดนุ่มๆ/เสียงต่ำ แต่ชัดทุกคำ ไม่กระซิบ" แทน
- style "ช้า เว้นจังหวะ" ได้เสียงชัดแต่ยาว `voice_qa.py` จะติด LONG แล้วอัดใหม่จนได้ take ที่สั้นแต่เพี้ยน
  → อย่าเชื่อ `--fix` อย่างเดียวกับบรรทัดสำคัญ ให้เทียบทุก take × หลาย tempo แล้วเลือกเอง (d04: take 0 tempo 1.08)
- Whisper ไม่นิ่งกับตัวสะกดท้ายคำ ("ตอบ" ↔ "ต่อ") แค่เปลี่ยน tempo ก็ได้ผลต่างกัน ให้ลองหลาย tempo ก่อนตัดสิน

### shell และเครื่องมือ

- ห้าม `pkill -f "python3 mix.py"` (ฆ่า shell ตัวเอง) ใช้ pattern แบบ `"hyperframes@0.8.18[5] render"`
- เรนเดอร์ด้วย `nohup ... &` ใน Bash ธรรมดาโดนยกเลิก (`render_cancelled_parent_exited`) ต้องใช้ Bash แบบ `run_in_background` เท่านั้น
- งาน background มีเพดาน 2 ชม. เรนเดอร์หลายตอนต่อคิวกันในคำสั่งเดียวจะโดนตัดกลางทาง → สั่งทีละตอน (หรือ 2 ตอนพร้อมกันคนละคำสั่ง)
- Monitor ที่ grep "error" จะจับข้อความ lint ของเรนเดอร์ → กรอง `lint|Continuing render` ออก
- `npx hyperframes check` หมดเวลาบ่อย ใช้ headless_shell ดู console แทน

### การจัดเฟรม

- **`glide` ของคีย์กล้อง = ระยะเวลาของการเลื่อนที่ "จบ" ที่ t ของคีย์นั้น** (เริ่มที่ t − glide) ไม่ใช่เริ่มที่ t · ถ้าใส่ `{ t: 6.2, glide: 6.5 }` กล้องจะเริ่มเลื่อนตั้งแต่ก่อนช็อตเริ่มและทับคีย์ก่อนหน้าทั้งหมด (EP.2 ช็อต count เคยพังแบบนี้: ให้ใส่ t = เวลาจบจริง เช่น `{ t: 12.9, glide: 6.5 }`)
- rig ที่วางด้วย `behind()` อยู่ในชั้น mid (parallax .6) พิกัดจึงเลื่อนจากที่คิดเมื่อกล้องไม่อยู่ใกล้ค่าเริ่มต้น และท่า `lie` ยืดไปทาง −x ~500 px จากจุดวาง (ภูหน้าประตูต้องวางที่ x≈900 ให้ตัวนอนอยู่ในช่องประตู 444–896) · ตรวจตำแหน่งจริงด้วย `node video/tools/probe-card.js` แบบดัดแปลง (getBoundingClientRect)

- **ฉากที่ต้องอ่านออกว่าเป็นของอะไร (บันได, ตึก, ห้อง) ต้องมีรายละเอียดที่บอกชนิดของมัน** ไม่ใช่รูปทรงนามธรรม
  (ช่องบันไดแบบกรอบสี่เหลี่ยมซ้อนกันผู้ใช้ดูไม่ออก ต้องมีขั้นบันได ราว ชานพัก และมุมมองบุคคลที่ 1 เช่นมือจับราว)
- **ตัวละครต้องมีตัว** หัวลอยๆ มีคอแท่งเดียวผู้ใช้หัวเราะ ("หัวซอมบี้ทำไมเป้นงั้น") ต้องมีไหล่ เสื้อ แขน แม้จะเห็นแค่ครึ่งบน
- ป้ายที่มีไฟในตัว (ป้ายทางหนีไฟ) วาดใน `L.glow` เหนือความมืด ไม่งั้นโดน `dark` กลบจนอ่านไม่ออก
- แก้ `head.part` / `shots.part` / `foot.part` แล้วต้อง `cat head.part shots.part foot.part > ep.tmpl.html` ก่อน `make.py` (ลืมแล้วช็อตใหม่ไม่ขึ้น จอดำ) · เอาชีวิตรอด 99 วัน มี `pk.part` คั่นระหว่าง head กับ shots
- `Write` ไฟล์ที่ยังไม่ได้ `Read` ในแชทนั้นจะถูกปฏิเสธ ("File has not been read yet") → Read ก่อน หรือเขียนด้วย python heredoc
- เกรดสี (`GRADE` filter บน world + tint multiply) ทำให้เรนเดอร์ช้าลงกว่าเดิม อย่าใส่ `backdrop-filter` หลายชั้นซ้อน

- ตัวละครหลุดขอบ ป้ายตกจอ พื้นไม่พอตอนกล้องเลื่อน UI บังหน้า
- ทุกครั้งที่เปลี่ยนกล้องให้ snapshot ก่อนเรนเดอร์
