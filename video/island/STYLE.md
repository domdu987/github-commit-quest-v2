## 0. สัญญาที่ทุก lib ต้องทำตาม
- ไฟล์ใหม่ใน `hf/lib/`: `isl.js` (ฉากเกาะ/ทะเล/เรือ), `islcast.js` (ตัวละคร), `islui.js` (การ์ด ไอคอน จอเงา), `islmap.js` (แผนที่ 3 มิติ + ภาพผ่าครึ่งร่างกาย)
  - ลำดับโหลดใน `head.part`: `isl.js` `islmap.js` `islui.js` หลัง `tideui.js` ก่อน `rig2.js` · `islcast.js` หลัง `tidecast.js` · เพิ่มชื่อในลิสต์ copy ของ `make.py`
- โครงไฟล์แบบ `tide.js`: `(function(){ const { mk, f1, put, blob } = Pop2; … Object.assign(Sets, {...}); window.Isl = Isl; })()`
  gradient ใหม่ขึ้นต้นด้วย `is` (`isSky…`) ใส่ `Sets.DEFS +=` · ใช้ `Qk.cs` (เงาสัมผัส) `Qk.grain` `Qk.tone` จาก `qkmat.js` ได้
- ชั้นภาพ: sky (p .05) far (.25) mid (.6) set (1) act (นักแสดง engine ใส่เอง) glow (ทับนักแสดง) fg (1.5, เบลอ 7px) light (ติดจอ)
  ผนัง/พื้นที่นักแสดงยืนต้องอยู่ `L.set` · ของที่ต้องทับนักแสดงให้คมอยู่ `L.glow` (ขอบเรือ กราบเรือ)
- ทุกอย่าง deterministic: `Pop2.mk(seed)` ห้าม Math.random/Date · ไม่ใช้ SVG filter (ช้า) ใช้ gradient
- ชิ้นที่ขยับต้องมี id `${id}-ชื่อ` บน `<g>` ที่ **ไม่มี transform** (ห่อด้วย `<g transform=…><g id=…>…</g></g>`)
- ฉากกว้างต้องเกินขอบจอ x −1300…2400 เผื่อกล้องเลื่อน · ของในระยะไกลเล็กตามระยะ · หมึก `#2e2a26` เส้น 2.5–4
- ฉากที่ "วาดใหม่ทุกเฟรม" (ทะเล คลื่น ฝน แสงเรือง) ใช้ proxy tween เดียว `tl.to(c,{t:dur,…,onUpdate})` แล้ววาดจากเวลา (seek ไปเวลาไหนก็ถูก)
- หัวไฟล์: อธิบายทุก set / view / option / id ที่ขยับได้ และฟังก์ชัน `Isl.*` (แชทถัดไปอ่านแค่หัวไฟล์)
- **สัดส่วน (V4):** rig สูง ~620·s = ผู้ใหญ่ 1.65 ม. · 1 ม. ≈ 376·s · ภูมิ 9 ขวบ ×0.74 · เรือหางยาว 9–10 ม. (ใช้ `Tide.longtail` ได้ แต่ทาสีใหม่: ลำตัวเหลือง-น้ำเงิน ชื่อ "เจี๊ยบทัวร์") · มะพร้าวอ่อน Ø ~22 ซม. ≈ 83·s

## 2. ฉากที่ EP.1 ต้องใช้ (Fork A1 = ข้อ 2.1–2.2 · Fork A2 = ข้อ 2.3–2.6)
2.1 `Sets.islPier(L, o)` ท่าเรือเกาะหลังเต่า เช้า — สะพานไม้ยื่นลงทะเล (ซ้าย→ขวา) เสาไม้ เชือก ยางรถกันกระแทก เรือหางยาว 2–3 ลำผูกอยู่ (ลำของลุง = เหลือง-น้ำเงิน ชื่อ "เจี๊ยบทัวร์" #id-boat มีธงเล็ก) ท้ายสะพานคือกระท่อมใต้ถุนเตี้ยของตาเวียง (#id-hut: ผนังไม้เก่า หลังคาจาก แห ทุ่น ไม้พายสลักกฎแขวนบนเสา #id-paddle) ชายหาดด้านใน มีเสาน้ำส้มสายชูของ ทช. (#id-vpost: เสาไม้ ป้ายฟ้า "น้ำส้มสายชู ปฐมพยาบาลแมงกะพรุน" ขวดในกล่อง) ต้นมะพร้าว บ้านชาวบ้าน ภูเขาเกาะไกล ฟ้าเช้า
  - views: `"pier"` (มองตามสะพานไปทะเล นักแสดงยืนบนสะพาน y ~1850–1950 s .85–1.0) · `"hut"` (หน้ากระท่อมตาเวียง เห็นไม้พายใกล้) · `"sea"` (จากปลายสะพานมองออกทะเล เรือออกไป เกาะผีเป็นเงาไกล) · `"beachpost"` (ชายหาดกับเสาน้ำส้มสายชูใกล้ เรือแล่นผ่านหลัง)
  - `Isl.pier(tl,id,t0,dur,o)` น้ำกระเพื่อม เรือโยก ธงสะบัด ใบมะพร้าวไหว · `o.boatGo` [a,b] เรือลุงแล่นออกจากท่าไปขวา/ไกล (เล็กลง)
2.2 `Sets.islBoat(L, o)` บนเรือหางยาวกลางทะเล มองจากหัวเรือไปท้ายเรือ: ที่นั่งไม้ กราบเรือทั้งสองข้าง (ใน L.glow ทับนักแสดง) ลุงนั่งท้ายจับคันบังคับเครื่อง (จุดยืนให้ `Isl.BOAT.spots`: uncle, fa, phum) ทะเลรอบเรือ ขอบฟ้า เกาะผีข้างหน้า · `o.weather "sunny"|"squall"|"wreck"`
  - squall: ฟ้ามืด ฝนเป็นเส้น (#id-rain วาดใหม่) คลื่นสูงซัดกราบ น้ำสาด เรือเอียง (ทั้ง set โยก #id-roll) ฟ้าแลบ (#id-flash ใน L.glow สั่งด้วย tl.set) · wreck: โขดหินดำโผล่ด้านข้าง เรือกระแทก เอียงแรง
  - `Isl.sail(tl,id,t0,dur,o)` วาดคลื่น ฝน โยกเรือ ตามเวลา · `o.roll` แอมพลิจูด · `o.storm` 0…1 ค่อยๆ มืด
  - `Sets.islWash(L,o)` ภาพจากหาดเกาะผี (มุมต่ำในคลื่น) เรือลุงเอียงลอยออกไปในม่านฝน หมวกแดงลอย (#id-cap) ใช้ `Tide.longtail` ทาสีใหม่
2.3 `Sets.islBeach(L, o)` หาดเกาะผี — `o.view "sea"` มองออกทะเลจากหาด: ทรายหน้า น้ำตื้นใสเห็นพื้นทราย/ปะการัง แนวหินดำสองข้าง ทะเลเปิด ขอบฟ้า เกาะหลังเต่าเป็นเงาไกล (ซ้าย) ฟ้าตาม `time` · `o.time` morning|noon|dusk-rain|night · `o.light` true = แสงเรือดวงเดียวกลางทะเล (#id-farlight กะพริบช้า) · `o.glow` (EP.2) น้ำเรืองแสงตามคลื่น · `o.box` กล่องโฟมเกย (#id-box) · นักแสดงยืนบนทราย y 1700–1950
  `o.view "land"` มองเข้าฝั่งจากน้ำ: หาดโค้ง ดงมะพร้าว (มะพร้าวอ่อนร่วงใต้ต้น #id-coco0…) เนินทราย โขดหิน/เพิงหินเก่าทางขวา (#id-shelter) ลานหินสูงสุดด้านหลัง (#id-top) ไม้แหลมปักดินข้างกองมะพร้าว (#id-stake) ร่มเงาใต้ต้น (ฟ้านั่ง) ชิ้นที่ "ค่ายเก่า": วงหินก่อไฟ 3 วงบนลานหิน (#id-ring0..2 เห็นเล็กๆ) กระบอกไม้ไผ่แขวน (#id-rattle)
  `o.view "top"` (EP.3) จากลานหินมองลงหาด: หาดเป็นผืน ทะเลรอบ เรือไกล — ทำ stub ไว้ก่อนได้
  - `Isl.beach(tl,id,t0,dur,o)` คลื่นซัดฝั่ง แสงระยิบ ใบมะพร้าวไหว · `o.rain` [a,b] ฝนเริ่ม/หนัก · `o.lightAt` แสงเรือไกลโผล่
2.4 `Sets.islHand(L, o)` ฉากเปิด/ฮุก: มุมใกล้มาก มือเด็กผู้หญิง (ผิว #ebbd95 สายรัดข้อมือชมพู) วักน้ำทะเลใสขึ้นมาจากน้ำตื้นที่มีพื้นทรายระยิบ หยดน้ำร่วงจากนิ้ว ริมฝีปากแตก (มุมคาง-ปากด้านบนขวาของภาพ ไม่ต้องเห็นตา) ชื่อเรื่อง "ติดเกาะ" + "EP.1" ขีดด้วยไม้บนทรายเปียกด้านล่าง (o.title o.sub) · `Isl.scoop(tl,id,t0,dur,o)` มือยกขึ้นหาปาก น้ำไหลลอดนิ้ว หยดลง · ใช้แบบ `tideSand` (วาดใหม่ทุกเฟรม)
2.5 `Sets.islInsert(L, o)` อินเสิร์ต 3 แบบ `o.kind`: `"box"` กล่องโฟมเปิดฝา: ขวดน้ำส้มสายชู (ฉลาก "น้ำส้มสายชู") เชือก แก้วพลาสติก ไฟแช็ก? (ไม่ใส่ ไฟแช็กอยู่ในชุดเอาตัวรอด) · `"bottle"` ขวดน้ำพลาสติกเหลือครึ่ง → ภูมิเขย่า (#id-water ระดับน้ำ) บนทรายร้อน · `"coco"` มะพร้าวอ่อนเสียบบนไม้แหลม เปลือกฉีก น้ำไหล แก้วพลาสติกรอง (#id-husk, #id-stream)
2.6 `Sets.islNight` = `islBeach` time "night" + กองไฟเล็ก (#id-fire เปลวไฟวาดใหม่ ประกาย) + แสงเรือไกล + ซับขอบผ้ากันฝนรองน้ำ (#id-poncho)

## 4. การ์ดและกราฟิก (Fork C: `islui.js` ตาม `tideui.js` · V8/V10 2.5D มีเงา ไฮไลต์ เข้าด้วย back/elastic ไล่ทีละชิ้น มีการเคลื่อนไหวรอง)
- `IslUI.rule(tl, layer, t0, dur, { active, done, y })` **ไม้พายเก่า** แขวนเอียงบนเชือก: ใบพายสลักกฎ 3 บรรทัด (ตัวอักษร Mali สลักลึก เงาในร่อง) ข้อ active = แสงไฟฉายทองไล่ตัวอักษร + คำคล้องจองเด้ง + ไอคอนเหรียญเปลือกมะพร้าวโผล่ข้างบรรทัด (เหรียญ: `seawater` แก้วน้ำทะเลมีวงห้าม · `jelly` แมงกะพรุนกล่อง+ขวดน้ำส้มสายชู · `boat` เรือไกล+คนบนหาดโบกมือ) · done = ทาสีเขียว ✓ · ที่เหลือ = รอยสลักจางมีตะไคร่
- **UI ของวิธีเล่าแบบ A (ทางแยก):**
  - `IslUI.fork(tl, layer, t0, dur, { q, a, b, secs, pick, pickAt })` การ์ดทางแยกกลางตอน: มะพร้าวผ่าครึ่งสองซีก (A ซ้าย B ขวา) คำถามบนป้ายไม้ลอยน้ำ นับถอยหลังด้วยเปลวไฟหรี่ (secs) · ที่ `pickAt` ตรายาง "คนส่วนใหญ่เลือก" กระแทกลงซีกที่ `pick` ซีกนั้นขยาย อีกซีกจางลง · `o.vote` true = ไม่เฉลย เมื่อหมดเวลากรอบกระพริบระหว่างสองซีก แล้วป้าย "คอมเมนต์เลือก A หรือ B" โผล่ · `o.out`
  - `IslUI.dark(tl, layer, t0, dur, { text })` จอมืดลงเป็นสีดำน้ำเงินจากขอบ (ไม่ใช่ game over แบบเกม) มีข้อความแดง Mali "ทางนี้… คุณไม่ถึงเช้า" ค่อยๆ ขึ้น เสียงหัวใจช้าลงจนหยุด (mix.py)
  - `IslUI.rewind(tl, layer, t0, dur, { rule })` ย้อนกลับ: แถบ scrub ไหลถอยหลัง ◀◀ ริ้วเส้นสแกน น้ำทะเลไหลย้อนเป็นวง (วาดใหม่) แล้ว `IslUI.rule` ของข้อ `rule` เรืองขึ้นกลางจอ (เรียกต่อกัน)
- `IslUI.chip(tl, layer, t0, dur, { text })` ชิปเวลา/วัน "เช้าวันนั้น" "วันที่ 1 · บ่ายสอง" (ป้ายไม้ลอยน้ำเล็กผูกเชือก ไม่ซ้ำ chip ของทะเลลด)
- `IslUI.source(tl, layer, t0, dur, { text })` ชิปที่มา (สแลบเปลือกมะพร้าว/ทรายสีอ่อน) y 1790
- `IslUI.gauge(tl, layer, t0, dur, o)` (ถ้าไม่ได้ทำใน islmap) มาตรวัด "น้ำในตัว" แบบขวดน้ำ
- `IslUI.choice(tl, layer, t0, dur, { q, a, b, secs, pull, at })` ตัวเลือกบน **มะพร้าวผ่าครึ่งสองซีก** (ข้อความบนเนื้อขาว) นับถอยหลังด้วยเปลวไฟกองไฟที่หรี่ลง · pull "a": คลื่นมืดซัดขึ้นจอลากกรอบไปฝั่ง a แล้วดึงลงน้ำ (ต่างจากทะเลลด: ที่นี่กรอบถูก "แสงไฟไกล" ดึง — ให้เป็นลำแสงจากดวงไฟไกลดึงกรอบไป) แล้วตัดดำ
- `IslUI.endCard(tl, layer, t0, dur, { l1, l2, final })` ขวดแก้วใสมีจุกคอร์ก กระดาษม้วนข้างในเขียน "ตอนที่ 2 · พิษไหม้" ลอยเข้าหาดตอนพลบค่ำ โคลงตามคลื่น แสงจันทร์ · final → "ตอนจบ"
- `Sets.islLegend(L,o)` + `IslUI.legendAnim(tl,id,t0,dur,o)` จอหนังเงาแบบเดียวกับช่อง (ผ้าหลังไฟ ชายคา) แต่หุ่นเป็นลายฉลุ "ใบจาก/ใบมะพร้าวสาน": เกาะเล็กกลางน้ำ ไฟสามกอง (#id-f0..2 เปลวสั่น) เรือหางยาวผ่านไกล (#id-boat) คนว่ายจากเกาะไปหาเรือ (#id-swim) แล้วจมหาย (ฟองสามฟอง) · o: fires [a,b], boat [a,b], swim [a,b], sink (t)
- `IslUI.symptom(tl, layer, t0, dur, { items })` ป้ายอาการ (ตัวร้อน วิงเวียน ปวดหัว) เป็นแผ่นใบมะพร้าวสานทีละใบ (ใช้เฉพาะที่บทพูด)

## 5. แผนที่และกลไกความรู้ (Fork B: `islmap.js` ตาม `tidemap.js`)
- `Maps.VEH.boat = () => svg` เรือหางยาวเล็ก (ด้านข้าง หันขวา ~90 หน่วย) ให้ `Sets.mapTH` ใช้ `vehicle: "boat"` ได้ · เส้นทาง: กรุงเทพฯ (100.52,13.75) → ท่าเรือฝั่งสุราษฎร์ฯ–ชุมพร (99.3,9.9) ด้วย van แล้วต่อเรือไปเกาะหลังเต่า (สมมติ 100.0,9.8) → ทำเป็น 2 ช่วง (van แล้ว boat) ด้วย `Maps.route` 2 ครั้งบนแผนที่เดียวกัน หรือ option `o.legs`
- `Sets.islMap3d(L,{id})` + `IslMap.play(tl,L,id,t0,o)` แผนที่ 3 มิติแบบ `tideMap3d`: อ่าวไทยฝั่งตะวันตก เกาะหลังเต่า (มีหมู่บ้าน ท่าเรือ) และเกาะผี (เกาะหินเล็กมีเนิน) ห่างกัน 4 กม. ทะเลไล่สีตามความลึก · ก้อนเมฆพายุฝนฟ้าคะนอง (cumulonimbus 3 มิติ ฐานมืด ยอดสว่าง ฟ้าแลบในก้อน) ก่อตัวทางตะวันตกแล้วเคลื่อนเข้าหาเส้นทางเรือ (#id-storm) ขณะเรือจุดเล็กออกจากท่า (#id-boat) · เส้นทางที่ตั้งใจ (ประ) กับเส้นทางที่ถูกพัด (แดง) · ป้าย "พายุฝนฟ้าคะนอง" "เกาะผี" · กล้องบินจากมุมสูงเข้าหาเรือ
- `Sets.islBody(L,{id})` + `IslMap.kidney(tl,id,t0,dur,o)` ภาพผ่าครึ่งร่างกายแบบไดโอรามา 2.5D (คนยืนครึ่งตัวโปร่ง เห็นกระเพาะ ไต 2 ข้าง กระเพาะปัสสาวะ เส้นเลือด) ข้างๆ มี "ขวดวัดน้ำในตัว" (มาตรวัด 0–100%) · ลำดับ (k 0…1): แก้วน้ำทะเล (ฟ้าใส มีผลึกเกลือ) เทเข้าปาก (k .05–.2) → เกลือ (เม็ดขาว) วิ่งไปไต → ไตต้องดึงน้ำจากตัว (ลูกศรจากมาตรวัดเข้าไต) → ปัสสาวะออก "มากกว่าที่ดื่ม" (แก้วออกใหญ่กว่าแก้วเข้า แสดงเทียบ 1 : >1) (k .35–.7) → มาตรวัดลดลง ปากแห้ง ตัวสั่น "ยิ่งดื่ม ยิ่งกระหาย" (k .7–1) · ตรายาง "ห้ามดื่มน้ำทะเล" ปิดท้าย · ข้อความทุกคำจาก quote S1/S2 (ARC) · o.labels override · กล้อง engine นิ่ง `drift:{s:0}`
- (EP.2/EP.3 ภายหลัง) `IslMap.sting` ถุงพิษยิงเข็ม · `IslMap.signal` มุมสูงเกาะกับไฟสามกอง/ตัว X/กระจก

## 7. วิธีทดสอบของแต่ละ fork
- ก๊อป `hf/lib` → `hf/lib_<ชื่อ>` แก้ไฟล์ของตัวเองในนั้น · ก๊อปโฟลเดอร์ตอน `mw/isl1` → `mw/isl_<ชื่อ>` แก้ `make.py` ให้ `LIB` ชี้ `hf/lib_<ชื่อ>` และ `PROJ` ชี้ `hf/isl_<ชื่อ>` · เพิ่ม `<script src="assets/<ไฟล์>.js">` ใน `head.part` และชื่อไฟล์ใน `make.py`
- เขียน `schedule.json` เองสำหรับทดสอบ (`{"total": T, "shots": [{"key":"a","start":0,"dur":4,"vo":[],"voEnd":0}, …]}`) และ `body.part` ที่มีช็อตของตัวเอง 3–6 ช็อต → build → เสิร์ฟพอร์ตของตัวเอง (A1 8861 · A2 8862 · B 8863 · C 8864) → `snap.cjs` → ดูภาพจริงทุกช็อต ต้องไม่มี PAGEERROR
- ส่งกลับ: ไฟล์ lib ที่เสร็จ (ก๊อปไปทับ `hf/lib/<ไฟล์>` ได้เลยเมื่อฉันสั่ง), รายการ set/option/id, ภาพนิ่ง 3–6 ภาพ (path), และสิ่งที่ช็อตต้องตั้งค่า (จุดยืน scale)
