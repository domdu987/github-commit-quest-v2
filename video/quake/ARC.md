# ตึกโยก — ARC (3 ตอน)

**ผู้ใช้สั่ง (28 ต.ค. 2026):**
- "เราจะทำแนวใหม่ แนวเอาชีวิตรอด"
- เลือก: สถานการณ์ "แผ่นดินไหวตึกสูง" · รูปแบบ "สมจริง ไม่มีผี" + "มุมมองบุรุษที่หนึ่ง ให้คนดูเลือกทางรอด"
- "แต่งเนื้อเรื่องเข้าไปด้วย": ต้องเป็นเรื่องที่มีตัวละคร ปม และตอนจบ ไม่ใช่คลิปสอนเฉยๆ

## แนวคิด
- ภัยจริงคือตัวร้าย: ตึก 32 ชั้นกลางกรุงเทพฯ โยกจากแผ่นดินไหวไกลออกไปหลายร้อยกิโลเมตร
- ความตึงมาจากเวลาที่ลดลง เสียงที่ได้ยิน และการตัดสินใจภายในไม่กี่วินาที
- ทุกช่วงสำคัญคนดูต้อง "เลือก"
  - เลือกผิด = เห็นผลทันที (สั้น จบด้วยภาพม้วนกลับแบบเทป)
  - แล้วย้อนกลับมาที่ทางที่ถูกพร้อมความรู้ (ภาพกลไกเคลื่อนไหว + ชิปที่มา)
- ท้ายตอนเป็นตัวเลือกให้คนดูตอบในคอมเมนต์ แล้วตัดดำ
- ไม่มีผี ไม่มีตำนาน · ตัวละครแต่งขึ้นทั้งหมด
- เหตุการณ์จริง 28 มี.ค. 2568 ใช้เป็นข้อมูลอ้างอิงในคำบรรยายสั้นๆ เท่านั้น ไม่ดัดแปลงเหตุการณ์จริงและไม่ใช้ภาพผู้เสียชีวิต

## มุมมอง
- คนดูคือ "คุณ" มองผ่านตาตัวเอง (`Pov.head` หายใจ หอบ สะดุ้ง)
  - เห็นมือสองข้าง มือซ้ายถือมือถือที่มีแอปไรเดอร์
  - ตัวเอกไม่มีเสียงพูด ผู้บรรยาย (Puck) พูดกับ "คุณ"
- ตามบทเรียนจากควันหลง ("ไม่ได้หมายถึงให้ทำแต่มุมมองคนที่1") สลับเป็นมุมกว้างเป็นช่วงๆ
  - ตึกจากข้างนอก สระบนดาดฟ้าน้ำกระฉอก ช่องบันไดมองลง ลานรวมพล
  - มุมกว้างทั้งหมดยังเป็น "โลกของคุณ" ไม่เห็นหน้าคุณชัด (หลังหมวกกันน็อก แขนเสื้อ)

## โลกของเรื่อง
- **คอนโด "เดอะสกาย 32"** (สมมติ) ย่านใจกลางกรุงเทพฯ 32 ชั้น
  - สระว่ายน้ำบนดาดฟ้า มีช่องบันไดหนีไฟสองฝั่ง ลานจอดรถใต้ตึก
  - ลานรวมพลคือสนามหญ้าฝั่งตรงข้ามถนน
- **วันศุกร์ บ่ายโมงยี่สิบ** ตึกเริ่มโยก
  - แผ่นดินไหวต้นทางอยู่ไกลจากกรุงเทพฯ หลายร้อยกิโลเมตร (ตัวเลขจริงใช้ตามแหล่งที่ยืนยันแล้วเท่านั้น)
- ป้ายในโลกเรื่อง (ใช้แทนการ์ด): แผนผังหนีไฟประจำชั้น "คุณอยู่ที่นี่ · ชั้น 27", ป้ายบันไดหนีไฟเลขชั้น, ป้ายจุดรวมพล
- **การ์ดท้าย** = นกหวีดสีส้มของมิวห้อยป้ายกระดาษ "ตอนที่ N · …" / "จบ"
- **กฎของเรื่อง** (โน้ตที่แม่มิวเขียนติดตู้เย็น "ถ้าตึกโยก… จำไว้นะลูก" มีสติกเกอร์ไอคอนทุกข้อ · คำคล้องจองขีดแดง):
  - EP.1: ตึกโยก อย่า**วิ่ง** / หมอบ ป้อง เกาะ อย่า**ทิ้ง** (S1 S2 S3 · "อย่าทิ้ง" = อย่าปล่อยโต๊ะ เลื่อนตามโต๊ะ S1)
  - EP.2: หยุดสั่นแล้ว**ไป** / ลงบัน**ได** ไม่ใช่ลิฟต์ (S1 S3 S4 S7)
  - EP.3: ติดใต้**ซาก** อย่าอ้า**ปาก**ตะโกน / เคาะท่อ เป่านกหวีด (S6)

## เบาะแสข้ามตอน
- นกหวีดสีส้มของมิว
  - EP.1: ห้อยกระเป๋า มิวเล่าว่าแม่สั่งไว้
  - EP.2: มิวยัดใส่มือคุณตอนแยกกัน "เผื่อพี่หลง"
  - EP.3: เป็นเสียงที่ทำให้กู้ภัยหาคุณเจอ
- ลุงสมศักดิ์บ่นว่าหลังคาทางเข้าล็อบบี้ร้าวมานานแล้ว (EP.2) → หลังคานั้นถล่มตอนอาฟเตอร์ช็อก (ท้าย EP.2)
- แม่มิวโทรมาไม่ติด (EP.1) → ติดตอนลงถึงชั้น 14 (EP.2) → มาถึงลานรวมพลตอนจบ (EP.3)

## EP.2 ลงบันได (~1:55)
- **hook:** n "ถ้าวันหนึ่ง… คุณต้องลงจากชั้น 27" · "{อย่าใช้ลิฟต์}"
- **ผลของตัวเลือก:** ไม่จุดเทียน ใช้ไฟฉาย ปิดแก๊สที่เตา (S4 S7)

- **ทางหนีไฟ:** แผนผังประจำชั้นแบบเคลื่อนไหว
