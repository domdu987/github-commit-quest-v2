# ตึกโยก — ARC (3 ตอน)

**ผู้ใช้สั่ง (28 ต.ค. 2026):**
- "เราจะทำแนวใหม่ แนวเอาชีวิตรอด"
- เลือก: สถานการณ์ "แผ่นดินไหวตึกสูง" · รูปแบบ "สมจริง ไม่มีผี" + "มุมมองบุรุษที่หนึ่ง ให้คนดูเลือกทางรอด"
- "แต่งเนื้อเรื่องเข้าไปด้วย": ต้องเป็นเรื่องที่มีตัวละคร ปม และตอนจบ ไม่ใช่คลิปสอนเฉยๆ

## แนวคิด
- ภัยจริงคือตัวร้าย: ตึก 32 ชั้นกลางกรุงเทพฯ โยกจากแผ่นดินไหวไกลออกไปหลายร้อยกิโลเมตร
- ความตึงมาจากเวลาที่ลดลง เสียงที่ได้ยิน และการตัดสินใจภายในไม่กี่วินาที
- ทุกช่วงสำคัญคนดูต้อง "เลือก"
  - เลือกผิด = เห็นผลทันที (สั้น จบด้วยภาพม้วนกลับแบบเทป)
  - แล้วย้อนกลับมาที่ทางที่ถูกพร้อมความรู้ (ภาพกลไกเคลื่อนไหว + ชิปที่มา)
- ท้ายตอนเป็นตัวเลือกให้คนดูตอบในคอมเมนต์ แล้วตัดดำ
- ไม่มีผี ไม่มีตำนาน · ตัวละครแต่งขึ้นทั้งหมด
- เหตุการณ์จริง 28 มี.ค. 2568 ใช้เป็นข้อมูลอ้างอิงในคำบรรยายสั้นๆ เท่านั้น ไม่ดัดแปลงเหตุการณ์จริงและไม่ใช้ภาพผู้เสียชีวิต

## มุมมอง
- คนดูคือ "คุณ" มองผ่านตาตัวเอง (`Pov.head` หายใจ หอบ สะดุ้ง)
  - เห็นมือสองข้าง มือซ้ายถือมือถือที่มีแอปไรเดอร์
  - ตัวเอกไม่มีเสียงพูด ผู้บรรยาย (Puck) พูดกับ "คุณ"
- ตามบทเรียนจากควันหลง ("ไม่ได้หมายถึงให้ทำแต่มุมมองคนที่1") สลับเป็นมุมกว้างเป็นช่วงๆ
  - ตึกจากข้างนอก สระบนดาดฟ้าน้ำกระฉอก ช่องบันไดมองลง ลานรวมพล
  - มุมกว้างทั้งหมดยังเป็น "โลกของคุณ" ไม่เห็นหน้าคุณชัด (หลังหมวกกันน็อก แขนเสื้อ)

## โลกของเรื่อง
- **คอนโด "เดอะสกาย 32"** (สมมติ) ย่านใจกลางกรุงเทพฯ 32 ชั้น
  - สระว่ายน้ำบนดาดฟ้า มีช่องบันไดหนีไฟสองฝั่ง ลานจอดรถใต้ตึก
  - ลานรวมพลคือสนามหญ้าฝั่งตรงข้ามถนน
- **วันศุกร์ บ่ายโมงยี่สิบ** ตึกเริ่มโยก
  - แผ่นดินไหวต้นทางอยู่ไกลจากกรุงเทพฯ หลายร้อยกิโลเมตร (ตัวเลขจริงใช้ตามแหล่งที่ยืนยันแล้วเท่านั้น)
- ป้ายในโลกเรื่อง (ใช้แทนการ์ด): แผนผังหนีไฟประจำชั้น "คุณอยู่ที่นี่ · ชั้น 27", ป้ายบันไดหนีไฟเลขชั้น, ป้ายจุดรวมพล
- **การ์ดท้าย** = นกหวีดสีส้มของมิวห้อยป้ายกระดาษ "ตอนที่ N · …" / "จบ"
- **กฎของเรื่อง** (ป้ายที่แม่มิวเขียนติดตู้เย็น สามท่อน quote ได้ คำจริงใส่หลังยืนยันความรู้แล้ว):
  - EP.1: ตึกโยก อย่าวิ่ง → หมอบ ป้อง เกาะ
  - EP.2: หยุดสั่น ลงบันได ไม่ใช่ลิฟต์
  - EP.3: ติดใต้ซาก เคาะ อย่าตะโกน

## เบาะแสข้ามตอน
- นกหวีดสีส้มของมิว
  - EP.1: ห้อยกระเป๋า มิวเล่าว่าแม่สั่งไว้
  - EP.2: มิวยัดใส่มือคุณตอนแยกกัน "เผื่อพี่หลง"
  - EP.3: เป็นเสียงที่ทำให้กู้ภัยหาคุณเจอ
- ลุงสมศักดิ์บ่นว่าหลังคาทางเข้าล็อบบี้ร้าวมานานแล้ว (EP.2) → หลังคานั้นถล่มตอนอาฟเตอร์ช็อก (ท้าย EP.2)
- แม่มิวโทรมาไม่ติด (EP.1) → ติดตอนลงถึงชั้น 14 (EP.2) → มาถึงลานรวมพลตอนจบ (EP.3)

## EP.1 หมอบ ป้อง เกาะ (~1:55)
- **hook** (POV ทางเดินชั้น 27): โคมไฟแกว่ง น้ำในแก้วสั่น
  - n "ถ้าวันหนึ่ง… ตึกที่คุณยืนอยู่ / เริ่มโยก" · "{อย่าวิ่งไปที่ลิฟต์}"
- **ย้อนไปสองนาทีก่อน:**
  - แอปไรเดอร์บอก "ห้อง 2714 · มิว · ก๋วยเตี๋ยวต้มยำ ไม่ใส่ผัก"
  - คุณขึ้นลิฟต์ แล้วมิวเปิดประตูรับ ("พี่ช้าจัง" / มุกเรื่องไม่ใส่ผัก)
  - เห็นนกหวีดส้มที่กระเป๋า และป้ายกฎบนตู้เย็น
- **แผ่นดินไหว:** เสียงครืดของตึก ม่านแกว่ง น้ำในตู้ปลากระฉอก
  - ภาพตัดข้างนอก: สระบนดาดฟ้าน้ำล้นตกลงข้างตึก
- **ตัวเลือกที่ 1 [วิ่งไปลิฟต์ / หมอบใต้โต๊ะ]** มิวตะโกน "ลงลิฟต์!"
  - ทางผิด: ประตูลิฟต์ปิด ไฟดับ ลิฟต์กระตุกค้างระหว่างชั้น → ม้วนเทปกลับ
  - ทางถูก: หมอบใต้โต๊ะทานข้าวที่แข็งแรง ป้องหัวและคอ เกาะขาโต๊ะไว้ ห่างจากหน้าต่าง
  - ความรู้: กลไก หมอบ ป้อง เกาะ + ชิปที่มา
- **กระจกหน้าต่างร้าวแตก** คุณดึงมิวเข้ามาใต้โต๊ะ
  - n ความรู้เรื่องอยู่ให้ห่างกระจกและของที่ล้มได้
  - ความรู้: ห้ามวิ่งออกระหว่างสั่น
- **การ์ดกฎข้อ 1:** ป้ายบนตู้เย็นของแม่มิว
- **ตึกหยุดสั่น** เงียบ แล้วสัญญาณเตือนไฟไหม้ดัง
  - n ความรู้เรื่องอาฟเตอร์ช็อก
  - มิวโทรหาแม่ไม่ติด
- **ปมค้าง:** กลิ่นแก๊สจากครัว (หม้อที่แม่ตั้งไว้)
  - มิวเอื้อมมือไปที่สวิตช์ไฟ "มืดจัง… เปิดไฟก่อน"
  - ตัวเลือกให้คนดู **[เปิดไฟ / ห้ามแตะสวิตช์]** → ตัดดำ
  - (ใช้ข้อนี้ก็ต่อเมื่อยืนยันจากแหล่งได้ ไม่งั้นเปลี่ยนเป็น [ลิฟต์ / บันได])
- **การ์ดท้าย:** นกหวีด "ตอนที่ 2 · ลงบันได"

## EP.2 ลงบันได (~1:55)
- **hook:** n "ถ้าวันหนึ่ง… คุณต้องลงจากชั้น 27" · "{อย่าใช้ลิฟต์}"
- **ผลของตัวเลือก:** ไม่แตะสวิตช์ ปิดวาล์วแก๊ส ห้ามจุดไฟ (ตามแหล่งที่ยืนยัน)
- **กระเป๋ายังชีพ:** หยิบกระเป๋านักเรียนของมิว ใส่น้ำ ไฟฉาย นกหวีด
- **ทางหนีไฟ:** แผนผังประจำชั้นแบบเคลื่อนไหว
- **ตัวเลือกที่ 2 [ลิฟต์ / บันได]:** ทางผิดเห็นลิฟต์ค้าง → ม้วนกลับ
- **ช่องบันไดแน่นคน:** เกาะราว ช่วยป้าเพ็ญชั้น 14
  - แม่มิวโทรติด ฉากซึ้งสั้นๆ
- **อาฟเตอร์ช็อกในช่องบันได:** ฝุ่นร่วง ไฟกะพริบ
  - หมอบชิดผนังป้องหัว ไม่วิ่งลงตอนสั่น
- **ถึงชั้นล่าง:** ลุงสมศักดิ์ตะโกนต้อนคนออกไปลานรวมพลห่างตึก (กระจกร่วง)
  - มุก: ลุงบ่นว่าหลังคาทางเข้าร้าวมานานแล้ว
  - มีคนจะกลับขึ้นไปเอาโน้ตบุ๊ก → อย่ากลับเข้าไป
- **การ์ดกฎข้อ 2**
- **ปมค้าง:** ป้าเพ็ญทำไม้เท้าหล่นที่ล็อบบี้ คุณวิ่งกลับไปพยุงป้าออกมา
  - มิวยัดนกหวีดใส่มือคุณ "เผื่อพี่หลง"
  - อาฟเตอร์ช็อกลูกใหญ่ หลังคาทางเข้าถล่ม → มืด
  - ตัวเลือกให้คนดู **[ตะโกนให้สุดเสียง / เคาะท่อ เป่านกหวีด]** → ตัดดำ
- **การ์ดท้าย:** "ตอนจบ · เคาะ อย่าตะโกน"

## EP.3 เคาะ อย่าตะโกน (ตอนจบ ~1:50 ไม่มีตัวเลือกท้าย)
- **hook** (POV ในความมืดใต้ซาก ฝุ่นในลำแสงมือถือ จอแตก แบตเหลือ 9%):
  - n "ถ้าวันหนึ่ง… คุณติดอยู่ใต้ซากตึก" · "{อย่าตะโกน}"
- **ตัวเลือกที่ 3 [ตะโกน / เคาะ]:** ทางผิดไอเพราะฝุ่น แรงหมด → ม้วนกลับ
- **ความรู้ (ตามแหล่งที่ยืนยัน):**
  - ปิดปากจมูกด้วยผ้า
  - ไม่จุดไฟแช็ก ได้กลิ่นแก๊ส
  - เคาะท่อหรือผนัง เป่านกหวีด
  - ขยับตัวให้น้อย
- **ข้างนอก:** มิวบอกพี่หมีว่า "พี่ไรเดอร์ยังอยู่ข้างใน มีนกหวีด"
  - ความรู้: แจ้งเจ้าหน้าที่ ห้ามเข้าไปเอง
- **สุนัขค้นหาเห่า** เสียงนกหวีดตอบ แสงลอดลงมา "เจอแล้ว!"
- **ลานรวมพล:** แม่มิวมาถึง มิวคืนนกหวีด… ไม่ คุณคืนนกหวีดให้มิว
- **การ์ดกฎครบสามข้อ**
- **ประโยคปิด:** n "แผ่นดินไหว… บอกล่วงหน้าไม่ได้ / แต่คุณ… {เตรียมตัวได้}"
- **การ์ด "จบ"**
