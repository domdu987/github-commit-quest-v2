# คลิปยาวแนวนอน 16:9 สำหรับ YouTube

ที่มา: เจ้าของสั่งเมื่อ 4 พ.ย. 2569 ว่า "คลิปสั้น ig Facebook · คลิปยาว YouTube" ให้ "เอาคลิปสั้นเก่าๆมาต่อเป็นคลิปยาว" และเลือก "แนวนอน 16:9"

## วิธีทำ
ใช้ composition แนวตั้งเดิมของแต่ละตอน เช่น `video/<ตอน>/composition` ที่เก็บด้วย store.sh แล้วเปิดโหมดแนวนอนดังนี้

1. แก้ `index.html` 5 จุด:
   - เปลี่ยน viewport, ขนาด html/body/#root และ `data-width`/`data-height` ของ #root ให้เป็น 1920×1080
   - ใส่ 2 บรรทัดนี้หลัง engine.js: `<script>window.LANDSCAPE = {};</script>` และ `<script src="assets/landscape.js"></script>`
   - เพิ่ม CSS 3 บรรทัด:
     - `.clip > .capwrap .capbox { font-size: 50px; }`
     - `.clip.lfit { background: radial-gradient(ellipse 60% 80% at 50% 50%, #1a2226, #05080a); }`
     - `.badge { bottom: 40px; }`
2. คัดลอก `landscape.js` ไปไว้ใน `assets/`
3. ตัวตอนไม่ต้องแก้อะไร เพราะ `landscape.js` ครอบ `Engine.build` แล้วจัดทุกคลิปใหม่เอง:
   - **ฉาก:** ขยายเวทีไปถึง x −660…1740 เพื่อให้โลกต่อออกไปทั้งซ้ายและขวา
   - **การจัดเฟรม:** ย่อเหลือ 0.8 แล้วเลือกแถบความสูง 1350 px ตรงที่ตัวละครอยู่ (y0 อัตโนมัติ หรือกำหนดเองด้วย `sh.land = { y0 }`)
   - **การ์ดและ UI:** ทั้งใน L.light และ HTML ย่อให้พอดีความสูงหน้าจอ (×.5625) อยู่กลางภาพ และไม่โดนตัด
   - **แคปชัน:** อยู่ตำแหน่งเดิมเมื่อเทียบกับเลย์เอาต์แนวตั้ง จึงไม่ทับชิปแหล่งอ้างอิง
   - **ฉากที่วาดพอดีจอแนวตั้ง:** เช่น จอหนังตะลุง แผนที่ สมุด จะแสดงทั้งเฟรมไว้กลางจอแบบ fit โดยอัตโนมัติ
   - **ฉากทึบเต็มความกว้างเดิม:** เช่น ฉากมืดหลังการ์ดตัวเลือก จะยืดให้เต็มหน้าจอใหม่
4. ดูภาพก่อนด้วย `node snapL.cjs <port> <out> t1 t2 …` ซึ่งถ่ายภาพที่ 1920×1080 และพิมพ์ค่า y0 หรือ fit ของแต่ละช็อต
5. เรนเดอร์ด้วย hyperframes ตามปกติ (`-f 60`) แล้วต่อทุกตอนเป็นเรื่องเดียว โดยตัดการ์ดท้ายที่บอกตอนถัดไปออก และตัดเสียงจาก mix.wav ของแต่ละตอนให้ตรงช่วงเดียวกัน
