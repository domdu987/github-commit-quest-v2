# ฮุกเปิด + ภาพปก (viral pass, 28 ต.ค. 2026)

ผู้ใช้สั่ง: "ช้าไม่ว่า ทำคุณภาพดีๆ ขอแบบสุดยอดมหาเทพ ทำให้คนดูสักล้านคน" → ทำโดยไม่ต้องเรนเดอร์ใหม่ทั้งตอน

- **ฮุกเปิด (cold open)**: เอาช่วงที่ตื่นเต้นที่สุดของตอนนั้น (1.5–2.5 วิ) จากไฟล์ HQ เอง มาวางหน้าสุด + หัวข้อคำถามบนกระดาษ (`headline.py`) + เสียง glitch/whoosh (`synth.py` ด้วย `hook1_cues.json`) แล้วจางเป็นดำเข้าฉากเปิดเดิม (ฉากเปิดทุกตอนเริ่มจากจอดำ อย่าจางเป็นขาว — กระพริบ)
  `bash mkhook.sh IN-HQ.mp4 OUT-HQ-hook.mp4 T0 DUR overlay.png sfx.wav [FADEIN]` (เข้ารหัสใหม่ทั้งตอน crf 16, ~15 นาทีถ้าเรนเดอร์วิ่งอยู่)
  - **ตอนที่ฉากเปิดไม่ได้เริ่มจากจอดำ (EP.5 เปิดด้วยถนนกลางแดด) ใส่ FADEIN 0.2** ให้ฉากเปิดค่อยๆ สว่างจากดำ — ไม่งั้นจางดำแล้วตัดเป็นภาพสว่างทันที เหมือนกะพริบ (เช็ก luma ที่รอยต่อทุกตอน · ความสว่างเฟรมแรกของแต่ละตอน: EP.1 4 (ดำ) · EP.2 29 · EP.3 63 · EP.4 40 · EP.5 160 → EP.3–5 ใช้ FADEIN 0.2)
  - เสียงฮุก (เสียงตอน + glitch/whoosh) ผ่าน limiter −1 dBFS แล้ว — ก่อนใส่ glitch ทับบทพูดดังจนพีคเกิน 0 dBFS (EP.2 +0.6 dB 12 sample ตรง glitch, ฟังไม่ออก)
  `python3 headline.py out.png "บรรทัด 1" "บรรทัด 2 (แดง)" y scale x` — วางให้ไม่บังบับเบิลคำพูด/หน้าตัวละครของช็อตนั้น
- **ภาพปก**: `python3 cover.py frame.png cover.jpg "EP.n" "บรรทัด 1" "บรรทัด 2" y [scale]` (scale ค่าเริ่ม 1.05 · บรรทัด 2 ยาวให้ลดจนการ์ดกว้างไม่เกิน ~1030 px — `headline.py` พิมพ์ขนาดการ์ดออกมา) — เฟรมจากคลิป + กระดาษหัวข้อ + ตรายาง EP กลางจอ (หน้าโปรไฟล์ TikTok ครอปกลางเป็น 3:4 → ข้อความอยู่ช่วง y 240–1680)
- ใช้ PIL + raqm (ตัดคำไทยถูก) ฟอนต์ Kanit Black (`assets/fonts/f3.ttf`)
