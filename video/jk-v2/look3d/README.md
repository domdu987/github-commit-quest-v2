# จอมโกหก v2 · ฉาก 3D จริง (ทดลอง 12 พ.ย. 2569)

เจ้าของสั่ง: "ทำฉาก ตัวละคร แสงสี มิติ มุมกล้องให้ดีขึ้น มีทั้งมุมใกล้ มุมไกล มุมไกลมากแล้วซูมไปหา แขนอย่าหลุด ดาบชี้ไปทางไหนให้ละเอียด" แล้วส่ง skill `reference-style-shorts` มา · ต่อมา: "ตัวละครเราเหมือนเดิม แต่เอาฉากแบบเขา"

- ฉาก: `town3d.py` ลานหน้ากิลด์ตอนเย็นใน Blender (bpy 5.3, Cycles CPU) ใช้โมเดลแสงของ skill (`office3d.mat_lit`: แสงเงาเป็น emission สีม่วงน้ำเงิน + ดวงอาทิตย์แข็งดวงเดียว) ลายพื้นผิววาดเป็น SVG ใน `tex_town.py`
- ตัวละคร: ตัวเดิมของเรา (rig/flat.js) วาดเป็นภาพโปร่งใสทุกเฟรมด้วย `sprites.cjs` (เปิดหน้า EP.2 ที่พอร์ต 8775) แล้วติดบนการ์ดใน `stage3d.py` (ไม่รับแสง, มีการ์ดเงาหันหาดวงอาทิตย์ให้เงาจริงบนพื้น)
- ดาบ: `sprites.cjs` วัดจุดปลายดาบ (`#…-handF > g:last-child` จุด 0,372) เทียบคาง/คอพระเอก → ใช้ jkKenLSA ท่า lunge arm −73 กับพระเอกห่าง 650 px ในการ์ดคู่เดียวกัน ปลายดาบหยุดที่คอพอดี
- แขน: ท่าคุกเข่าใหม่ `kneelHands` (ยกมือสองข้าง uaF/uaB −150, faF/faB −25) แขนติดไหล่ทั้งสองข้าง
- ช็อต (`look.py`): ไกลมากจากฟ้าแล้วซูมลง → มุมต่ำเงยเคน → ฝูงชน → ใกล้หน้าพระเอก → สองคนแล้วพุ่งเข้าหาดาบ · 720×1280 12 samples ~6–10 วิ/เฟรม · `finish.py` ขยาย 1080×1920 ใส่ซับ/HUD/หลอดคนเชื่อ และเสียง EP.2 ตั้งแต่ 53.02 วิ
- ลำดับรัน: `python3 tex_town.py` → `python3 look.py sprites` → `python3 look.py render 0:395` → `python3 finish.py raw out.mp4`
