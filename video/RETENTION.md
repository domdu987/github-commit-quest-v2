# สูตรเขียนบทให้คนดูต่อจนจบ (Retention Playbook)

รวมจากงานวิจัย เอกสารทางการของแพลตฟอร์ม และการถอดคลิปต้นแบบที่ผู้ใช้ส่งมา (ต.ค. 2026)
ใช้คู่กับ `HANDOFF.md` หัวข้อ 2.5 **ทุกเรื่องใหม่ต้องเขียนบทตามสูตรนี้ แล้วผ่าน checklist ท้ายไฟล์ก่อนสร้างเสียง**

> **ระดับความน่าเชื่อถือ**
> - **[วิจัย]** = งานวิจัยหรือเอกสารทางการ
> - **[แนวปฏิบัติ]** = คำแนะนำจากครีเอเตอร์หรือบล็อกการตลาด ตัวเลขยังไม่ได้ยืนยัน ใช้เป็นแนวทาง ไม่ใช่กฎ

---

## 1. แพลตฟอร์มวัดอะไร

- **[วิจัย] TikTok แจ้งเองว่า For You คำนวณจาก 3 กลุ่ม**
  1. การกระทำของผู้ใช้ (กดไลก์ แชร์ คอมเมนต์ ติดตาม ดู)
  2. ข้อมูลคลิป (แคปชัน เสียง แฮชแท็ก)
  3. การตั้งค่าเครื่อง (น้ำหนักน้อยที่สุด)

  [TikTok Newsroom](https://newsroom.tiktok.com/en-us/how-tiktok-recommends-videos-for-you/)
- **[แนวปฏิบัติ] สัญญาณที่แทบทุกแหล่งเห็นตรงกัน:** เวลาดูรวม, ดูจนจบ, ดูซ้ำ และแชร์/เซฟ มีผลมากกว่าไลก์
  - ส่วนตัวเลขอย่าง "ต้องดูจบ 75% ขึ้นไป" ยังไม่มีแหล่งทางการ
  - [darkroom](https://www.darkroomagency.com/observatory/tiktok-algorithm-guide-2026), [fanpage karma](https://www.fanpagekarma.com/insights/?p=14186)
- **[แนวปฏิบัติ] 3 วินาทีแรกคือด่านแรก**
  - แหล่งต่างๆ ให้ตัวเลขคนปัดทิ้งช่วงนี้ต่างกันมาก ตั้งแต่ประมาณ 33% ถึง 40%
  - YouTube Shorts มีตัวชี้วัด "viewed vs swiped away" ไว้ดูเรื่องนี้โดยตรง
  - [clipspeed](https://www.clipspeed.ai/blog/ai-hook-detection-first-3-seconds-2026.html), [tailwind](https://www.tailwindapp.com/blog/?p=9990), [subscribr](https://subscribr.ai/youtube-strategy/youtube-shorts-analytics-metrics-growth)

**สรุปเป้าหมายของบท**
1. ไม่ให้ปัดทิ้งใน 3 วินาทีแรก
2. ไม่มีช่วงไหนที่คนดู "รู้สึกว่าจบแล้ว" ก่อนจบจริง
3. ตอนจบทำให้อยากดูซ้ำหรืออยากดูตอนต่อ

## 3. สูตรโครงตอน (อัลกอริทึมเขียนบท)

ตัวอย่างคิดจากคลิปยาวประมาณ 90 วินาที

```
0–3 วิ   HOOK      สถานการณ์ "ถ้าวันหนึ่ง… คุณ[เจอ X]"  +  คำสั่งสวนสัญชาตญาณ "อย่า[สิ่งที่ทุกคนจะทำ]"
                    ภาพอันตรายตั้งแต่เฟรมแรก ไม่มีโลโก้หรือคำทักทาย มีตัวหนังสือบนจอ
                    → เปิดคำถามหลัก Q1 "ทำไมถึงห้าม?"
3–10 วิ  เดิมพัน   ตัวนับที่ลดลงเรื่อยๆ (เวลา, ระดับน้ำ, %, ออกซิเจน) + เหตุผลครึ่งเดียว
10–75 วิ บันได     วนรอบละ 8–15 วิ:
                      แต่…  (ปัญหาใหม่ / ภัยที่คนดูเห็นก่อนตัวละคร)
                      เพราะงั้น…  (ใช้ความรู้จริง: เหตุ → ผล + ตัวเลข 1 ตัว)
                      ปิดคำถามเล็ก แล้วเปิดคำถามใหม่ที่ใหญ่กว่า
                    ช่วง 50–60%: จุดดึงคนกลับ (หักมุม / การ์ด "กฎข้อ 2" / เปิดเผยอะไรบางอย่าง)
75–85 วิ ปิด Q1    ตอบ "ทำไมถึงห้าม" ด้วยภาพที่ชัดที่สุดของตอน
85–90 วิ เปิดใหม่  ประโยคปิดสั้นและหลอน 2 ท่อน ("มีใครบางคน" / "มาก่อนแล้ว")
                    + ชื่อตอนถัดไปเป็นประโยคชวนลุ้น หรือตัวเลือกที่ถูกดึง → ตัดดำและตัดเสียงทันที
```

## 4. กฎระดับประโยค

1. **1 บรรทัด = 1 ความคิด = 2–5 คำ = 1 ช็อตประมาณ 2 วินาที**
   - ประโยคยาวให้แตกเป็นท่อน และให้ท่อนแรก "ค้าง" เสมอ เช่น "เขามีเครื่องปั่นไฟ" / "ก็เกิดปัญหาใหม่"
2. **ความรู้ต้องเป็น เหตุ → ผล + ตัวเลข** ห้ามเป็นรายการข้อห้าม
   - ✗ "งูกัด ห้ามกรีด ห้ามดูด ห้ามขันชะเนาะ…"
   - ✓ "งูกัด" / "ยิ่งขยับ" / "พิษยิ่งวิ่งเร็ว"
   - ตัวเลขต้องมาจากแหล่งที่เช็กแล้ว และขึ้นเป็นกราฟิกบนจอ
3. **พูดกับคนดูด้วย "คุณ"** ในช่วง hook และตอนให้ความรู้ บทพูดของตัวละครสั้นและน้อย (ไม่เกินประมาณ 30% ของเวลา)
4. **คำกระแทกคำเดียว** ขึ้นกล่องแดง ("อย่า", "ไม่ทัน", "มาก่อนแล้ว") ส่วนกล่องเหลืองใช้กับคำสำคัญ
5. **กฎของเรื่องต้องคล้องจองหรือขนานกัน** เพื่อให้ quote ได้ ตอนละ 1–2 ประโยค
6. **คำเชิงลบหรือสูญเสียใน hook ได้ แต่ต้องจริงตามเรื่อง** ห้ามหลอกคนดู (clickbait ที่ไม่จ่ายคืนจะทำให้คนปัดทิ้ง)
7. **ห้ามมีช่วงเงียบหรือภาพนิ่งเกิน 3 วินาที** ยกเว้นตั้งใจทำเป็นจังหวะกลั้นหายใจ ซึ่งต้องมีเสียงหัวใจหรือมาตรอะไรสักอย่างเดินอยู่

## 5. Checklist ก่อนสร้างเสียง (ต้องผ่านทุกข้อ)

- [ ] วินาทีแรกมีภาพอันตราย และตัวหนังสือ hook ขึ้นจอแล้ว
- [ ] hook มีทั้ง "สถานการณ์" และ "คำสั่งสวนสัญชาตญาณ" และยังไม่เฉลยเหตุผล
- [ ] อ่านบทต่อกันแล้ว ทุกรอยต่อใส่ "แต่" หรือ "เพราะงั้น" ได้ ไม่มีรอยต่อที่เป็น "แล้วก็"
- [ ] ทุกวินาทีมีคำถามค้างอย่างน้อย 1 ข้อ (ไล่ดูทีละช็อต)
- [ ] มีตัวนับที่ลดลงเรื่อยๆ อย่างน้อย 1 อย่าง
- [ ] ไม่มีบรรทัดไหนเกิน 6 คำที่ยังไม่ถูกแตกท่อน
- [ ] ความรู้ทุกข้อมีเหตุ → ผล และแหล่งอ้างอิง ใส่ใน ARC.md
- [ ] มีภัยที่คนดูเห็นก่อนตัวละครอย่างน้อย 1 ฉาก
- [ ] มีประโยคที่ quote ได้ 1–2 ประโยค
- [ ] ปิดคำถามหลักของ hook ก่อนจบ แล้วเปิดคำถามใหม่ที่ใหญ่กว่า
- [ ] ตอนจบไม่มีประโยคลาหรือภาพนิ่ง ตัดดำและตัดเสียงทันที

## 6. วัดผลหลังโพสต์

- ดู TikTok Analytics:
  - average watch time
  - % watched full video
  - กราฟ retention ว่าคนหลุดตรงวินาทีไหน แล้วกลับไปแก้ช็อตนั้นในตอนถัดไป
- ทดลอง hook 2 แบบกับเนื้อหาเดียวกัน (โพสต์ห่างกันหรือใช้เป็นโฆษณา A/B) แล้วเก็บแบบที่คนปัดทิ้งน้อยกว่า
- YouTube Shorts: ดู "viewed vs swiped away" เทียบกับคลิปก่อนๆ ของเราเอง (ไม่มีเกณฑ์ทางการ)
