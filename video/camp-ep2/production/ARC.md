# ค่ายคืนสุดท้าย — โครงเรื่อง 3 ตอน

ตัวละคร: **ปิ่น** (ใจกล้า ใจร้อน), **กล้า** (ชื่อกล้าแต่ขี้กลัว), **พี่โจ้** (หัวหน้าค่าย), **ลุงชัย** (เจ้าหน้าที่อุทยาน)
กฎของเรื่อง: "หลังสองทุ่ม อย่าออกนอกแคมป์ — ได้ยินใครเรียกชื่อ อย่าขาน"

## EP.1 เสียงเรียก (ตอนนี้)
แคมป์วันสุดท้าย → ลุงชัยเตือน → รถตู้สตาร์ทไม่ติด ไม่มีสัญญาณ → พี่โจ้เดินไปตามคนที่ป้อม
→ สามทุ่ม พี่โจ้ไม่กลับ → เสียงพี่โจ้เรียกจากในป่า → ปิ่นเลือกตามเสียงไป → หลงป่า (หยุด·คิด·สังเกต·วางแผน)
→ เป่านกหวีด 3 ครั้ง → มีเสียงตอบจากข้างหลัง → กลั้นหายใจ → ไฟฉายเจอ "พี่โจ้" ตาเรืองแสง
→ "ทำไม… ไม่ขานล่ะ" → ตัวเลือก ขานรับ / วิ่งหนี ถูกดึงไปที่ "ขานสิ…" → ตัดดำ

ความรู้: ห้ามแยกกันเดินในป่ากลางคืน · หลงป่าให้หยุดอยู่กับที่ · นกหวีด 3 ครั้ง = ขอความช่วยเหลือ · ตาคนไม่สะท้อนแสงไฟฉาย

## EP.2 ตาสีเขียว
ตัวเลือกถูกดึงไปที่ "ขานสิ…" แต่กล้าสลัดหลุด เลือก "วิ่งหนี" → ไล่ล่าในป่า มีเงาตาเรืองแสงตามติด
→ ล้ม พลัดหลงกัน → เสียงปิ่นดังมาสองทาง (ซ้าย/ขวา) กล้าถาม "หมาที่บ้านปิ่นชื่ออะไร" ตัวจริงตอบทันที ตัวปลอมทวนช้าๆ
→ ซูมออกเป็นแผนที่ป่า: ป้อมพิทักษ์ป่าอีก 1 กม. ต้องผ่านเขตช้างป่า → ฝูงช้างผ่าน หลบหลังต้นไม้ QTE เงียบไว้
→ ช้างหันไปทางเงาในป่า เงาหนีไป → ปิ่นโดนงูเขียวหางไหม้กัด → ปฐมพยาบาล จำลักษณะงู → ถึงป้อมพิทักษ์ป่า
ค้างไว้: เคาะประตูไม่มีคนเปิด วิทยุข้างในเป็นเสียงพี่โจ้ "กล้า… เปิดประตูให้พี่หน่อย" แล้วมีเสียงลุงชัยตะโกนจากข้างหลัง "อย่าเปิดนะ!"
→ ตัวเลือก เปิดประตู / เชื่อเสียงข้างหลัง → ตัดดำ

ความรู้: เจอช้างระยะใกล้ อย่าส่งเสียงไล่ หลบหลังต้นไม้ใหญ่ ค่อยๆ ถอย · งูกัด ห้ามกรีด ดูด ขันชะเนาะ ให้นิ่ง รีบไปโรงพยาบาล
· จำลักษณะงูไว้บอกหมอ ไม่ต้องจับ · งูเขียวหางไหม้กัดคนบ่อย พิษต่อระบบเลือด

## EP.3 อย่าขาน (ตอนจบ)
กล้าเลือก "เชื่อเสียงข้างหลัง" → ลุงชัยตัวจริงวิ่งมาพร้อมกุญแจ "ในนั้นไม่มีใคร ลุงล็อกไว้เอง"
→ วิทยุเรียกรถฉุกเฉิน (1669) → แผนที่ซูมออก: ถนนขาด รถกู้ภัยรอถึงเช้า ตาของมันวนรอบป้อม
→ ตีหนึ่ง มือถือมีสัญญาณ ข้อความพี่โจ้ตัวจริงส่งตั้งแต่ 15:12 → "แล้วคนที่อยู่กับเราทั้งวัน… คือใคร"
→ กล้าจะให้ยาแอสไพริน ลุงชัยห้าม → มันเคาะวนรอบป้อม แล้วใช้เสียงของลุงชัยเองเรียกจากข้างนอก "ชู่ว… ห้ามใครขาน"
→ ฉากย่อง: กล้าย่องไปปิดหน้าต่างหลัง เหยียบไม้ผุดัง "เอี๊ยด" มาตรตรวจจับเต็ม ถูกพบ หน้าของมันโผล่ที่หน้าต่าง ปิดบานเกล็ดทัน
→ ทั้งคืนมันเรียกทุกชื่อ → ตีห้าครึ่ง รถกู้ภัยมาถึง → สามวันต่อมา ที่โรงพยาบาล
→ มือถือกล้าดัง ผู้โทร "ปิ่น" ทั้งที่ปิ่นนั่งอยู่ข้างๆ → ตัวเลือก รับสาย / ไม่รับ ถูกดึงไปที่ "รับสิ…" → ตัดดำ

ความรู้: ฉุกเฉินโทร 1669 · ถูกงูกัด ห้ามกินยาแก้ปวดที่มีแอสไพริน (ทำให้พิษงูออกฤทธิ์มากขึ้น) · ในความมืด เสียงบอกตำแหน่ง
