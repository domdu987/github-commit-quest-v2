- **เปลี่ยนเฉพาะเพลง:**
  - `video/music/suno1.mp3` เริ่มที่ 0 วิ ไม่มี EQ หรือฟิลเตอร์ (เอา low-pass 6 kHz ของเพลงออก)

  - duck 0.65 แบบทะเลลด (envelope 50 ms ÷ มัธยฐาน, smooth 0.25 วิ, ไม่มี gate)
- **คงเดิมทั้งหมด:** คิว SFX, dip ช่วงหลอน (ช่วงเงียบก่อนถึงสถานี, กลั้นหายใจก่อนหันกลับ), เพลงค่อยลดใต้การ์ดท้ายแล้วจบ, เสียงพูด, gain เส้นตรงเดียวไป −14 LUFS
