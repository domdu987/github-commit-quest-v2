# ตรวจเรื่องเมื่อวานทั้งหมด · 2 พ.ย. 12:15 น.

เจ้าของถาม "ซอมบี้บนรถไฟฟ้าเสร็จมั้ย" แล้วตามด้วย "เรื่องเมื่อวานทั้งหมด" → ตรวจทุกเรื่องที่ทำเมื่อ 1 พ.ย. ด้วยกฎปัจจุบัน
- ภาพ: ดู 360×640 ทุกวินาที + ซูมเฟรมเต็มในจุดที่สงสัย
- เสียง: วัดตามกฎ A4 ไม่มีซ่า

## เสียง (A4): ยังมีซ่าทุกเรื่อง

| เรื่อง | flatness 5–14 kHz ค่ากลาง | หน้าต่าง noise |
|---|---|---|
| ห้องสอบ EP.1 / EP.2 | 0.70 / 0.71 | 54% / 52% |
| ทางกลับบ้าน EP.1 / EP.2 | 0.64 / 0.62 | 65% / 56% |
| ซอมบี้รถไฟฟ้า EP.1 / EP.2 | 0.68 / 0.72 | 50% / 48% |
| (เทียบ) รอดคนเดียว v6 | 0.32 | 3% |

→ พักทั้งหมดไว้ในคิว แล้วรีมิกซ์แบบภาพเดิม · เป้าหมาย flatness ≤ 0.4 และหน้าต่าง noise < 10%

## ภาพ

| เรื่อง | จุดที่ต้องแก้ | เลน |
|---|---|---|
| ห้องสอบ | นักเรียน 3 คนนั่งซ้อนเรียงกันเหมือนก๊อป (EP.1 ~31 วิ · EP.2 ~5 วิ และ ~21 วิ) · ขอบฉากโหว่เห็นฟ้า หญ้า และพื้นดำ (EP.1 ~37 วิ และ ~46 วิ) · นักเรียนลอยตอนลากโต๊ะ (EP.1 ~40 วิ) · ป้ายห้องเป็น ม.3/2 แต่เรื่องเป็นห้อง ม.3/4 (EP.2 ~33–41 วิ) | C (ทันคืนนี้ 20:00 ถ้าเสร็จก่อน 18:00) |
| ซอมบี้รถไฟฟ้า | ผู้โดยสาร 6 คนดันประตูซ้อนเรียงแถว (EP.1 ~55 วิ) · ฮุกเฟรมแรกเป็นกลุ่มคนซ้อนกัน · พูดว่า "แสงไฟฉายใกล้เข้ามา" แต่ไม่มีไฟฉายในภาพ (EP.2 ~44 วิ) · เจ้าหน้าที่ตัวสูงกว่ารถ (EP.2 ~47 วิ) · คนพื้นหลังเป็นทรงเบี้ยหมากรุก (EP.2 ~57 วิ และ ~68 วิ) | D (คิว 3 พ.ย. 20:00) |
| ทางกลับบ้าน | ควันระเบิดเป็นก้อนกลมซ้อนเป็นตั้ง (EP.1 ~6 วิ และ ~65 วิ) · ทหาร 2 คนชุดเขียวซ้อนจนเป็นก้อนเดียว (EP.1 ฮุก และ ~40 วิ) · พูดว่า "พุ่มไม้บังตา" แต่ภาพเป็นเนินดิน (EP.2 ~4 วิ) | D (งานของเลน A · ต้องหาช่องลงใหม่ เพราะพลาดช่องเที่ยง) |

ส่วนที่ผ่าน:
- ฮุกทั้ง 6 ตอน: คำสั่งขึ้นใน ~2.5–3.5 วิ
- การ์ดกฎ ความรู้ และหักมุมของทุกเรื่อง
