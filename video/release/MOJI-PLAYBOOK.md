## 3. Instagram Reels (จุดที่ค้างวันนี้)
1. สร้าง container ด้วย `media_type=REELS`, `video_url` และ `caption` (ใส่ `share_to_feed=true`)
   - `video_url` ต้องเป็นลิงก์ที่ดาวน์โหลดไฟล์ mp4 ได้ตรงๆ ไม่ใช่หน้าเว็บ
2. ถามสถานะ (`status_code`) ทุก 30–60 วินาที นานสุด 10 นาที จนกว่าจะเป็น `FINISHED` แล้วค่อย `media_publish`
   - ถ้าสั่ง publish ตอนยัง `IN_PROGRESS` จะ error
3. ถ้าได้ `ERROR` หรือ `EXPIRED` ให้อ่านข้อความ error แล้วสร้าง container ใหม่
   - ถ้าไฟล์ HQ ไม่ผ่าน ให้ลองไฟล์ share (`video/<ep>/…-share.mp4`)
   - container มีอายุราว 24 ชั่วโมง ห้ามสร้างทิ้งไว้ข้ามวัน
4. ก่อนลงแต่ละวัน เช็กโควตาการลงผ่าน API ด้วย `content_publishing_limit` ของบัญชี
5. สเปกไฟล์ของเรา ผ่านทุกตอน: mp4 H.264 + AAC 48 kHz · 1080×1920 (9:16) · 60 fps · ยาว 55–90 วิ · 40–95 MB

  - เช็กโควตาใน Google Cloud Console ก่อน เพราะเราลงวันละ 6–9 คลิป

## 5. ไฟล์สถานะ (บังคับ)
`video/release/posted/YYYY-MM-DD.json` เป็นรายการ 1 แถวต่อ 1 คลิปต่อ 1 แพลตฟอร์ม
```json
[{"id":"sink-ep2","platform":"instagram","status":"posted","scheduled_for":"2026-11-01T10:00+07:00",
  "posted_at":"2026-11-01T13:05+07:00","url":"https://www.instagram.com/reel/…","error":null}]
```
- `status` มีค่าได้ 3 แบบ: `scheduled` | `posted` | `failed`
