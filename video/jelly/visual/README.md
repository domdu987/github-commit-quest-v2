## ของใหม่ใน `lib/jelly.js` (โหลดหลัง tide.js, tidecast.js)
- `Sets.jellyBeach`: หาดของ tide.js (มุมมองทะเล) แบบอ่าวไทย: ไม่มีเขาหินปูนและเงาสะท้อน · เกาะเตี้ย · เรือทะเบียน ปข · หอกู้ภัย เสาน้ำส้ม หินไกล ร่ม ของบนหาด · แมงกะพรุนใต้น้ำ + แถบน้ำทับตัวคนลุยน้ำ (`wade`) · ห่วงเป็ด
- `Sets.jellyPorch` บ้านยายรุ่งเช้า · `Sets.jellyHook` ฉากใกล้ขาบนทรายเปียก (ยังไม่ใช้ใน v1)
- `Jelly.box` แมงกะพรุนกล่อง · `Jelly.bottle` ขวดน้ำ (ถอดฝาได้) · `Jelly.post` เสาน้ำส้มสายชู (เต็ม/ว่าง) · `Jelly.tower` หอกู้ภัย · `Jelly.basket` ตะกร้าขวดน้ำส้ม · `Jelly.welts` หนวดบนผิว + รอยแดง
- ตัวละคร: `jTon` (+Bottle, +Phone) · `jPhum` · `jWan` (ห่วงเป็ด) · `jLaor` (+Basket) · `jGuard` · `jWoman`
- `lib/tide.js` = tide.js ที่เพิ่ม option `near: false`, `vines: false` (ค่าเดิมไม่เปลี่ยน)
