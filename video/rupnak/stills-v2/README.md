# รูพญานาค · ภาพนิ่งชุดใหม่ (ร่างให้เจ้าของดูก่อน · 2 พ.ย. 2569)

- เจ้าของสั่ง (ผ่านผู้ประสานงาน): "ทำเป็นที่มองจากด้านบนสวยๆ วัดขนาด กว้าง ยาว แล้วทำมุมที่เห็นความลึก ใต้ดิน" · "แก้เป็นภาพ มาให้ผมดูก่อน"
- เป็นภาพนิ่งเท่านั้น ยังไม่ได้ต่อเข้า EP ใดและไม่ได้เรนเดอร์ · ไฟล์ EP ที่ส่งไปแล้วไม่ได้แก้
