# ผีแม่ม่าย — ARC (3 ตอน)

## แนวคิด
ผีแม่ม่าย (ผีหญิงที่ชาวอีสานเชื่อว่ามาเอาชายหนุ่มไปตอนหลับ) = **อุปมาของโรคใหลตาย (กลุ่มอาการบรูกาดา)** ที่หัวใจเต้นผิดจังหวะตอนนอนแล้วหยุดบีบเลือด
ความเชื่อนี้เกิดจากเรื่องจริง: ผู้ชายในบางหมู่บ้านตายขณะหลับในวัยไล่เลี่ยกัน (S3) ซึ่งที่จริงคือพันธุกรรม
ผี "เลือกบ้าน" เพราะยีนอยู่ในครอบครัว ผี "มาเร็ว" เพราะช่วยไม่ทันไม่กี่นาทีก็ตาย และผี "สู้ไม่ได้" กับคนที่ปั๊มหัวใจเป็นและมี AED
คลิปไม่ล้อความเชื่อ แขวนเสื้อแดงได้ แต่ต้องปั๊มหัวใจเป็น (S6)

## ผี
ผีแม่ม่าย: ตัวดำสนิท ผอมสูงผิดสัดส่วน ผมยาวปิดหน้า นุ่งผ้าถุงขาดเป็นริ้ว นิ้วยาว ตาเขียวเรือง · นั่งเฝ้าปลายเท้าผู้ชายที่กำลังจะตาย
ลักษณะสำหรับ EP.1 (บนจอหนังตะลุง): "หญิงม่ายที่ตายเพราะคิดถึงสามี / ออกตามหาผู้ชายตอนหลับ / บ้านไหนแขวนเสื้อแดง มันจะคิดว่า… ไม่มีผู้ชาย"

## กฎของป้าบัว (อสม.)
1. **หลับแล้วเกร็ง อย่าเกรงจะปลุก** (EP.1: ชักเกร็งตอนหลับ = อันตราย ปลุกทันที S3 S5 S1)
2. **ปลุกไม่ตื่น ปั๊มให้ฟื้น** (EP.2: ไม่ตื่นไม่หายใจ → 1669 + AED + กดหน้าอก S1 S2)
3. **ญาติเคยตาย ตรวจใจก่อนสาย** (EP.3: ญาติสายตรงตายตอนหลับ → พาทั้งครอบครัวไปตรวจคลื่นไฟฟ้าหัวใจ S3 S4)

## เบาะแสข้ามตอน
- รูปพ่อติดริบบิ้นดำบนฝา (EP.1) → แม่หลบตาเมื่อเก่งถาม → หมอถาม "ในครอบครัวเคยมีใครตายตอนหลับไหม" (EP.2) → แม่สารภาพ (EP.3)
- ผีนั่งปลายเท้าเก่งเสมอ (EP.1–2) → ตอนจบ ผีไปนั่งปลายเท้าบอส (เด็กในสายเลือดเดียวกัน) แต่ยังไม่ทำอะไร: "มันรอได้"
- ป้ายเสื้อแดงทุกบ้าน (EP.1) → ผู้ใหญ่สมานเก็บเสื้อแดงไปแขวนที่ศาลาใต้ป้าย "จุดเก็บเครื่อง AED" (EP.3)

## EP.1 อย่าเกรงจะปลุก (~1:50)
ความรู้: ใหลตายไม่ใช่ผี (S3 S5) · ใครเสี่ยง (S3) · อาการตอนหลับ ชักเกร็ง กระตุก หายใจไม่สะดวก ช่วยไม่ทันไม่กี่นาทีก็ตาย (S3 S5) · ปลุกเสียงดัง ตบไหล่สองข้าง (S1)
1. **open** ฉากเปิด: เสื้อแดงตัวหนึ่งสะบัดในความมืด ชื่อเรื่องเขียนแปรงสีแดงแบบป้ายไม้ กล้องถอยเห็นทั้งซอยมีเสื้อแดงทุกบ้าน เงาดำผอมเดินข้ามถนนไกลๆ · n01 "ถ้าวันหนึ่ง… / คนในบ้านคุณ / ชักเกร็งตอนหลับ"
2. **hook** ภาพแวบ: มือฝนเขย่าไหล่เก่งในความมืด · n02 "{อย่าคิดว่าแค่ละเมอ}"
3. **arrive** รถสองแถวส่งเก่งหน้าซุ้มประตูหมู่บ้าน เสื้อแดงเต็มซอย · k01 "เสื้อแดงเต็มหมู่บ้าน… มีงานบุญเหรอ"
4. **horns** ผู้ใหญ่สมานบนหอกระจายข่าว · s01 "ประกาศ… บ้านไหนมีผู้ชาย / ให้แขวนเสื้อแดงไว้หน้าบ้าน"
5. **fon** ฝนวิ่งมา · f01 "ผู้ชายในหมู่บ้าน… ตายตอนหลับ / สองคนแล้วนะพี่" · k02 "ผีแม่ม่ายเหรอ… ปีไหนแล้ว"

## EP.2 ปั๊มให้ฟื้น (~1:50)
ความรู้: โทร 1669 ขอ AED แจ้งสถานที่ อาการ เบอร์ (S1) · นอนหงายพื้นแข็ง สันมือครึ่งล่างกระดูกหน้าอก มือประสาน ลึก ≥5 ซม. 100–120 ครั้ง/นาที คนทั่วไปไม่ต้องเป่าปาก (S1 S2) · AED: เปิดเครื่อง ทำตามเสียง ถอดเสื้อ แผ่นใต้ไหปลาร้าขวา + ชายโครงซ้าย ห้ามสัมผัส ช็อตแล้วกดต่อทันที (S1 S2) · กดต่อเนื่องจนทีมกู้ชีพมาถึง (S1 S2)
- recap → hook n01 "ถ้าวันหนึ่ง… คุณปลุกคนในบ้านไม่ตื่น / {อย่ารอหมอผี}" → ฝนนึกถึงป้าบัว การ์ดกฎข้อ 2 → โทร 1669 (ลำโพง) → ตะโกนให้ลุงเปี๊ยกไปเอา AED → จัดท่าบนพื้นไม้ → มือ (insert) → ปั๊ม นับจังหวะ (ฉากแอ็คชั่น: มือผีดึงเท้าเก่งจากความมืด ฝน "ไม่ให้!") → AED มาถึง เสียงเครื่องสั่ง → "ห้ามสัมผัส" ทุกคนยกมือ → ช็อต ตัวเก่งกระตุก ผีหวีดหาย → กดต่อทันที → รถกู้ชีพ 1669 มาถึง ส่งต่อ → ห้องฉุกเฉิน หมอ "ถ้าไม่มีคนปั๊ม เขาไม่รอด"
- ปมค้าง: หมอถาม "ในครอบครัว… เคยมีใครตายตอนหลับไหม" แม่เงียบ หน้าต่างห้องมีตาเขียว · ตัวเลือก "บอกหมอ / ปิดไว้" ถูกดึงไป "ปิดไว้" → การ์ดท้าย "ตอนจบ · ตรวจใจก่อนสาย"

## EP.3 ตรวจใจก่อนสาย (ตอนจบ ~1:50 ไม่มีตัวเลือก)
ความรู้: ใหลตายเป็นพันธุกรรม ยีนไม่ต่ำกว่า 20 ยีน (S3) · ญาติสายตรงเสี่ยง พาครอบครัวมาตรวจ (S3 S4) · ตรวจคลื่นไฟฟ้าหัวใจได้ทุกช่วงอายุ (S3) · เครื่องกระตุกหัวใจฝังใต้ผิวหนังหน้าอก (S3) · ยาสลบ/ยานอนหลับกระตุ้นได้ ต้องบอกหมอ (S3) · แขวนเสื้อแดงได้ตามความเชื่อ (S6)
