# บางระจัน แบต 3% · ตอนเดียวจบ (~73 วิ · 3 พ.ย. 2569)

**คำสั่งเจ้าของ:** "เอาตอนเดียว ให้จบ ทำให้น่าสนใจ"
- ฉบับนี้ใช้แทนโครง 3 ตอนใน `STORY_FUN.md`
- เดินเรื่องตามโครงคลิป 69 วิของช่อง ผู้บรรยายเล่าเป็นหลัก ตัวละครพูดคนละ 1–2 ประโยค
- เปิดเรื่องกลางเหตุการณ์ แล้วย้อนไปเล่า · ของที่ซ่อนไว้ในวิที่ 2 คือคำตอบของเรื่อง

**กติกาประวัติศาสตร์ (คงเดิม):**
- ไม่มีมุกล้อวีรชน
- ข้าศึกเป็นเงากับคบไฟในหมอก ไม่มีฉากฆ่าหรือเลือด
- เก่งไม่เปลี่ยนประวัติศาสตร์ ทำแค่เรื่องเล็กที่ไม่มีในพงศาวดาร

## เรื่องในประโยคเดียว

เก่งตื่นมาในค่ายบางระจัน พ.ศ. 2309 พร้อมมือถือแบต 3%
- ทางเดียวที่จะได้กลับบ้านคือนาฬิกาปลุก 7 โมงในเครื่อง
- เขาใช้แบตจนหมดเกลี้ยงเพื่อช่วยค่าย
- คำตอบอยู่ในข้อความที่เขาปิดจอทิ้งตั้งแต่วินาทีที่ 2 ซึ่งส่งมาจากเบอร์ของเขาเอง

## อะไรทำให้น่าดู

| | ในคลิป |
|---|---|
| **แบต % มุมจอ** | ทุกมุกกินแบต คนดูลุ้นไปกับตัวเลข 3 → 2 → 1 → 0 |
| **"ผีเสื้อฟ้า"** | จุกเห็นเก่งใส่เสื้อบอลสีฟ้าแล้วร้องว่าผีเสื้อฟ้า แตงสวนว่า "ตัวเท่าควาย" ไอ้ดำหันขวับ |
| **นางไม้ในกล่อง** | ผู้ช่วยเสียงทักทาย ทั้งค่ายกราบ เก่งเลยสั่งไก่ย่างในนามนางไม้ |
| **มะนาว 200 ลูก = 1%** | ฉลองกันเหมือนงานวัด ส่วนยายแผ้วโกรธเพราะไม่มีมะนาวตำน้ำพริก |
| **โชว์ผีบางระจัน** | ไฟฉายมัดเขาควาย ควายเรืองแสงเดินออกจากหมอก แบตหมดกลางโชว์ แล้วเสียงหัวเราะที่น่ากลัวที่สุดคือเสียงยายแผ้ว |
| **ข้อความวนเวลา** | เก่งต้องส่งข้อความเดิมย้อนกลับไปหาตัวเองในคืนแรก |
| **มุกปิด** | ยายในปี 2569 หน้าเหมือนยายแผ้ว และยังซ่อนมะนาวเหมือนเดิม |
