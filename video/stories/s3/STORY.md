# ไอน์สไตน์ใต้ดาบโจโฉ (เรื่องใหม่ #3 · ร่าง v1 · 3 พ.ย. 2569)

> อ่าน "โรเบิร์ตไอน์สไตน์" ในคำสั่งผู้ใช้ว่า **อัลเบิร์ต ไอน์สไตน์** (Albert Einstein)

**คำสั่งผู้ใช้:** "ถ้าโรเบิร์ตไอน์สไตน์ กับมาเกิดใหม่ในยุคสามก๊กแล้วกำลังจะถูกตัดคอจะเอาชีวิตรอดยังไง"

**Logline:** คุณคือไอน์สไตน์ ไปเกิดใหม่ปลายราชวงศ์ฮั่น แล้วตื่นมาใต้ดาบของโจโฉ ทุกตอนมีคำถามเดียวที่คุณรู้คำตอบ
แต่ในวังโจโฉ **คนที่ตอบถูกก็หัวขาดได้** คุณจึงต้องรอดด้วยฟิสิกส์ที่เด็กห้าขวบเข้าใจ และด้วยศิลปะ "ให้คนอื่นเป็นคนฉลาด"

- **แนวเรื่อง:** ย้อนยุคปนตลกร้าย ไม่มีผี (ใช้ S13 ข้อ 2 แบบไม่มีผี: "อันตรายจริงในร่างตำนาน" = ความระแวงของโจโฉ ซึ่งมีบันทึกจริง)
- **นอกสูตรหลักของช่อง:** S3 ไม่เอาสงคราม/ไซไฟ แต่เรื่องนี้เป็นคำสั่งเจ้าของช่องสำหรับเลนทดลอง ไม่มีฉากรบหรือเลือด การตัดหัวอยู่นอกจอทุกครั้ง
- **เรื่องสมมติทั้งหมด** บนบันทึกจริง: ทุกเหตุการณ์ประวัติศาสตร์และทุกประโยค "บันทึกจริง…" ชี้ไปที่ quote ด้านล่างได้ (S1–S12)
  ตัวละครจริงพูดบทที่แต่งขึ้น ยกเว้นประโยคที่ระบุว่า "บันทึกจริง"
- **ปีของเรื่อง:** EP.1 = ค.ศ. 201 (โจชง 5 ขวบ ตามบันทึก "生五六歳") · EP.2–3 = ค.ศ. 208 ปีที่ฮัวโต๋ถูกประหาร โจชงตายตอนอายุ 13 และศึกผาแดง
  (บันทึกไม่ระบุปีที่ชั่งช้าง ปี 201 เป็นการเลือกของเรื่อง)

## กฎของกุยแก (S4 · ตอนละข้อ · คล้องจองด้วยคำซ้ำ "เอง")

> **รู้คำตอบ อย่าตอบเอง / นายไม่เชื่อ ให้ฟังเอง / นายพลาดไป ให้แก้เอง**

- **ข้อ 1 (EP.1):** ความจริงที่ช่วยชีวิตได้ ให้คนอื่น (ที่ปลอดภัยกว่า) เป็นคนพูด · การ์ดขึ้นตอนคุณตอบ "คิดจะผ่าช้าง"
- **ข้อ 2 (EP.2):** คนมีอำนาจไม่เชื่อคำพูด แต่เชื่อสิ่งที่ได้ยินกับหูตัวเอง · การ์ดขึ้นตอนโจโฉเอาหูแนบท่อไม้ไผ่
- **ข้อ 3 (EP.3):** อย่าพูดว่า "บอกแล้ว" ให้นายแก้หน้าเองด้วยเรื่องที่นายเชื่อ · การ์ดขึ้นตอนโจโฉเขียนจดหมายถึงซุนกวน
- **การ์ด:** ม้วนไม้ไผ่ (竹簡) คลี่ออก ตัวอักษรพู่กันเขียนทีละท่อน ข้อของตอนนี้สว่าง ข้อที่ผ่านแล้วมีตราแดงประทับ ข้อที่ยังไม่ถึงจาง

## เบาะแสข้ามตอน (S8)

1. **เรือไม้ของเล่นมีเส้นถ่าน:** EP.1 0:15 (เห็นแวบเดียว) → EP.1 0:58 เฉลยว่าเส้นมีก่อนคุณคิดออก → EP.3 ลอยในแม่น้ำ ข้างในมีรอยขีดของเด็ก
2. **สายตาเด็กที่ 0:06 ของ EP.1:** เด็กเห็นรอยยิ้มคุณ → EP.1 "ยิ้มเร็วไปนะ" → EP.3 "ข้ารู้ตั้งแต่วันชั่งช้าง ว่าท่านรู้"
3. **อาการไอของเด็ก:** EP.1 ตอนจบ → EP.2 เสียงหายใจในท่อไม้ไผ่ → EP.3 ประโยคจริงของโจโฉ "吾悔殺華佗，令此兒彊死也"
4. **น้ำเต้าเหล้าของกุยแก:** EP.1 ห้อยเอว → EP.2 แขวนว่างบนเสา (กุยแกตายปี 207 · S11) คุณต้องใช้กฎที่เหลือคนเดียว
5. **ธูปนับถอยหลัง:** EP.1 ธูปประหาร → EP.2 ธูปยามห้าในคุก → EP.3 ธูปบนศาลของเด็ก (ดอกเดียวที่คุณไม่อยากให้หมด)
