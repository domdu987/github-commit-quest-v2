# คนเดินดิน — โลกที่ทุกคนมีพลัง ยกเว้นคุณ (เรื่องใหม่ #4 · ฉบับเน้นสนุก · 3 พ.ย. 2569)

**คำสั่งเจ้าของ:** "ถ้าทุกคนในโลกบินได้ยกเว้นคุณ แต่คุณฉลาดที่สุดในโลก… ให้ดีเวอร์ๆ เอาสูตรมาใช้"
- รอบสอง: "ทุกคนในโลกมีพลังวิเศษ บินได้ ยกเว้นคุณ"
- รอบสอง: "อันนี้ไม่ต้องอินความรู้ เอาให้สนุกดูเพลิน"

**เปลี่ยนจากร่างแรก:**
- ตัดความรู้เรื่องฟ้าผ่าและความสูงกับแหล่งอ้างอิงออก
- ทุกคนในเรื่องมี **พลังวิเศษประจำตัว** เพิ่มจากการบิน
- เรื่องกลายเป็นมหากาพย์ฮีโร่ 3 ตอน: ฟ้าดับ ทั้งเมืองร่วง แล้วคนไม่มีพลังคนเดียวช่วยโลก
- ตัวละครชุดเดิม: ภูมิ ฟ้า เมฆ ยายแย้ม และหมาชื่อตูบ · ตัวใหม่: **กัปตันสุริยา**
- "สูตร" = สูตรคลิปของช่อง S13 ครบ 8 ข้อ (ตารางด้านล่าง) และฮุก "ถ้าวันหนึ่ง… คุณ…" ทุกตอน

## เรื่องย่อในประโยคเดียว

ทุกคนได้พลังตอนห้าขวบจาก **วงแหวนทองบนฟ้า** ยกเว้นคุณ คนเดียวในโลกที่มีพลัง 0% แต่ฉลาดที่สุดในโลก
- คืนหนึ่งคุณคำนวณได้ว่า วงแหวนกำลังหรี่ลงวันละ 1%
- อีกเจ็ดวัน พลังของทุกคนจะดับ ตรงกับวันที่ทั้งเมืองบินขึ้นไปสามพันเมตรเพื่อทำลายสถิติโลก
- ไม่มีใครเชื่อคนไม่มีพลัง

## มุกและภาพที่ทำให้ "ดีเวอร์"

| | บนจอ |

## สูตรคลิปของช่อง (S13) ทั้ง 8 ข้อ

| ข้อ | ในเรื่องนี้ |
|---|---|
| 1 ของล่อใจ + "อย่า…" | EP.1 "อย่าเชื่อฮีโร่" (ฮีโร่ยิ้มบนจอยักษ์) · EP.2 "อย่าดิ้น" (คนที่ดิ้นกลางฟ้า พลังที่เหลือหมดเร็วกว่า) · EP.3 "อย่าสู้บนฟ้า" |
| 2 ภัยในร่างตำนาน | ไม่มีผี ภัยตัวจริงซ่อนอยู่ในร่าง "ฮีโร่อันดับ 1" ที่ทุกคนรัก |
| 3 พลิกสิ่งที่คนเชื่อ | "ไม่มีพลัง = ไร้ค่า" → คนไม่มีพลังคนเดียวพาทั้งเมืองลงมา · "บินได้ = อยู่สูงสุด" → คนที่ขึ้นไปสูงที่สุดคือคนที่บินไม่ได้ |
| 4 ชุดตัวละคร | เด็กมั่นใจเกิน (เมฆ) · เพื่อนปากแข็ง (ฟ้า) · ยายที่ถูกหาว่าเพี้ยน (ยายแย้ม) · สัตว์เตือนภัย (ตูบ) · ฮีโร่ที่ทุกคนรัก (กัปตันสุริยา) |
| 5 คนดูรู้ก่อน | วงแหวนหรี่ลงทุกช็อต · วันที่ที่วงไว้บนกราฟ = วันเปิดตัวกัปตันสุริยา · เส้นแสงที่ถุงมือ · ตูบเห่าใส่จอ |
| 6 ปิดตอน | หักมุมในภาพ + ประโยคเดียว · คำถามแคปชัน |
| 7 เฟรมแรก/ปก | ฟ้าเต็มไปด้วยคนบิน ภูมิยืนคนเดียวบนพื้น จอยักษ์มีหน้าฮีโร่ยิ้ม |
| 8 จังหวะปล่อย | ปล่อยคืนเดียว 3 ตอน |

## เบาะแสข้ามตอน (S8)

- **วันที่บนกราฟ (EP.1):** เส้นเริ่มลดตรงวันที่ที่มีวงแดงตัวเล็ก "วันเปิดตัวกัปตันสุริยา"
- **เส้นแสงจากถุงมือ (EP.1):** เส้นแสงบางๆ จากถุงมือต่อขึ้นวงแหวน ตอนเขายกกำปั้นบนจอ
- **ตูบ:** เห่าใส่จอทุกครั้งที่กัปตันสุริยาออกมา
- **รูปเก่าของยายแย้ม (EP.1):** รูปที่ปักกล่องเย็บผ้า เป็นคนทั้งเมืองยืนอยู่บนพื้นเมื่อ 60 ปีก่อน (เฉลยใน EP.3 ว่าครั้งนั้นก็มีคนขโมยแสง พลังคืนฟ้าตอนคนขโมยหมดสติ)

## โครง 3 ตอน

### EP.1 คนเดียวที่บินไม่ได้ (~71 วิ · บทเต็มอยู่ท้ายไฟล์)
- **ฮุก:** "ถ้าวันหนึ่ง… ทุกคนบินได้ ยกเว้นคุณ" → "{อย่าเชื่อฮีโร่}"
- **เรื่อง:**
  1. ปูโลกพลังวิเศษแบบบ้านๆ แล้วเล่าว่าภูมิได้พลัง 0% แต่ฉลาดที่สุดในโลก
  2. ภูมิเดินขึ้นบันได 40 ชั้นทุกเช้า
  3. คืนหนึ่งเขาวัดได้ว่าวงแหวนหรี่ลงวันละ 1% อีก 7 วันจะดับ ตรงวันเทศกาล #เหนือเมฆ
  4. ทั้งโรงเรียนหัวเราะ ฮีโร่อันดับ 1 บอกบนไลฟ์ว่า "ฟ้าไม่มีวันดับ"
  5. มีแค่ฟ้าที่เชื่อ ทั้งคู่กับยายแย้มและตูบใช้หกวันสร้างตาข่าย บันได บอลลูน และแอป "ทางลง"
- **ปิด:** วันเทศกาล ทั้งเมืองบินขึ้นสามพันเมตร วงแหวนดับ แสงของคนเป็นล้านดับพร้อมกัน ภูมิกดปุ่มแดง "ถึงตาคนเดินดินแล้ว"
- **แคปชัน:** "ถ้าคุณเป็นคนเดียวที่รู้ว่าพลังทั้งโลกจะดับ คุณจะบอกใครคนแรก?"

### EP.2 วันที่ฟ้าดับ (~74 วิ)
- **ฮุก:** "ถ้าวันหนึ่ง… พลังของคุณดับ กลางฟ้าสามพันเมตร" → "{อย่าดิ้น}"
- **กติกาที่ภูมิคำนวณไว้:**
  - แสงที่ค้างในตัวแต่ละคนจะค่อยๆ หมดใน **9 นาที** ทุกคนจึงค่อยๆ ลดระดับลง ไม่ได้ร่วงทันที
  - คนที่ดิ้นหรือกระพือแขน พลังที่เหลือจะหมดเร็วกว่าคนอื่นสามเท่า
- **เรื่อง:**
  1. มือถือทุกเครื่องบนฟ้าเด้งแอป "ทางลง" บอกเวลาที่เหลือของแต่ละคน ("คุณเหลือ 4:12 · ลงตึก B7")
  2. ภูมินั่งสั่งการจากบ้านชั้นดินเหมือนศูนย์ควบคุม
  3. ฟ้าใช้แรงที่เหลือ 10% ขนเด็กลงทีละสองคน
  4. คนแห่ลงบันไดของภูมิ เด็กที่เคยพ่นสี "คนเดินดิน" ก้มหน้าเดินลงขั้นแรก
  5. ยายแย้มยืนแจกน้ำที่ตีนบันได สั่งนกพิราบนำทางคนที่หลง
- **ไคลแมกซ์:**
  1. เมฆตกใจจนดิ้นแรง พลังหมดก่อนใคร ร่วงลงมา
  2. ภูมิกระโดดขึ้นบอลลูนที่เย็บจากป้ายเทศกาล ลอยขึ้นฟ้าเป็นครั้งแรกในชีวิต
  3. เมฆปั้นเมฆก้อนเดียวรองตัว ชะลอได้หนึ่งวินาที พอดีให้ภูมิคว้าไว้ในตะกร้า
- **หักมุม:** ทุกคนลงถึงพื้นครบ ทั้งเมืองโห่ร้อง แต่สูงขึ้นไปยังมีคนหนึ่งเรืองแสงอยู่ คือกัปตันสุริยา กำลังดูดแสงสุดท้ายจากวงแหวน
- **ปิด:** กัปตันสุริยาพูด "ขอบใจนะคนเดินดิน ที่พาทุกคนลงไป… ฟ้านี้เป็นของผมแล้ว"
- **แคปชัน:** "ถ้าพลังดับกลางฟ้า คุณจะลงที่ไหน?"

### EP.3 คนเดินดินไปถึงฟ้า (ตอนจบ · ~75 วิ)
- **ฮุก:** "ถ้าวันหนึ่ง… คนเดียวที่บินได้ คือตัวร้าย" → "{อย่าสู้บนฟ้า}"
- **โลกไม่มีพลัง (มุกช่วงต้น):**
  - คนทั้งเมืองหัดเดิน แม่ปิ้งขนมปังด้วยกระทะ ลุงเปิดขวดโหลด้วยช้อน
  - กัปตันสุริยาลอยเหนือเมืองเรียกเก็บ "ค่าฟ้า"
- **ความลับของยายแย้ม:** 60 ปีก่อนก็มีคนขโมยแสงวงแหวน พลังคืนฟ้าตอนที่คนขโมย **หมดสติ**
- **แผนของภูมิ (ไม่สู้เลย):**
  1. ภูมิแฮ็กเข้าไลฟ์ของกัปตันสุริยาที่มีคนดูพันล้าน แล้วท้า "ฮีโร่ตัวจริงต้องทำลายสถิติ #เหนือเมฆ ของตัวเอง"
  2. คอมเมนต์ท่วมจอ #คนเดินดินท้า ตัวร้ายติดยอดวิว บินสูงขึ้นทีละหมื่นเมตรเพื่อโชว์
  3. น้ำแข็งเกาะเกราะ ลมหายใจเป็นควัน ขอบโลกเริ่มโค้ง
  4. อากาศบางเกินไป ตัวร้ายหมดสติกลางไลฟ์
- **ไคลแมกซ์:**
  1. แสงไหลออกจากตัวกัปตันสุริยากลับขึ้นวงแหวน วงแหวนสว่างอีกครั้ง พลังกลับคืนทุกคนพร้อมกัน
  2. ตัวร้ายหมดสติร่วงลงมา ภูมิในบอลลูนรุ่นสอง (ชุดกันหนาวกับถังอากาศที่เตรียมไว้) คว้าไว้ด้วยตาข่าย เขาเลือกช่วยตัวร้าย
  3. ฟ้าบินขึ้นมาข้างบอลลูน แล้วคนทั้งเมืองที่ได้พลังคืนก็บินตามขึ้นมา
- **ช็อตจบ "ดีเวอร์":**
