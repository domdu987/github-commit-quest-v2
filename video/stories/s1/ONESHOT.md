# สกิลขี้โม้ · ตอนเดียวจบ (~72 วิ · 3 พ.ย. 2569)

**คำสั่งเจ้าของ:** "เอาตอนเดียว ให้จบ ทำให้น่าสนใจ"
- ฉบับนี้ใช้แทนโครง 3 ตอนใน `STORY_FUN.md`
- เดินเรื่องตามโครงคลิป 69 วิของช่อง ผู้บรรยายเล่าเป็นหลัก ทุกตัวละครพูดสั้น
- ประโยคประจำช่อง "พลาดไปแล้ว… ตั้งแต่วินาทีที่… / คุณเห็นไหม?" ชี้กลับไปที่ของที่ซ่อนไว้ตั้งแต่ต้นคลิป

## เรื่องในประโยคเดียว

ต้นได้สกิล F **"ถ้ามีคนเชื่อเรื่องที่โม้หนึ่งคน เรื่องนั้นจะจริงขึ้น 1%"**
- เขาโม้จนได้อันดับ 1 ในคืนเดียว
- แต่มุกที่พูดเล่นไปประโยคเดียวทำให้ทั้งเมืองเชื่อว่าเขาเป็นราชาปีศาจ
- ทางรอดทางเดียวคือหูแดง ซึ่งเป็นจุดอ่อนที่สุดของเขา

## อะไรทำให้น่าดู

| | ในคลิป |
|---|---|
| **เฟรมแรกคือตอนจบ** | ต้นนั่งบัลลังก์อันดับ 1 สวมถังไม้ครอบหัว ถ้าดูดีๆ จะเห็น **เขาเล็กๆ สองอันโผล่จากถัง** คนดูที่ย้อนกลับมาดูจะร้อง "เห็น!" |
| **ตัวนับ % ลอยเหนือหัว** | คนดูเห็นความเชื่อเพิ่มขึ้นทีละขั้น |
| **มังกร 1% = จิ้งจก** | ยิ่งคนเชื่อ ตัวที่นอนสลบนอกหน้าต่างยิ่งโต: จิ้งจก → ตะกวด → จระเข้ → มังกรจริง |
| **ถังไม้** | ครอบหัวไว้ปิดหูแดง ทำให้เขาโกหกเก่ง และทำให้มุกพูดเล่นกลายเป็นเรื่องจริงด้วย |
| **จุดอ่อนกลายเป็นทางรอด** | ถอดถังให้ทุกคนเห็นหูแดง ความเชื่อเรื่องราชาปีศาจพังในวินาทีเดียว |
| **มุกปิด** | โม้อีกครั้ง หูแดงอีกครั้ง จิ้งจกหล่นใส่หัวอีกตัว |
