ไฟล์: `video/lib-shared/iconfx.js` (ไม่พึ่งไฟล์อื่น ต้องมีแค่ GSAP) · คลิปตัวอย่าง: `video/lib-shared/iconfx-demo-HQ.mp4` (14.9 วิ 60fps มีเสียง: การ์ด 6 แบบบนฉากของเรื่อง + ไอคอน 5 ธีม)

ใช้แทน `SU.medal` / `SU.sheen` / `SU.fxGo` ในงานใหม่ ของเดิมยังใช้ได้ ไม่ต้องย้อนไปแก้เรื่องที่ final แล้ว

## ติดตั้งในตอน
เลือกทางใดทางหนึ่ง
- **ต่อท้ายใน shots.part** (ง่ายสุด): ใส่ `/path/to/repo/video/lib-shared/iconfx.js` ลงในรายการไฟล์ของ `build.sh` ก่อน `body.part` เช่น
  `cat helpers.part … sinkui.part <ของเรื่อง>.part …/video/lib-shared/iconfx.js body.part > shots.part`
- **เป็น asset**: คัดลอกไฟล์ไป `hf/lib/` เพิ่ม `"iconfx.js"` ในรายการของ `make.py` และใส่ `<script src="assets/iconfx.js"></script>` ใน `head.part` ต่อจาก `rig2.js`

ทุกฟังก์ชันวางลง layer แบบ screen space (`L.light`) และรับ `tl` กับเวลาแบบเดียวกับ fx ของช็อต (เวลาบน timeline หลัก)

## เรียกใช้
```js
// ไอคอนกฎตอนผู้บรรยายพูดกฎ: ใหญ่ ≥ ¼ จอ (r ≥ 135 · ค่าเริ่ม 150) พุ่งเข้า กระแทก แล้วลอยมีชีวิต แล้วไปเกาะมุมจอ
const { id, hit } = IconFX.enter(tl, L.light, { theme: "zombie", art: IconFX.ART.bell, x: 540, y: 760, r: 170,
  t: t0 + F("rule", 0, 0), from: "left", label: "กดกระดิ่ง", idle: 1.4, exit: "dock", dockX: 950, dockY: 300, dockR: 80 });

// การ์ดเช็กลิสต์: พลิกเข้ามีมิติ รายการขึ้นทีละข้อ ✓ ลากเส้น + ประกาย · ✗ สั่น + แฟลชแดง
IconFX.card(tl, L.light, { theme: "zombie", title: "กฎรถไฟฟ้า", t: t0, dur: 2.4, step: 0.35, items: [
  { text: "กดกระดิ่ง", sub: "คุยกับศูนย์ได้ทันที", mark: "ok", art: IconFX.ART.bell },
  { text: "เปิดประตูฉุกเฉิน", sub: "กลางรางยกระดับ", mark: "no", art: IconFX.ART.noTrack }] });
```
- `art`: SVG ในกรอบ ±100 (ตัวอย่างพร้อมใช้ใน `IconFX.ART`: bell, noTrack, stopwatch("2 วิ"), gangway, log, buoy, candle, helmet)
- `from`: "below" | "left" | "right" | "above" · `exit`: "dock" (ย่อไปเกาะมุม ขนาด r ≥ 77 = 1/7 จอ แล้วยังขยับต่อ) | "fly" (บินออกพร้อมหาง) | "none"
- ห้ามปล่อยให้ไอคอนหายเฉยๆ ถ้าช็อตจบก่อน ให้ใช้ `exit: "fly"` หรือให้ช็อตถัดไปเป็นเฟรมที่ไอคอนเกาะมุมอยู่

## การ์ดกฎ = ของจริงในโลกของเรื่อง (`IconFX.board`) · มาตรฐานใหม่ เจ้าของ 1 พ.ย.
เจ้าของ: "ภาพ 1 ให้เข้าตามธีมเรื่องดิ" · ตัวอย่างที่ถูกคือป้ายไม้ลอยทะเลของทะเลลด **ห้ามใช้กล่อง UI เป็นการ์ดกฎ** (`IconFX.card` ใช้กับรายการเช็กลิสต์สั้นๆ ได้ แต่การ์ดกฎใช้ board)
```js
IconFX.board(tl, L.light, { skin: "clipboard", title: "กฎของลุงเชิด", sub: "ใบงานซ่อม · ขบวน 07", t: t0 + 0.2, dur: 2.2, y: 260,
  active: 0, done: [], at: [0.5, 0.7], items: [{ text: "<u>กดกระดิ่ง</u> อย่าวิ่งลงราง", art: IconFX.ART.bell }, { text: "ข้ามตู้ กั้นประตู", art: IconFX.ART.gangway }] });
```
| skin | ของจริง | ท่าเข้า | ของประกอบที่ขยับ | ไฮไลต์ด้วย | ฟอนต์ |
|---|---|---|---|---|---|
| `clipboard` (ซอมบี้/รถไฟฟ้า/งานช่าง) | คลิปบอร์ดอะลูมิเนียม ตัวหนีบ กระดาษเส้น รอยนิ้วน้ำมัน คราบแก้ว | ยื่นเข้ากล้อง (ใหญ่→พอดี) แล้วโยกนิ่ง | ป้ายแขวน "ห้ามใช้งาน" เหลืองดำแกว่ง · ปากกาผูกเชือกแกว่ง · มุมกระดาษพลิ้ว | ปากกาเน้นข้อความเหลือง · ✓ เมจิกแดง | Sriracha (ลายมือเมจิก) |
| `chalk` (ห้องเรียน) | กระดานดำกรอบไม้ รอยลบ ถาดชอล์ก | ห้อยลวดลงมา แกว่งแล้วนิ่ง | แปรงลบเลื่อน · ชอล์กกลิ้ง · ฝุ่นชอล์กลอย | เส้นใต้ชอล์กเหลือง | Mali |
| `tailgate` (ถนน/รถ) | ฝาท้ายรถบรรทุกเหล็กลอน พ่นสี คราบโคลน ทับทิมสะท้อนแสง 4 มุม | หล่นลงตามแรงโน้มถ่วง เด้งบนบานพับ | โซ่สองข้างแกว่ง · ทับทิมวาว · สั่นเหมือนเครื่องติด | สเปรย์ส้ม | Kanit หนา (ตัวพ่นสี) |
| `canal` (น้ำ/คลอง) | ป้ายเตือนเหล็กเคลือบขาวขอบแดง สนิม น็อต บนเสา | แกว่งเข้าบนน็อตตัวเดียว แล้วนิ่ง | ห่วงชูชีพห้อยแกว่ง · หยดน้ำ · แสงคลื่นสะท้อน | พู่กันเหลือง | Kanit |
| `fieldbook` (ทหาร) | สมุดสนามปกผ้าใบ ตะเข็บ กระดาษกริด ชื่อสเตนซิล | ตบลงพื้น ฝุ่นพุ่ง | สายหนังหัวเข็มขัดแกว่ง · ดินสอ · ฝุ่น | ดินสอเทียนแดงวงรอบ | Sriracha + หัวเรื่องสเตนซิล |
| `yant` (ผีไทย) | ผ้ายันต์บนไม้ไผ่ เชือกแดง อักขระ ยันต์ ขอบไหม้ | คลี่ลงจากไม้ แล้วไหว | เปลวเทียนไหว · ควันลอย · ผ้าพลิ้ว | ทองคำเปลว | Sriracha (หมึกพู่กัน) |
- ข้อความใส่ `<u>…</u>` ตรงคำที่ต้องเน้น (สีเน้นของวัสดุนั้น) · `at` = เวลา (วิ หลัง t) ที่แต่ละข้อขึ้น · ข้อ `active` ถูกไฮไลต์ · ข้อใน `done` ได้ ✓
- เสียง: วัตถุตกถึง → เสียงของวัสดุ (`thud`/`creak`/`clang`/`whoosh`) · ไฮไลต์ `t + at[active] + 0.2` → `rustle`/`hiss`/`ching` · ✓ `t + at[k] + 0.3` → `tap` (บันทึกลง `IconFX.cues` ด้วย)
- เพิ่ม skin ใหม่: เพิ่มใน `SK` (ฟอนต์ สี เครื่องมือ) และ `objects` (back/front/enter/life)

## ไอคอนธีมถนน
`road` เป็นแผ่นยางมะตอยมีถนนวิ่งเข้าไปในภาพ เส้นขอบเหลือง เส้นประขาว หมุดสะท้อนแสงวาว อ่านว่า "ถนน" ได้ทันที · ท่อนซุงเป็น art เฉพาะเรื่อง (`IconFX.ART.log`) ไม่ใช่สัญลักษณ์ธีม · รถเล็กบนถนน `IconFX.ART.carSmall`

## ธีม (`IconFX.THEMES`)
| ธีม | กรอบ / วัสดุ | อนุภาคตอนกระแทก | ชีวิตตอนอยู่บนจอ | เสียงกระแทก |
|---|---|---|---|---|
| `zombie` | แผ่นเหล็กขูดขีด หมุด 4 มุม ขอบแดงไฟฉุกเฉิน | เศษเหล็ก ฝุ่น | ขอบนีออนกะพริบเหมือนไฟเสีย | `slam` |
| `road` | แผ่นยางมะตอย ถนนเปอร์สเปกทีฟ เส้นเหลือง เส้นประขาว หมุดสะท้อนแสง | ประกายไฟ | หมุดสะท้อนแสงวาวไล่กัน | `clang` |
| `roadWarn` | ป้ายเตือนเหลืองข้าวหลามตัด | เศษหิน | แสงวาวแผ่นสะท้อนแสง | `clang` |
| `water` | ห่วงชูชีพส้มขาว กลางเป็นฟองแก้ว | ฟองอากาศลอยขึ้น | ฟองลอยขึ้นต่อเนื่อง | `splash` |
| `military` | ป้ายห้อยคอเหล็กบนโซ่ | ฝุ่นดินพุ่ง | ฝุ่นร่วง | `thud` |
| `ghost` | ผ้ายันต์ ขอบแดง อักขระ แขวนเชือก | ควัน | แกว่งเหมือนเปลวเทียน | `gong` |
| `plain` | เหรียญกลมแบบเดิม (ไว้ใช้ทั่วไป) | ดาวประกาย | – | `pop` |

เพิ่มธีมใหม่: เพิ่มรายการใน `T` (สี วัสดุ อนุภาค ชีวิต เสียง) และฟังก์ชันกรอบใน `plates`

## ขนาดขั้นต่ำ
- ไอคอนตอนพูดกฎ: r ≥ 135 (กรอบกว้าง ≥ ¼ ของจอ 1080) · โค้ดบังคับขั้นต่ำให้แล้ว
- ไอคอนที่เกาะมุม: r ≥ 77 (≥ 1/7 จอ) · โค้ดบังคับขั้นต่ำให้แล้ว
- ตัวหนังสือในการ์ด ≥ 44 px

## จุดเวลาสำหรับเสียง (ใส่ใน CUES ของ mix.py ให้ตรงเฟรม)
- `IconFX.enter`: พุ่ง `t` → `whoosh` · **กระแทก `t + IconFX.HIT` (0.30 วิ)** → เสียงกระแทกของธีม + `sting` เบา · ไปเกาะมุม `t + 0.30 + 0.45 + idle` → `whoosh` แล้ว `pop` อีก 0.45 วิ
- `IconFX.card`: เปิด `t` → `whoosh` · รายการที่ k `t + 0.45 + k·step` → `click` · ✓ `+ IconFX.TICK` (0.22) → `ding` · ✗ `+ IconFX.CROSS` (0.18) → `buzz` + `thud` · ปิด `t + dur − 0.3` → `whoosh`
- หรือดึงทุกจุดจากหน้าเว็บ: ทุกครั้งที่เรียก ฟังก์ชันจะบันทึก `{ t, type, gain }` ลง `window.IconFX.cues`
  เปิดหน้า composition ด้วย Playwright แล้วอ่าน `window.IconFX.cues` (ดู `video/lib-shared/iconfx-cues.cjs`) แล้วต่อเข้า `CUES` ของ mix.py ได้เลย
